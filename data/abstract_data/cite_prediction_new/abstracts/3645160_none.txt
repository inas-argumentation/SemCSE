Research on Hot Line Lottery-Ticket-Buying Project Based on PSTN SMS
This paper introduces a kind of hot line lottery-ticket-buying project based on China's publish switch telephone network (PSTN) short message system (SMS). This project expands and improves on SMS. It adds a trade module of Chinese terminal service interface (CTSI) server, operation trade gateway and specialized CP system (it also means to connect with the lottery service system and the lottery center), and meanwhile expands the CTSI protocol to enable SMS to connect with lottery center interactively, which can overcome the shortages of SMS that just carries out storage and retransmit functions. Different from lottery-ticket-buying system nowadays in China, this system is a kind of hot line system which can extends the deadline of bet and increases the lottery sale. The content of this paper are system constitution, protocol expanding, system function and advantages and disadvantages of this system
