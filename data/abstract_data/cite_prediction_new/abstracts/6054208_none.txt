Constructing a Remote Monitoring and Control System Based on 3G Mobile Networks
This paper aims at constructing a new wireless remote monitoring and control system based on 3G mobile networks and Internet. The system architecture combined with RMF (Remote Monitor Flat), CMF (Central Manager Flat) and UAF (User Access Flat) is put forward. The hardware and software design of RMF built in embedded environment, the logic structure design of CMF based on database, and implementation of CMF are taken into consideration and described in detail. The proposed system makes a great improvement upon the traditional wireless monitoring and control system and provides a useful application on the value-add services of 3G and Internet.
