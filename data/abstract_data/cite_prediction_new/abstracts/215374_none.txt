A new matrix method for pulse train identification: Implementing by systolic array
In this paper NASH1 algorithm, a new matrix-based method for identification of radar pulse train, is implemented by systolic array. NASH can be used to identify the PRI for constant, staggered, and jittered signal. Previous matrix-based methods can only identify the first type of signal, i.e. constant PRI. The complexity of the computation in NASH is more than the previous matrix-based method. To overcome this drawback a systolic array, the best parallel structure for the matrix operation, is designed. The systolic array helps to parallelize the matrix inversion, which is the most time consuming part of NASH algorithm.
