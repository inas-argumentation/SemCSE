Design of Multi-function and Programmable Man-Machine Interface
Matrix keyboard or coded keyboard is used multiply for human-computer interaction in current industrial control systems, this program's adaptability is poor, amount of information is small, complex to realize, takes up more hardware and software resources, has low reliability and scalability. This paper presents a system with standard PS/2 interface and circular queue algorithm, to achieve the function of attaching three kinds of peripheral equipment by standard interface. The system drives programmable matrix keyboard, magnetic card readers, as well as the second external PS/2 device, using the standard PS/2 interface of the host, sends data from the three kinds of peripheral to the host corresponding treatment program. The actual application shows: this program has advantages of less code, clear levels of the program structure, high reliability and strong real-time, provides a practical reference model for such research of Man-machine interface equipment.
