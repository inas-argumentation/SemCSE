Fault detection in manufacturing systems with data network partitions
The authors deal with fault detection and analysis in a partitioned data network in a computer-integrated manufacturing (CIM) system. They use the following definitions concerning the data network and the material network: the data network is the logical communication of information between two production units. The material network is the logical communication of material between two production units. The use of the material network is proposed in a computerized manufacturing system to detect and analyze faulty production units when the system experiences data networking partitioning. This approach can help avoid a costly system reconfiguration. The detection and analysis is done by the other production units in the system, either by a single production unit or by production units working together in voting groups.<<ETX>>
