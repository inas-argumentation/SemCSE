A Multiple-tier Distributed Data Integration Architecture
Database online technology has been around for many years. Presently much enterprise data are being generated and used online. For B2B and B2C interaction, Internet is acting as an important role in businesses environment. It has been recognised that the major technical difficulty in bringing data into the end-user environment was the fact that the data is existed on a diverse set of platforms and that the form of automation was required to extract the data efficiently and regularly from those platforms. Enterprise-level intelligent data projects will serve online informational or analytical needs. The key to provide this evolutionary capability is a well defined architecture. This paper presents a Multiple-tier Distributed Data Integration Architecture (MDDIA) to support enterprise data manipulation. This architecture provides a logical layer to map a Unified Logical Data Model to reconstruct data from independent to dependent resources. The paper introduces key technologies used in MDDIA, and illustrates an implementation – NetCase, an integrated solution for multiple-tier distributed network businesses and information applications.
