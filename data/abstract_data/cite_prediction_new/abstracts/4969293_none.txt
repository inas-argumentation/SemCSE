Throughput and Packet Error Rate Analysis Using Routing Algorithm
In now a day's explosion of digital world results in faster, easily accessible, most efficient, reliable communication over the network communication to exchange the information. Considering this advantages, this paper introduced the network on which shortest path algorithm implemented to communicate some nodes on network in shortest, efficient path with efficient throughput mechanism. The nodes carry the data in the form of packets which consists packet header with IP addresses of source and destination and data payload with user information. In the simulation, it estimates the throughput, arrival and blocking rate with packet error rate by implementing ARQ protocol with cooperative diversity system.
