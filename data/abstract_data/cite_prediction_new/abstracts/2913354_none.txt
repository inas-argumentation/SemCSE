Power control game via improved utility functions of primary-secondary user in cognitive radio networks
In cognitive radio networks, power control is considered as an important issue to improve the performance of dynamic spectrum sharing. In this paper, in order to maximize the efficiency of the system, the secondary users and primary user behaviors will be considered. Hence, we propose improved utility functions of primary-secondary user based on a power control game model in this study which rewards primary user for sharing its idle spectrum and lets secondary users achieve efficient transmissions. And then, a detailed analysis of the existence and uniqueness of Nash Equilibrium is discussed for the utility functions. Finally, the simulation results show that this power control game method can improve the performance of the scheme in cognitive radio networks significantly.
