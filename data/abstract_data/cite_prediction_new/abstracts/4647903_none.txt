Intelligent adaptive Control and Simulation for a Spin Missile
This paper proposed a new intelligent controller for a spin missile with uncertainty and unknown parameter. The spin missile controller expression with undetermined parameters can be acquired by using adaptive backstepping design idea, and the controller parameters are optimized online by using genetic algorithm. By using this new method proposed in this paper, not only the stability of the spin missile control system can be acquired more easily but also the dynamic behavior of the spin missile system is good. The simulation shows that the controller is valid.
