Speed control of switched reluctance motor using fractional order control
Switched Reluctance Motor has a strong candidature for the variable speed drive operation. The performance of the drive is enhanced by controlling the speed with a PI controller to reduce the speed ripple which in turn leads to reduced torque ripple. The classical PI controller offers many features like less settling time, fast control, low-cost application but suffers from less stability. To overcome this, a fractional order PI controller was adopted. This paper presents the control of Switched Reluctance Motor using FOPI controller and the controller performance was compared with the classical Integer Order PI controller.
