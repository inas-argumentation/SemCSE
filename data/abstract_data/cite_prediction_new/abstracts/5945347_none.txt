A new algorithm for computing the inertia of eigenproblems (Ax=lambda x) and (Ax=lambda Bx)
The inertia of a n × n complex matrix A , is defined to be an integer triple, In ( A ) = ( π ( A ) , ν ( A ) , δ ( A ) ) , where π ( A ) is the number of eigenvalues of A with positive real parts, ν ( A ) is the number of eigenvalues with negative real parts and δ ( A ) is the number of eigenvalues with zero real parts. In this paper we show that the inertia can be computed by Gereshgorin theorem and block shift-and-invert algorithm for equation Ax = λ Bx or Ax = λ x and this algorithm is compared by function eig.m and sptarn.m in Matlab.
