Predictive torque control with zero-sequence current suppression for open-end winding induction machine
In this paper, a predictive torque control method using direct voltage vector selection (PTC-DVS) with zero-sequence current suppression for open-end winding induction machine is realized. A cost function based on torque error, stator flux error and zero-sequence current is utilized to provide optimal voltage vector selection. The proposed method is compared with conventional field oriented control using PI controllers, and it is shown that the predictive torque control method can achieve faster torque response than conventional method. By varying the weight of the zero-sequence current in the cost function, the system can operate using either 27 voltage vectors or 7 non-zero-sequence-producing voltage vectors.
