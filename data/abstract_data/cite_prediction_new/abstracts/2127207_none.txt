Shear Wave Frequency-Steered Beams from Electrode Arrays
Abstruct-Interdigital arrays launch bulk wave beams that are frequency-steered. In order to employ this effect for device design, both the beam directivity and diffraction loss need to be characterized. Several configurations for device application are examined for the case of horizontally polarized shear waves. An analysis based on realistic charge distributions is developed for predicting beam characteristics from single and double electrode arrays. Double electrode elements are found to be more directive than single electrode elements.
