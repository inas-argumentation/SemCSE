Tracing data diffusion in industrial research with robust watermarking
This paper presents a security system for enforcing security policies throughout distributed environments. The aspects of the system dealing with the protection of digital data using object labeling and mandatory encryption at the OS level are covered briefly; the main focus is on protection provided in the analog domain. This is accomplished by embedding multiple watermarks identifying the copyright owner, the identity of the object, and of users accessing the object into any markable object accessed by users.
