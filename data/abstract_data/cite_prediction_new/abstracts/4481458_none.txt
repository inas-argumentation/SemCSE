Switching control for LPV polytopic systems using multiple Lyapunov functions
In this paper, we study the switching control for a linear parameter varying (LPV) polytopic system using multiple Lyapunov functions to improve the system's ℋ∞ performance. For the large range of parameter varying, we divide the parameter region into small subregions and find a suitable Lyapunov function for each parameter subregion. Under the average dwell time switching logic, a sufficient Linear Matrix inequality (LMI) condition is proposed to guarantee the performance. The proposed control scheme is applied to an active magnetic bearing system.
