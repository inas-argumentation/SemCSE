Design and implementation of multimedia file transfer System using fountain codes technology on Android
Mobile communication devices have stepped into the field of multi-function and intelligent, and files in smart phones need to be transferred rapidly in many fields. However, the traditional TCP-based transmission schemes waste a lot of time when sending files over network with high latencies or high loss rates. This paper presents a multimedia file transfer system on Android platform that utilize the fountain codes technology. We compare the upload performance of the system that used Fountain Codes Technology to FTP client in many environment. The test in practical applications has been done and we found that FTP client was very prone to stalling when propagation is poor, in the same propagation environment, the multimedia file transfer system tended to make use the available bandwidth and complete the file transfer but with a reduced file transfer time.
