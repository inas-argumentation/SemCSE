A FOREST FIRE MONITORING SYSTEM BASED ON GPS AND ZIGBEE WIRELESS SENSOR NETWORK
This Paper presents some basic ideas on the configuration of a mobile system for detecting and locating fire places efficiently and effectively. This paper describes the main features of the overall system, which consist of a sensor head that can detect fire over large areas, a locating system based on a Global Positioning system, a remote supervisor control section and a robot used as the subsystems carrier. The whole system has been configured to work in a semi-autonomous mode with a view also to robot mobility and energy efficiency
