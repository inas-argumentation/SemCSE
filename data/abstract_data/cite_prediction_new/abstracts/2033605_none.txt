Study of a Target Positioning Algorithm with Data Filtering in Wireless Sensor Networks
For reducing the computation overhead spent on processing the received raw data in wireless sensor networks, a target positioning algorithm featuring data filtering is proposed. In this algorithm, a parameter, which is defined as the ratio of the triangular area determined by certain three selected positioning nodes to the maximum triangular area determined by some three nodes moving around the same concentric circles centered at the target, is introduced. Since it is proved that the node groups with larger ratios have the less upper bound of positioning errors, the new target positioning algorithm utilize this parameter to filter the massive received ranging data. The simulation results show that this algorithm can effectively improve the positioning accuracy with less computation overhead.
