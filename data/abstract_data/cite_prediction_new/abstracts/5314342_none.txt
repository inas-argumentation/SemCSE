Transaction Management in Active Heterogeneous Database Systems
The heterogeneous environment is emerging in the current information systems. Within this situation, it is desirable to maintain consistency across databases, i.e., to ensure that they do not contradict each other with respect to the existence or value of real-world entity. Active rules have been widely used in the modern database systems. Active databases contain the capability to automatic monitor the conditions which defined over the database state and the ability to take an action when the state of the underlying database changes. They have provided a great contribution to the maintenance of data integrity and data consistency in database systems. This paper investigates a transaction mechanism for this new type environment.
