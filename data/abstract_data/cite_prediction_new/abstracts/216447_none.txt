Space-shared communication based on truly 3D information space
In order to achieve space-shared communication, it is essential to develop a truly 3D information space. Therefore, we aimed to construct a unified 3D CG space, that is, a unified 3D geometric modeling system. As for the basic coding method, "Extended Geometry Scheme" is proposed. By using this scheme, we have realized the 3D CG space with unified structure. Another important aspect of the space-shared communication is the development of teleoperation using robots on networks. It is important that 3D images are displayed naturally without wrong feeling in such real operation space. We have developed a 3D image display method using the parallax and focus function of human's eyes simultaneously. The proposed 3D display method is a combination of real image generation by Fresnel lens and parallax display with stereoscopic glasses. By using this method, it is possible to display realistic 3D images.
