Canopy : A Controlled Emulation Environment for Network System Experimentation
Network systems are hard to debug because they are inherently parallel and non-deterministic. Canopy assists with network debugging by putting the entire network system into a controlled emulation environmentconstructed from virtual machines and a simulated network. This puts all variables under the user’s control and provides a coherent, omniscient viewpoint of the entire system. To aid the user in observing and manipulating the system, Canopyprovides tools such as traffic visualization, packet manipulation, rollback and replay.
