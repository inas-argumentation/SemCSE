Error Probability Computation for Orthogonal STBC Over Correlated Rayleigh Fading Channels
Orthogonal space-time block coding (STBC) is a useful means to combat multi-path fading in wireless communications, whose performance analysis has been done by a lot of articles. This paper first proposes a simple algorithm to calculate the probability density function of the equivalent signal to noise ratio for orthogonal STBC over correlated Rayleigh fading channels. Then the closed-form expressions for symbol error rate of linear modulation are derived. Compared with the conventional Monte Carlo experiments, the new method can significantly reduce the simulation time.
