Wide and multi-band antenna design using the genetic algorithm to create amorphous shapes using ellipses
A method is demonstrated for generating compact, broadband and multi-band antennas using ellipses to create new amorphous shapes with greater bandwidth and less return loss that previously demonstrated. The genetic algorithm is used to optimize the design. Four example designs are given including amorphous patches and amorphous monopoles. FDTD is used to simulate the designs allowing the user to embed a low insertion loss design directly into a heterogenous structure or dielectric material.
