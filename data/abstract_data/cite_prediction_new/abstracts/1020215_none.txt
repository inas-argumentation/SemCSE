Optimum structure for a radial basis functions based equalizer
A solution of a nonlinear equalizer based on the radial basis functions neural network is given in this paper. We consider a bipolar signal which passes through a dispersive channel and is corrupted by additive noise. When the distortion caused by the channel is nonlinear, the classical methods fail. The task of signal recovery is viewed as a pattern recognition problem, where each transmitted signal has been assigned a class and the equalizer's task is to find an optimum boundary between the classes. We give a solution for the minimum necessary number of hidden units for a radial basis functions (RBF) neural network implementation for the equalizer. Simulation results, where the RBF neural network is used as an equalizer are provided.
