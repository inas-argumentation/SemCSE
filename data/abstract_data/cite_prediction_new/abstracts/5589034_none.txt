A new approach for handling events in complex applications
Many applications related to graphical user interface, multimedia, and communication protocols have been developed using the event-driven programming. This approach of programming is fundamentally different from the procedural approach which can lead, in a GUI application for example, to some structures which are very rigid and hard to maintain and extend, especially when the number of events to be handled is considerable. This is among the reasons why other programming approaches have been proposed. This paper proposes a new approach to handling events in complex applications such as real time and telecommunication applications. This approach is easy to understand and suitable for developing interactive applications.
