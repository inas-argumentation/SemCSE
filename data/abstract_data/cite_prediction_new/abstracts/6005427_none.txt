Graphics Processor Based Rigid Body Physics Simulation for Massive Crowds of Simulated Agents
This project is about the mapping of a rigid body physics simulation to a parallel stream processor, the programmable Graphics Processing Unit (GPU) located on modern video cards. The target application was to give physically correct movement to thousands of simulated agents in computer games. All basic functionality corresponding to a physics system used in games, should be implemented on the GPU. This includes updating positions and velocities (using the laws of classical dynamics) as well as collision handling. The difficulties involved how to perform the calculations in parallel and how to represent data in memory so that the GPU can read from and write to it. After a closer look at the problem, however, it is concluded that not every part of the system can run on the GPU in real-time. More precisely, the CPU needs to perform a selection of body pairs that are possibly colliding, while everything else runs on the GPU. Apart from that, the developed system is very well parallelized and can perform physics calculations on thousands of bodies. The developed prototype application gives visually pleasing results, and runs with a very good real-time frame rate. The system is expected to offload the heavy physics computations from the CPU so that it can perform other valuable calculations. Svensk titel: Grafikprocessorbaserad fysikalisk simulering av fasta kroppar för massiva grupper av simulerade agenter.
