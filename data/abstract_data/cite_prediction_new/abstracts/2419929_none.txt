Date Mar. 5, 1981.A system for decoding compressed data comprising an address memory of a FIFO type or RAM type, and an addition/subtraction circuit in which addition/subtraction is carried out between the address of a reference color change element and a relative distance between the reference color change element and a color change element in question, so that position data for the color change element in question is obtained, and the obtained position data of the color change element in question is written-in to the address memory.
