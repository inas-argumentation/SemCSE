Hyperplane Arrangements, Parking Functions and Tree Inversions
A (real) hyperplane arrangement is a discrete set of hyperplanes in ℝn. We will be concerned with hyperplane arrangements that “interpolate” between two well-known arrangements: (1) the set B n of hyperplanes xi = xj, for 1 ≤ i < j ≤ n, and (2) the set B n of hyperplanes xi = xj = m, for 1 ≤ i < j ≤ n and m ∈ ℤ.
