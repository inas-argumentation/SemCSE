A fast VLSI hardware modular multiplication / division algorithm
This paper presents a simple algorithm for the evaluation of modular multiplication and division, which can be used in a number of applications in signal processing and public-key cryptography. The method combines the multiplication and division procedures by using only additions and subtractions. The full algorithm takes log2C + x steps to complete where C is the cipher text and x is a function of the number of leading zeros in C. Furthermore, due to its simplicity, the algorithm can be easily implemented using VLSI technology. Key-Words: Multiplication, division, VLSI, signal processing, cryptography.
