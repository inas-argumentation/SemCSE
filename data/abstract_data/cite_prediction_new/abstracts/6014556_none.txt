AMACONT: A System Architecture for Adaptive Multimedia Web Applications
Engineering personalized ubiquitous Web applications requires to develop adaptable Web content as well as to automatically adjust it to varying client devices and dynamically changing user preferences. To meet this requirement, this paper introduces the system architecture of the AMACONT project [Am04] that aims at the dynamic generation of Web presentations tailored to users’ varying needs and device capabilities. Different techniques for static and dynamic content, layout and structure adaptation supported by the overall architecture are explained. Furthermore, strategies for dynamic device and user modeling are illustrated in order to guarantee up-to-date user and device models for the whole content generation process. Finally, modules of a modular graphical authoring tool for the visual development of adaptive Web applications are presented.
