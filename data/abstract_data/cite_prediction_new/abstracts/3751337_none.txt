Turbo coded orthogonal frequency division multiplexing for digital audio broadcasting
From the fact that the first bit among the four coded bits at the rate compatible punctured convolutional (RCPC) coding defined in the Eureka 147 DAB system is not punctured, this paper proposes a new DAB system model that substitutes the turbo code for the existing RCPC code without modifying the puncturing procedure. The performance of a new system is compared to that of the, conventional system in the fast information channel (FIC) and main service channel (MSC) for DAB transmission mode I on the Rician fading channel and the Rayleigh fading channel.
