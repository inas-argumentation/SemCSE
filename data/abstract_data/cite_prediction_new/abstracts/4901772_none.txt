Improving reliability in cell-based evolve hardware architecture using fault tolerance control
This paper presents a cell-based architecture with fault tolerance control unit. The main features of proposed model are a control unit can be used to take control over neighbor functional units when neighbor control units failed. In the approach considered a cell to be control layer and functional layer. A functional unit in the functional layer is used to perform operations of cells and support repairing and detecting faults in the control layer. A control unit in the control layer can be used to detect and repair faults in other control units in the control layer and its functional unit in the functional layer. Therefore, this strategy can take advantage of the internal resource. This paper shows how the model can be used to repair a control unit fault and a functional unit fault. The reliability analysis shows the improving fault tolerance of this model.
