E-band double layer cavity backed slot array antenna
In this paper a double layer cavity backed slot array antenna at E band is presented for point-to-point wireless communication. The antenna is built using an equal-split rectangular waveguide feed network and 2×2 elements sub array. The feed network is composed four E-plane T-junctions to lower the leakage between the metal plate. The 8×8 slot array antenna has been fabricated using PEI resin. The measured reflection coefficient remains below −10dB with reasonably good radiation patterns and gain over 24.8dB of the band from 71 GHz to 86 GHz.
