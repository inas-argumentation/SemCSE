PVM Implementations of Advection-Chemistry Modules of Air Pollution Models
The Parallel Virtual Machine (PVM) Package is available now at many sites and can be used to develop truly heterogeneous programs for multiple computer systems. The PVM Package is a software package developed at Oak Ridge National Laboratory and Emory University. It enables a heterogeneous collection of UNIX computers that are linked in a network to function as a single parallel computer. PVM applications can be run across a wide variety of architectures. PVM handles automatically all message conversions required when the linked computers use diierent data representations. Participating computers can be distributed anywhere in the world and linked by a variety of networks. It should be possible to distribute the tasks in an optimal way: to send to each computer in the network tasks that are most suitable for its architecture.
