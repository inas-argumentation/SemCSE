Positive definite and Gram tensor complementarity problems
Given a continuous function and , the non-linear complementarity problem $$\text{ NCP }(g,q)$$NCP(g,q) is to find a vector such that $$\begin{aligned} x \ge 0,~~y:=g(x) +q\ge 0~~\text{ and }~~x^Ty=0. \end{aligned}$$x≥0,y:=g(x)+q≥0andxTy=0.We say that g has the Globally Uniquely Solvable ($$\text{ GUS }$$GUS)-property if $$\text{ NCP }(g,q)$$NCP(g,q) has a unique solution for all and C-property if $$\mathrm{NCP}(g,q)$$NCP(g,q) has a convex solution set for all . In this paper, we find a class of non-linear functions that have the $$\text{ GUS }$$GUS-property and C-property. These functions are constructed by some special tensors which are positive semidefinite. We call these tensors as Gram tensors.
