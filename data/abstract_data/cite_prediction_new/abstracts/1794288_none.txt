3D reconstruction of industrial component using simulated CT
Nowadays a digital solid model of an object can be obtained by 3D reconstruction processes, such as laser scanner, Coordinate Measuring Machine or CT-Scan. In this work, a 3D reconstruction process using simulated CT technique is developed and tested. The reconstruction principle of simulated CT Scan is similar to CT-scan based reconstruction technique, however the input data acquisition technique is different. Using this technique, a good reconstruction result can be achieved with higher angular resolution of the object projection image. Here, an electro-mechanic controlled rotary table system was designed and manufactured. This system was carefully designed to ensure that the image of X-ray scanned object was clearly taken without any interference. Furthermore, an intensity standardization method of the projection image has been developed. A cone beam algorithm has been employed to reconstruct the 3D solid model, which can be read by any commercial CAD software, where the geometrical analysis could then be conducted. The analysis results show a good agreement between the reconstructed and the original object, where the maximum difference is around 1.6 mm.
