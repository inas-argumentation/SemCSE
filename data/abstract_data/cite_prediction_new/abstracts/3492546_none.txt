Design and Implementation of an Auto-Configuration and Cooperation Generation of Web Service User Interface Based on TR-069 Protocol
This paper presents a novel architecture for auto-configuration and cooperation of automatic web service UI eneration with lightweight UI resource. The auto-configuration and cooperation generation mechanisms proposed in our network rchitecture are based on TR-069 and TR-106. Using the communication mechanism of TR-069 and UI resource data model based on TR-106, the latest comprehensible UI resources can be easily cooperate, share, and configure between clients and servers. A software stack in our system is designed to balance UI resources' capacity and clients' workload. The proposed method would not be limited to central control resource management and automatically configures clients by using most updated UI resources.
