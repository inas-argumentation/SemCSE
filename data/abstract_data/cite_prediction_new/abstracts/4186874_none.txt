The research and design of the data path In LTE system
When Data goes through the protocol stack, the protocol processes will result to memory applying, releasing, copying and other operations. The data rates of LTE system is very high and the ARM completing all protocol data processes needs a lot of time, so it will affect data transmission in time. In order to reduce processing time, this paper uses the concept of block information, which does not process the ture data but just to record the protocol processing operations. These operation's information with received block information from the upper(lower) layer assembles the block information in certain layer. After analysis, we know that using block information of data blocks eliminates a lot of operations, such as Memory applying, releasing, data copying and so on, which greatly reduces the processing time and improves the instantaneity of data transmission.
