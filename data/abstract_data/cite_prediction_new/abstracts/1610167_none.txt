Polylinear form of functions on HOSVD basis in relation to Fourier image processing
In the paper a new data representation domain and approximation approach is proposed based on Higher Order Singular Value Decomposition (HOSVD) and the achieved results are compared to the well known Fourier representation domain. The developed method utilizes measurement data, based on which a special set of one variable orthonormal functions can be numerically reconstructed using the HOSVD. With the help of such determined functions more precise data approximation can be achieved, then in case when using trigonometric functions or orthogonal polynomials. Beside this the number of functions necessary to approximate the input data plays important role, as well, which in case of such determined functions will be relatively low. This property of the approach enables to perform much more efficient data compression by maintaining the accuracy of the approximation at a higher level.
