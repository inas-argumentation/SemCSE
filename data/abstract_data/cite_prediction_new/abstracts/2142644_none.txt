Dynamic surface control techniques applied to horizontal position control of a quadrotor
This paper introduces dynamic surface control (DSC) techniques to formulate concise sliding mode controllers to control the horizontal position of an underactuated quadrotor. Sliding mode control is a popular type of robust nonlinear control method. However, traditional methods on handling underactuated model such as integrator backstepping and dynamic input augmentation could lead to the explosion of terms when time derivatives are taken in controller designs. It makes sliding mode controllers only feasible for highly simplified dynamic models. We solve the term explosion problem by introducing DSC filters in synthetic controls, so that a full quadrotor model can be used for horizontal controller designs.
