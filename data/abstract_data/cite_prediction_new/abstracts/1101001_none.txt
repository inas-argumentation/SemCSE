Performance Evaluation of Secure and Efficient AODV Routing Protocol using NS2
This paper focuses on the improvement on the performance of AODV single path routing protocol concerning the route maintenance mechanism with security. This paper presents the performance comparison of proposed protocol Secure and efficient AODV (SE-AODV) with AODV routing protocol using NS2. As the reactive routing protocols is completely different from the proactive routing protocols because they belong to two different routing families. Our proposed SEAODV routing protocol change the on-demand single path routing protocol into proactive multipath routing protocol in terms of predicting the link failure by utilizing the link state prediction algorithm and in terms of creating multiple routes by utilizing on-demand multipath routing approach.
