Implementing Resource Containers in K 42 CSC 2227 Term Project Final Report
Resource containers (RC) offer a framework in which to provide accurate accounting and enforcement of operating system resource allocation and usage. In this project we have implemented the RC framework on the K42 operating system platform and evaluate its functionality, and performance. Furthermore, we present lessons learned in this project that deal with practicality, compatibility, and applicability of this model in the context of K42 in particular, and in a general-purpose server operating system in general. Our performance results demonstrate that RC the framework can be implemented in K42 with negligible overhead to the system along the common execution paths. However, the compatibility of the design of K42 and the RC framework is fairly poor. Although, we managed to partially implement the RC model, completely harmonizing the two model remains an open problem. K42 uses a two level scheduling hierarchy that hides resource allocation and consumption in the user level from the operating system kernel. An RC model that is implemented only in the kernel level, would result in inaccurate resource accounting and scheduling. However, with some restrictive assumptions (that might diminish the flexibility of K42 to some extent), it is possible to achieve acceptable accuracy in accounting and scheduling. In terms of memory management in K42, there is insufficient granularity to identify threads and corresponding user-level scheduler entities, leading to difficulties in identifying the appropriate resource container to perform accounting and enforcement.
