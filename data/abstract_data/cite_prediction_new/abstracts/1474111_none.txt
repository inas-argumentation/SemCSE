Productivity of telecommunication systems with modified signal-code constructions
The paper represents research results of using modified signal-code constructions productivity with multipositional phase manipulation. The construction peculiarities are considered for coder, decoder and signal processing block with modified construction. The principals for signal processing have been described and the block-scheme of signal processing system for the offered signal-code constructions has been represented. Energy gain coding from using modified code constructions in telecommunication systems has been defined. The recommendations have been given for choosing number of iteration cycles in decoding and the code word construction has been described for coding with noise immunity and error correction.
