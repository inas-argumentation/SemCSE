A prosthetic hand control interface using ESP8266 Wi-Fi module and Android application
Upper limb amputees frequently experience mental and physical challenges because of the inability to utilize their furthest points. To help such users in getting a utilitarian substitute hand at an achievable cost, a 3D printed prosthetic was developed using ESP8266 wireless module. A strategic distance can be maintained from the expensive and complex control techniques using a simple Android application that permits the amputees to choose a gesture that one wishes the hand to perform. Mobile application sends this data to the Wi-Fi module, which in turn controls the mechanism to activate each finger independently. Its simple design empowers the users with a quickly adaptable technology.
