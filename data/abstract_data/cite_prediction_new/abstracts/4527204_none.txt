A web service based enterprise information integration model
In order to integrate enterprise legacy system effectively, a web service based information integration model is presented. Firstly, the characteristics of legacy system are analyzed, and then the data and functions that need to be published are confirmed. Secondly the legacy system is wrapped into web service through multi-agent technology. Then enterprises can dynamically integrate all web services distributed in different domains with different integration goals. Due to adoption of wrapping technology for legacy system, original security and stability of legacy system are guaranteed in the integration platform. Finally, the validity and practicability of the integration technology are verified through the application in the establishment of computer information integration platform for TE procedure.
