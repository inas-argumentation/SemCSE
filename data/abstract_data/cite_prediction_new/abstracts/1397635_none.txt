A low power STT-RAM based register file for GPGPUs
State-of-the-art general-purpose graphics processing units (GPGPUs) execute a large number of threads simultaneously to hide latency of memory hierarchy and functional units. The extreme multithreading requires a large register file to hold the state of the executing threads. As feature size shrinks, both static and dynamic power of SRAM based register files increase rapidly. In this work, we exploit spin-transfer-torque random access memory (STT-RAM) to implement a power efficient register file. STT-RAM is a promising memory technology which has fast read access, high density, and non-volatility. However, one of the disadvantages of STT-RAM is its long write latency and high write energy. To address this challenge, we propose three optimization techniques: The first optimization technique augments branch divergence and reduces dynamic power of STT-RAM. Due to branch divergence, many warps have inactive threads. We propose using active mask of GPGPUs and access only those registers that correspond to active threads. By disabling idle registers, we are able to reduce dynamic power of the register file. The second optimization technique relies on dead registers. Our evaluation reveals that there are a fair number of registers that are written but are never used. We exploit a combination of software and hardware approach and propose dead-write elimination to reduce latency and dynamic power of costly write operations in STT-RAM. The third optimization technique uses a small buffer to replace accesses to the large register file with accesses to the small buffer which holds working set of executing threads. By combining these three optimization techniques, we show that the power consumption of the register file can be reduced by 86% with negligible impact on performance.
