A modified modulation strategy for an active rectifier stage structurally based on the topology of an indirect matrix converter
A modified modulation strategy for an active rectifier is discussed in this paper. It is designed for an inverter which is structurally based on the topology of the rectifier stage in an indirect matrix converter. This modified modulation strategy is based on a carrier signal whilst the switching frequency is still variable within a certain range. This is dependent on the input value for inverter output voltage. This modulation strategy allows easy set-up of the output voltage and with that allows the use of energy storage systems which demand high flexibility. The implementation of this strategy is illustrated in this paper as well as simulation results which demonstrate the variance in the switching frequency.
