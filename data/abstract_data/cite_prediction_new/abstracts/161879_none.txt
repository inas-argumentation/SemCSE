Road Accident vehicle detection using Particle Swarm Optimization technique
In present days, the major road ways are monitored using surveillance camera. When an accident happen with in this surveillance area, the existing system has the information about the accident and it was failed to alert the authority unless manually initiated. Our proposed system will send the information to the authority as earlier as any mesh up happened. This process is done by following two step.The images are taken with and without object in the surveillance area, the features are extracted and stored in the database. Classification is done between normal and abnormal images using Particle Swarm optimization.
