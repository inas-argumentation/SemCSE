Java Source Code Protection Based on JNI and AES Algorithm
In the Java web security field, the encryption and decryption code of the traditional Java source code protection scheme, which is based on custom class loader encryption, can be easily decompiled. This effect results in the leakage of the source code and the low efficiency of encryption and decryption. This study proposes a scheme based on the Java Native Interface (JNI) and the Advanced Encryption Standard (AES) to protect the Java source code. The proposed scheme adopts the JNI for calling the encryption and decryption's codes implemented by C/C ++, and the encryption and decryption's codes adopt an improved AES encryption algorithm. This scheme greatly improves both the encryption and decryption of the implementation efficiency and the security of the source code.
