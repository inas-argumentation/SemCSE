Design and implementation of a uniform wireless OPC DA Server
Based on the study of the drawback of traditional wired automatic control system and current wireless remote monitoring system in dealing with remote-placed and widespread-placed controlled objects, this paper gives out a new architecture using mobile communication networks and OPC technology. It uses Mobile Agent and Mobile Agent Server to ensure the transparent data exchange between controlled objects and OPC server. And Driver Layer and Factory Method Pattern is exploited to make it feasible that one OPC Server serves for different kinds of controlled objects. Also, the system is released as a platform. And it makes the manufactures no longer caring about how far, how wide and in which form the controlled objects are organized.
