High-speed demonstration of low-power 1 k-bit shift-register memories using LR-biasing SFQ circuits
We designed a low-power shift-register memory using singleflux-quantum (SFQ) circuits for bit-serial SFQ microprocessors. In order to reduce the static power consumption of the SFQ memories, LR-biasing SFQ circuits were employed, where the resistance network for supplying the bias current is replaced with the inductance network with small resistance. We implemented a low-power 1 k-bit SFQ shift-register memory and confirmed its 30GHz operation for all addresses. The power consumption was reduced to 26% of the conventional resistively biased SFQ memories.
