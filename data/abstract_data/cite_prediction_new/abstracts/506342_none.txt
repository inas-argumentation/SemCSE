Performance improvement of grid integrated solar PV system using DNLMS control algorithm
This paper presents a 3-phase grid integrated solar photovoltaic (PV) system incorporating decorrelation normalized least mean square (DNLMS) algorithm with the aim to enhance the overall performance of the system. Here, a 3-phase, 3-wire, single stage PV system consists of PV array with an appropriate maximum power point tracking (MPPT) method, filters, loads, and a 3-leg voltage source converter (VSC) with a DC link capacitor. The main objective of the PV integrated system with the proposed modern adaptive control algorithm is to achieve unity power factor (UPF) at the grid end, load balancing, and harmonics elimination while transferring the active power to the grid as well as to loads. These required objectives are achieved through controlled switching pulses for the insulated gate bipolar transistor (IGBT) based VSC using DNLMS control algorithm with fast convergence rate. In the laboratory, an experimental prototype is developed and proposed algorithm is implemented to verify its efficacy.
