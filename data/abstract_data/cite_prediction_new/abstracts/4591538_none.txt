BLOCKER: A Variable & Multiattribute Declustering for Parallel Database Machines
In this paper, a new declustering approach is introduced which uses an analytical workload model to determine the number of processors for each relation to execute the given workload efficiently. The number of processors determined is used in generating load balanced declustering based on a well-known multiattribute file structure [4]. The result turns into a parallel file structure called PARMA [5]. The overall system, therefore, combines all advantages of variable and multiattribute declustering together with efficient processor mapping [2] and the underlying parallel file support.
