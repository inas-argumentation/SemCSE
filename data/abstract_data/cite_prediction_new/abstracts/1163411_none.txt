An Improved Baptista Encryption Algorithm Based on Conservative Chaotic System
An Improved Baptista algorithm based on conservative chaotic system is proposed in this paper. During encryption, the initial value of the chaotic system is updated timely. The plaintext is divided into groups at the length of a character. In the standard map, when the integer part of y is equivalent to the value of character’s ASCII code, iteration is selected as the cipher text .And before each iterative process, x has been done a simple transformation. Theoretical analysis and experiment results show that the algorithm has a better sensitivity to initial value and an excellent uniformity of distribution in cipher text. The algorithm has the good performance o f simple implementation and reliable safety.
