Multisite cardiac pacing. A code proposal revisited
In a previous communication, we proposed a new code for multisite pacing based on the standard pacemaker code1, 2. The proposed code uses a split format in the first position to describe the anatomic chamber or chambers being paced and the third position to describe the inhibited (I) and the triggered (T) response of the pacemaker to sensed signals1, 2. Using the original proposal, a conventional DDD pacemaker would assume the conceptual code of A/V. D. TI/I or A/V. D. D/I2. To the ease of comprehension, periods have been added to separate each of the 3 positions. The top letter in the first position refers to the atrium and the bottom letter to the ventricle. The code for a DDD pacemaker with dual site ventricular stimulation would be A/VV.D.D. A biventricular pacemaker without atrial pacing could be codified as a VV.V.I (inhibited) or VV.V.T (triggered) device while a pacemaker with dual site atrial and ventricular stimulation would be coded as an AA/VV.D.D device. Using the split format in the third position, a dual site ventricular DDD pacemaker with a horizontal ventricular triggered function would be an A/VV.D.D/T device. A modified split format of the first position can describe devices for monochamber left ventricular (LV) pacing such as A/L.D.D pacemaker. The “L” in the first position indicates an LV lead. Using the letter “L” in the first position or second position (as discussed later) is easy to remember and it would be immediately recognized as representing a left-sided chamber. For multisite pacing a right ventricular (RV) lead is best depicted as “R” rather than “V” and this designation could be extended to any position in the standard code. Thus, a code for a biventricular DDD pacemaker becomes (A/RL.D.D) and that of a bifocal right ventricular DDD pacemaker becomes (A/RR.D.D). Any pacemaker code should be upgraded periodically to accommodate advances in technology to make the code more clinically relevant.
