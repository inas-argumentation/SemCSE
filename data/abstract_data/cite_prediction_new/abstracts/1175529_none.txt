Parallelizing the Divide and Conquer Algorithm for the SymmetricTridiagonal Eigenvalue Problem on Distributed Memory Architectures
We present a new parallel implementation of a divide and conquer algorithm for computing the spectral decomposition of a symmetric tridiagonal matrix on distributed memory architectures.
