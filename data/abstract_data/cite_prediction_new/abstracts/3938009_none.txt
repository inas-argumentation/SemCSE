Existence of large solutions for a class of quasilinear elliptic equations
We consider the quasilinear elliptic equation div ( | ∇ u | p - 2 ∇ u ) = a ( x ) f ( u ) , u ⩾ 0 in Ω , where p > 1 , a ( x ) ⩾ 0 , a ( x ) ≢ 0 , a ( x ) ∈ C ( Ω ¯ ) , and f is continuous and non-decreasing on [ 0 , + ∞ ) , satisfies f ( 0 ) = 0 , f ( s ) > 0 for s > 0 and the Keller–Osserman condition ∫ 1 + ∞ [ F ( s ) ] - 1 / p d s = + ∞ , F ( s ) = ∫ 0 s f ( t ) d t . We establish conditions on the function a that are necessary and sufficient for the existence of positive solutions, bounded and unbounded, of the given equation.
