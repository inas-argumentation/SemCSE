Robust finite-time H∞ control for nonlinear system with parameter uncertainties and one-side Lipschitz via output feedback
This study investigates the problem of robust finite-time H∞ control for nonlinear system with parameter uncertainties and one-side Lipschitz via output feedback. The nonlinear function is considered to satisfy nonlinear condition. By means of Linear matrix inequality (LMI) techniques, design algorithms of static output feedback controller are developed. Finally, numerical examples are presented to demonstrate the effectiveness of the theoretical results.
