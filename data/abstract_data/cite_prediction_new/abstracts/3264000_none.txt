Low Frequency Eddy Current Imaging using MR Sensor Detecting Tangential Magnetic Components for Non-destructing Evaluation
An eddy-current distribution imaging system with wide area magnetic field exposure, which can be applied to the detection of deep crack of the metal using a magnetic resistive (MR) sensor is developed. This eddy current image is obtained by the developed system detecting perpendicular components to the magnetic filed exposure. By using very low frequency magnetic field exposure, detection of the opposite side slit of the metal substrate is enabled.
