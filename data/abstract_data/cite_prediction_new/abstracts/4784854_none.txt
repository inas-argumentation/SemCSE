AWING: a general purpose command interface generator (and an exercise in software reuse)
A number of interface generators have recently been developed that exploit the graphic capabilities of modern workstations by assisting in the creation of windowbased menu/mouse interfaces for application systems. Unfortunately, most such interface generators produce an interface that restricts the application to run only on a workstation, because the interface requires a high resolution display and a mouse input device. As a result, these interface generators typically cannot be used with applications that must be executable from a variety of system access points, including via terminals without menu/mouse capabilities. These restrictions mean that the interface generator cannot be used to upgrade existing applications with a menu/mouse interface if the ability to enter command-line input must also be retained as an option. Or, if the interface generator is used, the menu/mouse and command-line interfaces are constructed separately, typically from two different interface specifica,tions, and must subsequently be somehow integrated in the underlying application. AWING is an interface generator tha.t genera.tes both a menu/mouse and a command-line realization of a command interface language from a single language specification. Because AWING derives both interface realizations from a common specification, it guarantees that the command recognition events passed to the underlying application are consistent between the two realizations.
