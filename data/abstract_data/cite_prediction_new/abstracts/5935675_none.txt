Final Project Report – Redesigning the D 3 E Publisher ’ s Toolkit Interface
The DE Toolkit aimed at supporting users in converting long hierarchical HTML documents into a frame-based environment which supports quick navigation and anchored discussions. However, the Toolkit has demonstrated to be hard to use, requiring high level of cognitive effort and knowledge on its underlying structure. In other words, it does not seamlessly map the intension of the system into the intension of the users. The goal of this project is to provide design recommendations for a new user interface for the DE Toolkit, which aims at reducing this gap. Toward this end, it will analyze (1) the goals and users of the system, (2) how they use the system in real situation, and finally (3) the communicability ([ROP00b]) of the interface in passing to users the designers intentions. In so doing, it aims at facilitating the adopting of the toolkit by a broader audience of non-expert users. This project will then perform a complete design analysis of the toolkit based on TaskCentered Design analysis. This framework will guide all stages of the project, from the initial definition of Tasks, questionnaires among others to the final design recommendations.
