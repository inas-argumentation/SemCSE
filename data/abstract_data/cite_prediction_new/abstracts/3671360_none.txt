Application of One Combined Algorithm in Enterprise Capability Appraisal Model Based on Rough Set and Fuzzy Theory
As businesses are many factors involved in capacity assessment, it is difficult to judge the results, aims at the imprecise and uncertainty of evaluation, an enterprise capability appraisal model based on rough set and fuzzy theory is given in the paper. A java program by using rough set algorithm is developed to determine weight of the index, then combining fuzzy evaluation to get the comprehensive evaluation. The actual application shows that the model is a feasible assessment method and makes the evaluation more rational.
