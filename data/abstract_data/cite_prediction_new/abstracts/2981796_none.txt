Constructing Reliable Embedded Systems Using the Results of System Safety Analysis
Thorough assessment of embedded systems in terms of reliability and safety requires the use of several analysis techniques. Such an assessment accompanies system definition and construction from the beginning. It is shown how standard analysis techniques can be combined along with traditional system decomposition. With this type of integration it shall be possible to reach the level of software description and continue with appropriate analyses. A sufficiently decomposed system will be reconstructed by continuously comparing the quantitative and qualitative results of fault tree analysis with user-defined requirements satisfying reliability constraints.
