REFLECTIONS ON TURBULENT SADDLES , CREDIBILITY OF NUMERICS , AND RELATED ISSUES
1 Turbulent transients One of the two main ways towards plain turbulence is that recognized as the subcritical route, typical for parallel shear flows. Classical examples are the plane Poiseuille, plane Couette and Hagen-Poiseuille flows. The subcritical routes, parameterized with the Reynolds number Re, can be described following the references [1, 2, 3]: 0 ≤ Re ≤ R exp : Exponentially bounded energy decay to the basic laminar flow (globally stable laminar flow [1, 2, 3]; universal attractor [4, 5]). R exp < Re ≤ R E : Monotonous energy decay to the basic laminar flow (globally stable laminar flow; universal attractor). For the Navier-Stokes equation we have R exp ≡ R E [1]. R E < Re < R S : Non-monotonous decay to the basic laminar flow (globally stable laminar flow; universal attractor; initial algebraic growth). R S ≤ Re ≤ R T : Presence of (unstable) coherent structures others than the basic flow, which coexist with it. Re-laminarization to the basic flow, which remains Lyapunov stable (sub-criticality; no turbulence). R T < Re ≤ R T T : Transient turbulence. A turbulent saddle is formed. If R T Re ≤ R T T , dominant presence of turbulent phenomena is observed (noise sustained turbulence). R T T < Re: Plain turbulence. A proper turbulent attractor exists, or otherwise, intense noise sustained turbulence remains, supported by a turbulent saddle. If 0 ≤ Re < R S , the flow is topologically equivalent to the Stokes non-inertial transient flow. We call this region the " Stokes regime ". R S fixes the end of this regime, as well as the first saddle-node bifurcation point [2] from which a cascade of coherent structures is born [6]. If the basic flow becomes linearly unstable for Re = R L , case of the plane Poiseuille flow, sub-criticality implies R S < R L < ∞, i.e., Lyapunov destabilization of the basic flow is a phenomenon independent of turbulence. From a long time ago, turbulence has been recognized as a chaotic phenomenon [7, 8]. The link between transient chaos, chaotic saddles and events like attractor crises, has been established since the early eighties (see [9, 10, 11, 12, 13] and references quoted there).
