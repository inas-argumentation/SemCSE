IIPS-ICC: An Intelligent IP-Surveillance Platform Using Interactive Camera-handoff Control
In this paper, we develop an intelligent IP-surveillance platform using interactive camera-handoff control, which is called IIPS-ICC. In addition to fundamental tele-surveillance functions, the emerging techniques adopted in IIPS-ICC contain flexible surveillance description language, scalable video coding and intelligent data fusion. The proposed camera-handoff control is used to assist client applications in changing a monitoring connection automatically when tracked people move among multiple cameras in a large-scale surveillance environment, e.g., hospital. According to experimental results, IIPS-ICC would be a feasible solution to provide more reliable and scalable surveillance services in the next-generation IP surveillance system.
