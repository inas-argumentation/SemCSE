A Delay Reduction Multicast Routing Protocol for Group-shared Ad Hoc Network
Mobile ad hoc network is a wireless mobile network that does not have any base station or other central control infrastructures. Design of efficient multicast routing protocols in such networks is challenging. Shared tree routing protocol is a widely used multicast routing protocol in ad hoc network. However, it has problems encountered in end-to-end delay. In this paper we have proposed a protocol as an extension of the existing multicast Ad hoc On-demand Distance Vector (MAODV) routing to improve the inherent problem of large end-to-end delay in shared tree method. Our protocol is referred to as Delay reduction multicast routing protocol (DRMRP). The protocol uses n-hop local ring search to establish new forwarding path and limit the scope of flooding. With this mechanism simulation results demonstrate excellent reduction of average end-to-end delay as well as high packet delivery ratio.
