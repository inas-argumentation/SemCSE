Concept of a Data Exchange Agent System for Automatic Construction of Simulation Models of Manufacturing Processes
The simulative agent system is going to be capable of independent collection of information required for construction of a simulation model, monitoring and constant data updating, deciding on the necessity of building new updated simulation models, applying changes to data (based on results of a conducted simulation) into class ERP and PDM systems. In this way will be achieved - apart from faster model construction - an increase in reality reproduction precision, in comparison to simulation models built with traditional methods.
