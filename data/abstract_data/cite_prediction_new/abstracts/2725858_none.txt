Seismicity Online Grid Map for Regional Earthquake Activity Studies
We have developed a new user friendly, online server based database system and filtering method which allows us to analyze display data and plot seismicity maps using 'Google Maps'. The application is demonstrated using seismic data in the region of Greece and it allows segmentation of the region so that the earthquake-active regions can be identified. Cumulative earthquake time plots as well as earthquake magnitude graphs can be plotted for any subregion. A real time database update from the Geodynamic Institute of Athens will be demonstrated.
