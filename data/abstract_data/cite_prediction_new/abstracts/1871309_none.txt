Handheld modern computer brings new features to portable X-ray fluorescence coating thickness measurement device
X-ray fluorescence is routinely used to measure coating thickness on table top setup. The use of a handheld modern computer (PC compatible) gives the possibility to build a portable device with new features. The computer is used to control deviceʼs components and to do processor consuming calculation. The user interface is “push button” to allow the utilization by nonspecialized operator.
