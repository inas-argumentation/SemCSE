Research on pre-stack Reverse Time Migration image
According to the Reverse Time Migration (RTM) which is based on the full wave equation, RTM can processes the data of the arbitrarily variety velocity, and is unlimited by the dip. In the paper, RTM is employed to process the data, and the exciting time image condition is used with it, and the parallel Message Passing Interface (MPI) is employed to speed up the migration running speed. The result which is produced by RTM is compared with the kirchhoff pre-stack depth migration result, and it can be seen that RTM's result is better than kirchhoff pre-stack depth migration, RTM is a high precision migration method.
