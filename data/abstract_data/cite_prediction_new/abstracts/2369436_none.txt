Investigation on single phase ac-ac dynamic voltage restorer towards mitigate voltage sag
This paper presents an investigation on a single phase Dynamic Voltage Restorer (DVR) topologies to mitigate voltage sag. Single Phase Matrix Converter (SPMC) is presented as a direct AC to AC converter replacing the Voltage Source Inverter (VSI) in a typical DVR system. A simulation was done using Matlab/Simulink software to observe the SPMC performance towards mitigating the voltage sag. Single line to ground fault was used to create the disturbance to the load and a Sinusoidal Pulse Width Modulation (SPWM) strategy was used as the switching technique to control the SPMC switches.
