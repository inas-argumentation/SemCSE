Wilson loops and anomalous dimensions in cascading theories
We use lightlike Wilson loops and the AdS Conformal Field Theory correspondence to compute the anomalous dimensions of twist-2 operators in the cascading [Klebanov-Strassler (KS)] theory. The computation amounts to find a minimal surface in the uv region of the KS background, which is described by the Klebanov-Tseytlin solution. The result is similar to the one for $\mathrm{SU}(N)\mathcal{N}=4$ Super Yang-Mills theory but with N replaced by an effective, scale-dependent N. We performed also a calculation using a rotating string and find agreement. In fact, we use a double Wick rotated version of the rotating string solution which is a Euclidean world-sheet ending on a lightlike line in the boundary. It gives the same result as the rotating string for the $\mathcal{N}=4$ case, but it is more appropriate than the rotating string in the $\mathcal{N}=1$ case.
