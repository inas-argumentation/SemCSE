Optimal Imperfect Production Inventory Model under Joint Effect of Machine Breakdowns and System Reliability

Moreover, the machine repair time is stochastic and independent of the machine b reak-down rate. To make the research a more realistic one, a relation between reliabilit y parameter and machine breakdown parameter has been established so, that smaller val ue of reliability parameter indicates long run of production process, lesser imperfect it ems and negligible number of machine breakdown.
