A Secure Sketch for Set Reconciliation Soren Johnson Professor
In this paper we present an implementation of an algorithm for creating a secure sketch for the set difference as defined in [1]. This sketch is a short, efficiently computable description of a set such that, given a second set that differs only in a small percentage of elements, the original can be reconstructed. However, this sketch is secure in the sense that in the absence of such a similar set, as little information as possible can be obtained about the elements of the original. This work has applications in cryptography and database synchronization.
