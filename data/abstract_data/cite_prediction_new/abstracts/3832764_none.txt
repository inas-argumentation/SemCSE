Software performance analysis using a graphic modeling technique
Most performance analysis tools in existence today are closely associated with traditional programming languages. Hence a user cannot model a software system using a performance modeling technique directly. The authors consider this problem and describe a graphic modeling technique and a support tool (GPAS). GPAS can accept the model in a graphical form independent of any programming language and use it to evaluate the computation's performance. An example is used to show the feasibility of using this approach.<<ETX>>
