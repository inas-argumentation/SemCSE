Accelerometer and gyroscope measurements performed by module supported by graphical user interface
The article deals with design and description of a graphical user interface (GUI) which represents a support tool for accelerometer and gyroscope measurements. First of all, the GUI serves for data acquisition from realized module consisting of integrated accelerometer and gyroscope. From the acquired data, it is possible to calculate rotation angle of device or when it is needed, calibration of device or moving average filtering can be performed. Within the article there are described the algorithms serving for data acquisition, device calibration and data filtering using of moving average filter routine.
