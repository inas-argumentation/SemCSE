Deblending random seismic sources via independent component analysis
We consider the question of deblending for seismic shot records generated from simultaneous random sources at different locations, i.e., how to decompose them into isolated records involving one source at a time. As an example, seismic-while-drilling experiments use active drill-string sources and receivers to look around and ahead of the borehole, but these receivers also record noise from the operation of the drill bit. A conventional method for deblending is independent component analysis (ICA), which assumes a “cocktail-party” mixing model where each receiver records a linear combination of source signals assumed to be statistically independent, and where only one source can have a Gaussian distribution.
