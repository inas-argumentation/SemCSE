EVEN: A software environment for Estelle specification verification
This paper presents a software environment, EVEN (Estelle Verification Environment using NPNs), for the automatic verification of standard Estelle specification. EVEN, consisting of a number of tools, incorporates the state space caching and the sleep set methods to address the state space explosion problem. Lastly, the application of EVEN to verify the ISO ROSE protocol and its subsequent performance in terms of measures such as memory, time and number of states obtained are described in this paper. The advantages that EVEN has over other existing Estelle verification tools are: verification is based on standard Estelle; the dynamic behaviours of an Estelle specification can be handled; any deadlock uncovered is reported in a friendly Estelle format so that an Estelle user need not know how EVEN works; and a relief strategy to alleviate the state space problem is incorporated into the system.
