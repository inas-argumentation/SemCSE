Implementation of migrations from Class OPC to OPC UA for data acquisition system
OPC (OLE (object linking and embedding) for Process Control) UA (Unified Architecture) is a new standard for communication between automation systems and devices. Class OPC is widely used, but it is limited in some application areas. It is necessary that OPC UA is Compatible with the existing products. The migration strategies from Class OPC to OPC UA are introduced in the article. The paper focuses on the development of the OPC UA Wrapper for DA (Data Access) and the OPC UA Server that aggregates the diverse OPC UA Servers. OPC UA Client can supervise and control the diverse objects by the OPC UA Wrapper and the OPC UA Server through the Internet.
