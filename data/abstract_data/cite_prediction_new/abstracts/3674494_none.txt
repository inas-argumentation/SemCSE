Throughput of CDMA Data Networks With Reduced-Rank MMSE Receivers and Automatic Retransmission Request
Reduced-rank MMSE receivers have been proposed for CDMA communication systems recently. The output SINR, provided by a reduced-rank receiver depends on the filter rank and is confined between the SINRs of the single user matched filter (SUMF) and the minimum mean squared error (MMSE) receiver. The same remark is valid for the bit error rate (BER). In packet CDMA data networks like HSDPA, the measure of performance is the throughput. Thus, previous results on reduced-rank MMSE receivers SINR cannot be used directly. In this paper, we study the throughput of CDMA data networks using reduced-rank MMSE receivers, automatic retransmission request (ARQ) and packet combining. We study the effect of the filter rank on the throughput of the system.
