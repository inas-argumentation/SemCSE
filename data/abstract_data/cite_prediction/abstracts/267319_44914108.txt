Automatic Tuberculosis Screening Using Active contour segmentation using Chest Radiographs
Tuberculosis is a major health threat which causes high death of patients. Standard diagnostics of the tuberculosis still have some of the issues like slow and often unpredictable. So, in this paper proposes an automatic system for detecting the tuberculosis from the postero-anterior chest radiographs. Initially the lung region has been extracted by utilizing the lung nodule edge detection method. From the segmented region, the set of texture and shape features extracted which is classified as normal or abnormal tuberculosis using the binary classifier. During the segmentation of cavities is a challenging task in chest radiographs due to the presence of superimposed structures. It is important to accurately measure the extent of cavitation to measure temporal changes and response to therapy. A pixel classifier is trained using cavity border pixels based on Gaussian, location and Hessian features to construct a cavity wall likelihood map. A polar transformation of this likelihood map around the seed point is then used as a cost function to find an optimal border using dynamic programming. Then the performance of the proposed system is analyzed using 50 chest radiographs that contains the total 50 cavities. We achieve an area under the visualized curve (AUC) of 90% (88.3% accuracy) for the first set, and an AUC of 92% (90% accuracy) for the second set. For the first set, we compare our system performance with the performance of radiologists. When trying not to miss any positive cases, radiologists achieve an accuracy of about 92% on this set, and their false positive rate is about half of our system’s rate.
