A Cloud Computing Resource Allocation Model Based on Combinatorial Double Auction
As the rate of information growth intensifies, so has the study of cloud resource management because cloud computing can generate powerful online resource convergence. This paper presents a new cloud computing resource allocation model based on combinatorial double auction mechanism (CDA-CCRA) for more effective resource utilization. The CDA-CCRA model can simultaneously satisfy the requirements of users and providers and significantly reduce transactions. Simulations show that the CDA-CCRA model allocates resources well in a cloud computing environment.
