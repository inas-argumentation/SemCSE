A PROGRAMMING INTERFACE FOR MEDICAL DIAGNOSIS PREDICTION
The aim of this paper is to present a programming interface that can be used for assisting physicians in medical diagnosis. The interface provides an original diagnosis technique based on relational association rules and a supervised learning method. Using the designed interface, we made an experiment for cancer diagnosis; the precision of the diagnosis on our testing data was 90%. The main advantage of the proposed interface is that can be use in diagnosis for every disease, and, much more, can be simply extended, by adding new symptom types and new relations between symptoms for the given disease.
