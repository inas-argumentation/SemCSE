An Automated Biometric Attendance Management System with Dual Authentication Mechanism Based on Bluetooth and NFC Technologies
Attendance Management System (AMS) is the easiest way to keep track of attendance for community organisations for day-to-day monitoring o f attendance and manpower analysis. AMS comes in four types. These are Manual, Biometric, Card-based or E-Commerce systems. This paper presents the implementation of an AMS that is based on Bluetooth and NFC technologies in a multi-user environment. I uses fingerprint and the Bluetooth address of the N FC-enabled phone of the user to authenticate the id ntity of the user. A Java based desktop application recei ves the NFC tag IDs, other information associated w ith the mobile phone and the user and submits them to an a alyser for the interpretation of the user’s behavi our. Key Terms: Attendance Management System, Authenti cation, Biometric, Bluetooth, Mobile Phone, NFC.
