BaitBuster : Destined to Save You Some Clicks Md Main
The use of tempting headlines (clickbait) to allure readers has become a growing practice nowadays. The widespread use of clickbait risks the reader’s trust in media. According to a study performed by Facebook, 80% users “preferred headlines that helped them decide if they wanted to read the full article before they had to click through”. In this paper, we present a clickbait detection model which uses distributed subword embeddings and achieves an accuracy of 98.3%. Powered with the model, we build BaitBuster, a solution framework (social bot+browser extension), which not only detects clickbaits floating on the web but also provides brief explanation behind its action. Moreover, we study 1.67 million contents created by 153 media organizations and discover the relation between clickbait usage and media reliability.
