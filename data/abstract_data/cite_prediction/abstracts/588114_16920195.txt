Cluster Based Routing Protocols: A Comparative Study
Wireless Sensor Network is an infrastructure less network consisting of small, lightweight, low power, and inexpensive wireless sensor nodes which gather and propagate the environmental data. Different routing protocols have been proposed for wireless sensor networks for efficient routing. Each protocol has its own way of routing which vary from each other in terms of the parameters selected or the approach. Cluster based routing is one of the famous routing approaches in which the head node gathers data from all other nodes in the cluster, performs certain aggregation function and then sends that aggregated data to the base station. In this paper i will present the comparative study of few cluster based routing protocols.
