Query processing for header dictionary triple using GPUs
Resource Description Framework (RDF) is popular format used in semantic web. Its data size is increasingly large; thus query such data is very time consuming. This paper presents an approach for RDF query processing using Graphics Processing Unit (GPU). The data is first transformed in Header Dictionary Triples (HDT) format to compact its size. Next, the representation of HDT is again transformed so that the data can be transferred into GPU memory. A proper triple search method is done by concurrent threads using Compute Unified Device Architecture (CUDA) framework with Jcuda. In the experiments, we compare the total search time to process the queries with GPU and CPU considering UNION, INTERSECTION, and JOIN. The speedup can be upto 267 times using GTX 750 depending on the type of queries and number of query results.
