Variational graph auto-encoder using triplets of nodes for preserving proximity
In this paper, we present a scalable approach for unsupervised learning on graph-structured data that is based on variational auto-encoder. Most previous unsupervised methods for graph representation only consider the reconstruction errors. To train our model, we add different nodes of triplets as input, where one triplet consists of a given reference node <i>v<sub>r</sub></i>, a positive node <i>v<sub>p</sub></i> which is a adjacent node of <i>v<sub>r</sub></i>, and a negative node <i>v<sub>n</sub></i> which is a long-distance node of <i>v<sub>r</sub></i>. Then, we adopt triplet-based loss function that minimize the reconstruction errors and minimize the distance between <i>v<sub>r</sub></i> and <i>v<sub>p</sub></i> than the distance between <i>v<sub>r</sub></i> and <i>v<sub>n</sub></i>. The method captures the relationships between nodes and complex features of a graph by exploiting the variational auto-encoder while still preserves both structure and text information. Experimental results in three real-world citation data show that our approach outperforms the top competitors in link prediction.
