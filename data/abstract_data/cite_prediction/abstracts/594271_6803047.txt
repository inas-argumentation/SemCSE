Automatic Number Plate Recognition ( ANPR )
The Automatic Number Plate Recognition is a system which is designed to help in recognition of number plates of vehicle. The purpose of designing this system is to develop security system. This system performs the various functions like number plate detection of vehicles, then processing them and using the processed data for storing and allows the vehicle to enter or reject the vehicle. This system is based upon the image processing technology which involves the number of image processing algorithm. The objective of this ANPR system is to design an efficient automatic vehicle number plate and used the system for various application like Toll collection, Parking System, border crossing, traffic control, stolen cars, etc.The ANPR system consist of mainly four stages to implement the system which are Image acquisition, Number plate extraction, Number plate segmentation and Character recognition. In this paper we consider the system only for Indian vehicle condition where number plate standard are rarely followed.
