Characterization of log periodic planar dipole array antenna
This paper proposes a analysis approach for characterizing the broadband Log Periodic Planar Dipole Array (LPPDA) antenna useful for C-band applications. A simplest geometry of the edge fed Log Periodic Planar Dipole Array is designed and developed. Parameters like length, width of the elements, and spacing between elements are the varied using defined scale factor (τ) and a spacing factor (σ), keeping others constant and their impact was noted down. A parametric analysis is performed. using CST software. A transmission line equivalent circuit of the proposed LPPDA is constructed. Log periodicity behaviour of the proposed antenna is checked by plotting input impedance with respect to logarithm of frequency. An antenna is fabricated and measured in laboratory.
