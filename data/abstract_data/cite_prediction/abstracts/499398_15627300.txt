Confidentiality Issues on a GPU in a Virtualized Environment
Professor Patrick Cousot Principles of Software Security Fall 2015 Summary: Confidentiality Issues on a GPU in a Virtualized Environment 1 “Confidentiality Issues on a GPU in a Virtualized Environment” presents a discussion of the security implications of General-Purpose computing on Graphics Processing Units (GPGPU). Because of the inherent parallelisms of Graphics Processing Units (GPUs), they have become popular for general-purpose computing that relies heavily on parallel computations. Common applications of GPGPU include financial applications, encryption, and Bitcoin mining; GPUs use hundreds to thousands of cores to accelerate parallel computing tasks. Recently, GPUs have been offered by cloud computing providers in order to supply on demand use of hardware that would otherwise be very expensive. While GPUs have been designed for maximum performance, they have not been designed for concurrent accesses that arise frequently in GPGPU applications. GPU buffers are not zeroed when allocated, and this creates confidentiality issues both between different programs and between different users. In a cloud environment, the attack surface becomes even larger because several users can exploit the same GPU either sequentially or simultaneously. To understand the risks associated with GPGPU applications, we should first review the basics of GPUs. GPUs have hundreds of cores, each of which can handle hundreds of threads.
