PUBLIC-KEY STEGANOGRAPHY BASED ON MODIFIED LSB METHOD
Steganography is the art and science of invisible communication. It is a technique which keeps the existence of the message secret. This paper proposed a technique to implement steganogaraphy and cryptography together to hide the data into an image. This technique describes as: Find the shared stego-key between the two communication parties by applying Diffie-Hellman Key exchange protocol, then encrypt the data using secret stego-key and then select the pixels by encryption process with the help of same secret stegokey to hide the data. Each selected pixel will be used to hide 8 bits of data by using LSB method.
