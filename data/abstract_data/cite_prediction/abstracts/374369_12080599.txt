Cache-oblivious shortest paths in graphs using buffer heap
We present the <i>Buffer Heap</i> (<i>BH</i>), a cache-oblivious priority queue that supports <i>Delete-Min</i>, <i>Delete</i>, and <i>Decrease-Key</i> operations in <i>O</i>(1over<i>B</i> log<inf>2</inf> <i>N</i>over<i>B</i>) amortized block transfers from external memory, where <i>B</i> is the (unknown) block-size and <i>N</i> is the maximum number of elements in the queue. As is common in cache-oblivious algorithms, we assume a 'tall cache' (i.e., <i>M</i> = Ω(<i>B</i><sup>1 + ε</sup>), where <i>M</i> is the size of the main memory). We also assume the Decrease-Key operation only verifies that the element does not exist in the priority queue with a smaller key value, hence it also supports the insert operation in the same amortized bound. The amortized time bound for each operation is <i>O</i>(log <i>N</i>). We also present a <i>Cache-Oblivious Tournament Tree (COTT)</i>, which is simpler than the Buffer Heap, but has weaker bounds.Using the Buffer Heap we present cache-oblivious algorithms for undirected and directed single-source shortest path (SSSP) problems for graphs with non-negative edge-weights. On a graph with <i>V</i> vertices and <i>E</i> edges, our algorithm for the undirected case performs <i>O</i>(<i>V</i> + <i>E</i>over<i>B</i> log<inf>2</inf> <i>V</i>over<i>B</i>) block transfers and for the directed case performs <i>O</i>((<i>V</i> + <i>E</i>over<i>B</i>) . log<inf>2</inf> <i>V</i>over<i>B</i>) block transfers. The running time of both algorithms is <i>O</i>((<i>V</i> + <i>E</i>). log <i>V</i>).For both priority queues with <i>Decrease-Key</i> operation, and for shortest path problems on general graphs, our results appear to give the first non-trivial cache-oblivious bounds.
