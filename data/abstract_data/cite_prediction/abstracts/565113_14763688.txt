Smart phone based robotic arm control using raspberry pi, android and Wi-Fi
This paper proposes a method for controlling a Robotic arm using an application build in the android platform. The android phone and raspberry piboard is connected through Wi-Fi. As the name suggests the robotic arm is designed as it performs the same activity as a human hand works. A signal is generated from the android app which will be received by the raspberry pi board and the robotic arm works according to the predefined program. The android application is the command centre of the robotic arm. The program is written in the python language in the raspberry board. the different data will control the arm rotation.
