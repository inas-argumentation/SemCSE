Application of Arabic language processing in language learning
Natural Language Processing (NLP) provides several solutions that can refine the language learning. Nowadays, Arabic Language Processing (ALP) has become the focus of many researchers and developers. Further, the amount of ALP tools and applications has grown significantly over the last years. The integration of these tools will result in positive outcomes in interactive programs for learning the Arabic language. The purpose of this work is to base on effective tools for providing assistance in language learning system. This paper highlights how ALP tools can be used to enhance the process of language education. Further, it describes some of ALP tools to present propositions that could guide current and future practitioners in the field of Arabic language learning. Finally, we shed the light on an ongoing project of developing an effective interactive system for Arabic learning.
