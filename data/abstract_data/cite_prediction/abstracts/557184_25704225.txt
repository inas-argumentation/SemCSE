Remotely controlled autonomous robot using Android application
The present practices parents are not able to give that much time for babies. This paper proposes a method for remotely controlling a robot using android application. WIFI is used as communication medium between robot and smart phone with android application. The purpose of this paper is to make smart robot as a toy, such that parents can handle a robot from remote place. With this robot they can view son from the remote place through camera and also send him voice message from the android application. It also has motion detection wherein it does not crash against any object. Raspberry Pi 3 is heart of the system, overall controlling of robot is fully depends on RPI 3. It has inbuilt WIFI and Bluetooth connectivity.
