Task scheduling in Cloud Using Hybrid Cuckoo Algorithm
Cloud computing is used for delivering and managing the services over the internet. Cloud computing provides data access and storage devices without the knowledge of the physical location of the end user. Cloud computing has three types of services: software as a service (SaaS), platform as a service (PaaS) and infrastructure as a service (IaaS). Task scheduling is the main issue in cloud computing and it is very important part of cloud computing. Various types of algorithms are used for scheduling for example FIFO, Genetic algorithm, round robin algorithm etc. This paper is focused on the optimization solution for the task scheduling using hybrid cuckoo algorithm. This algorithm combines the results of genetic algorithm and cuckoo search algorithm. Index Terms – Cloud computing, Task scheduling, Genetic algorithm, Cuckoo algorithm, Hybrid cuckoo algorithm.
