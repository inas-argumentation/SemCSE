Support Vector Machine Based Fingerprint Identification
This work is released in biometric field and has as goal, development of a full automatic fingerprint identification system based on support vector machine. Promising Results of first experiences pushed us to develop codification and recognition algorithms which are specifically associated to this system. In this context, works were consecrated on algorithm developing of the original image processing, minutiae and singular points localization; Gabor filters coding and testing these algorithms on well known databases which are: FVC2004 databases & FingerCell database. Performance Evaluating has proved that SVM achieved a good recognition rate in comparing with results obtained using a classic neural network RBF. Keywords—Biometry, Core and Delta points Detection, Gabor filters coding, Image processing and Support vector machine.
