Behavioral Analysis of Docker Swarm Under DoS/ DDoS Attack
In recent time, a lot of talks is going about Docker an open source application containerization technology for building, shipping, and running applications. Docker when compared to other technologies has the ability to simplify the things that would previously require a lot of efforts. Due to this simplification, the time and cost of deploying and managing services have reduced tremendously. When we further talk about the Docker, one of its prime features which come to mind is the concept of Docker Swarm, a native clustering solution for Docker. This swarm clustering concept has over shattered the old and out-dated computer clustering techniques. Now, when we look into this paper, it totally talks about Docker Swarm from building a swarm cluster to managing the tasks. At last, this paper shows the behavioral analysis of Docker Swarm under DoS/ DDoS attack. This analysis has been done at two levels first at the node level and second at the cluster level and based on the analysis conclusion have been drawn.
