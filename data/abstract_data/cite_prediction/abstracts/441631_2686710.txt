Low-Level Library Analysis and Summarization
Programs typically make extensive use of libraries, includ ing ynamically linked libraries, which are often not available in source-code for m, and hence not analyzable by tools that work at source level (i.e., that analyze intermed iat representations created from source code). A common approach is to write library modelsby hand. A library model is a collection of function stubs and variable declarations tha t capture some aspect of the library code’s behavior. Because these are hand-crafted, they are l ikely to contain errors, which may cause an analysis to return incorrect results. This paper presents a method to construct summary informati on for a library function automatically by analyzing its low-level implementation ( i.e., the library’s binary).
