Generation and analysis of tactics for anti-torpedo defense system
Anti Torpedo Defense System (ATDS) is a very vast system with infinite geometrics and corresponding Tactical Solutions. Also, a few geometries do exist, where the Tactical Solution can never be arrived optimally. The Purpose of the system is to analyze the generated Tactical Solution which enhance the ships survivability against enemy Torpedo using the Optimal decoy deployment logic and maximizing the engagement time by computing Time of Initial deployment and time Lag between successive deployments of the decoys. The Ultimate solution is to make the own platform survive against incoming threat by administering necessary decoys and maneuvers as decided by the Tactics Algorithm. The main aim of this paper is to analyze the developed system with various geometries and illustrate the performance analysis of the system. Also we develop an ODE solver which improves the ship engagement time.
