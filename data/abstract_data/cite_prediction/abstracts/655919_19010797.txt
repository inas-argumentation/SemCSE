Core Techniques of Ontology-Based Question Answering Systems : a Survey
The Semantic Web contains an enormous amount of information in the form of ontologies. To make this information available, many ontology-based question answering (QA) systems were created in the last years. Building a QA system is difficult since many different challenges have to be solved. To address these challenges, QA systems generally combine techniques from natural language processing, machine learning and Semantic Web. The aim of this survey is to give an overview over the techniques used in current QA systems. We present the techniques used by the QA systems which were evaluated on a popular series of benchmarks: Question Answering over Linked Data (QALD). These techniques are presented in a novel way: techniques that solve the same task are first grouped together and then described. For each technique advantages and disadvantages are discussed. This allows a direct comparison of similar techniques. We conclude that there is a need for a framework to interweave current approaches.
