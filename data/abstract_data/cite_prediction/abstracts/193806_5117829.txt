A Police Big Data Analytics Platform: Framework and Implications
Police big data analytics is a hot issue. This paper designs a police big data analytics platform aiming to efficiently analyze and utilize police big data. This platform is based on the key technologies of big data analytics and has a four-layer structure: data acquisition, data storage, processing analytics and application service. Furthermore, this paper presents usage scenarios, application cases and platform construction strategies by considering the actualities of police work. Overall, this paper provides an insight into big data analytics for police.
