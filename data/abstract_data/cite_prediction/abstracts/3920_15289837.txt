Generative probabilistic models for multimedia retrieval: query generation against document generation
This paper presents the use of generative probabilistic models for multimedia retrieval. We estimate Gaussian mixture models to describe the visual content of images (or video) and explore different ways of using them for retrieval. We consider so-called query generation (how likely is the query given the document model) and document generation (how likely is the document given the query model) approaches and explain how both fit in a common probabilistic framework. We show that query generation is theoretically superior, and confirm this experimentally on the Trecvid search task. However, we found that in some cases a document generation approach gives better results. Especially in the cases where queries are narrow and visual results are combined with textual results, the document generation approach seems to be better at setting a visual context than the query generation variant. 1This is an extended and revised version of a previous conference paper [1].
