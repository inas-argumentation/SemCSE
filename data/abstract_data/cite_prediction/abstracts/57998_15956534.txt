Concatenated coded OFDM system over AWGN channel with H.264 source coding
This paper presents a robust concatenated coding scheme for OFDM with 64 QAM over AWGN channel. At the forward error correction unit, our proposed concatenated coding scheme employs standard form of BCH code as outer code and LDPC code as inner code. Varying from the code rates of BCH codes, we can find the minimum requirement of signal to noise ratio in the proposed concatenated coding scheme. In addition, our proposed scheme can yield better performance than that using BCH (7200, 7032) code in ETSI EN 302 775. Finally, we apply the H.264 source coding via our platform for demonstrations.
