An improved PageRank algorithm to handle polysemous queries
With advances in Internet technology, the web structure has become complex, and it has become impossible for search engines to provide a user the relevant information from the web without the use of web mining techniques. In response to a query from the user, the webpages are ranked and listed based on their importance and relevance with respect to the query. Web structure mining is used to analyze the hyperlink structure of the web to determine the importance of webpages. Web Content Mining is used to analyze the content of a webpage with respect to the query. Though many algorithms have been introduced employing both of these methods, not much focus has been laid on how a content should be analyzed in response to a query which contains one or more terms with different meanings/senses. Through the paper, we propose a technique to rank the pages in order of relevance for such queries.
