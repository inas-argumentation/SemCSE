Adaptive breaker failure protection scheme for double busbar substation using IEC 61850 GOOSE message communication
IEC 61850 Standard of Substation Network and Communication System is an open standard which introduced the Ethernet based communication for the information exchange between protection and control devices in substation. There is several communication services such as client-server communication, server-to-server communication named Generic Object Oriented Substation Event (GOOSE)/ Generic Substation Status Event (GSSE) message and sampled value communication service for the current and voltage measurement transmission. By adopting IEC 61850 communication services, the architecture of the substation information or signals exchange can be simplified by transforming the multiple copper based wiring into single Ethernet cable which can transmit multiple signals. Besides that, the GOOSE message deployment for the scheme input and output signals will reduce the physical wiring that can offer flexibility in the substation expansion and modification project through software based engineering tools process. Based on the advantages of the standard which can be gained for the protection and control scheme implementation, this paper will highlight the design of the adaptive breaker failure protection scheme using IEC 61850 GOOSE message for the busbar intertrip signal transmission and the IEC 61850 engineering process.
