Performance Analysis of Virtual Machine Introspection Tools in Cloud Environment
Virtual Machine (VM) security is one of the biggest issues with a cloud environment. This issue could be solved with the help of Virtual Machine Introspection (VMI) tools. VMI tools monitor the state of Virtual machine running in the cloud environment. VMI tools extract state of a virtual machine without the consent of the guest system. These VMI tools are built with the help of hardware virtualization functionality provided by Intel and AMD processors. These VMI tools facilitate the cloud providers to secure their virtual machines against attacks by observing the state of the VM. In this paper, we mainly discuss and analyze the five different VMI tools, their architecture, their key problems and performance analysis of these tools when adopted in the cloud environment.
