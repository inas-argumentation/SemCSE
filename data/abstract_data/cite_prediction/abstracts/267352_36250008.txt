Real-time simulation of hybrid microgrid for islanding detection analysis
This paper investigates passive islanding detection methods in hybrid microgrid having both rotating machine and converter-based distributed energy units (DEUs). The converter control schemes of distributed energy units are simulated using Real Time Digital Simulator (RTDS). Frequency, voltage, phase jump detection and active power based passive islanding techniques are analyzed and compared with sequence component based techniques to improve the accuracy during power imbalance situations. A hybrid micro grid system is simulated using Real Time Digital Simulator (RTDS). Several test cases are generated to examine the performance of the passive islanding detection methods.
