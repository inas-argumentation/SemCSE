CadentFlow : An Application-Driven Network Abstraction for the Cloud
Cloud applications typically have a set of correlated flows between stages of computation. The coflow abstraction, which takes into account this structure, helps improve the performance by enabling collective optimization on the set of related flows. However, an application may have implicit preferences among component flows which is not captured by the coflow abstraction. A network controller unaware of these inter-flow preferences may make sub-optimal decisions. In this paper, we put forward a new abstraction, CadentFlow, with per-flow metrics and an optimization objective, to capture the application requirements effectively. Using distributed deep learning as a representative application, we show that minimizing the Coflow Completion Time (CCT) does not always lower application completion time, and may even hurt performance. Compared to CCT minimization, application performance can be improved by up to 25% during training in distributed deep learning using flow-level information provided by CadentFlow. We discuss the implications of this abstraction in network scheduling and application design.
