An implementation of private cloud's service model (IaaS) using lightweight virtualization
The interest on traditional technologies is decreasing with the increasing demand on new technologies. The world of cloud market is changing with emergence of new technologies. In this paper we used a new virtualization method known as lightweight virtualization or containerization for the implementation of Infrastructure as a Service (IaaS) in private cloud rather than traditional hypervisor approach because in containerization bootup time of VMs is in seconds, Size is in Mb's and have negligible CPU overhead. Cloud providers have already used this approach for making PaaS and SaaS but not IaaS. With this implementation network administrator/ System Administrator may get ready to think for the deployment of their hypervisor based cloud to Container based cloud.
