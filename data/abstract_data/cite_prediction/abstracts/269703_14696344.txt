A Passive RFID Information Grid for Location and Proximity Sensing for the Blind User
We describe a navigation and location determination system for the blind using an RFID tag grid. Each RFID tag is programmed upon installation with spatial coordinates and information describing the surroundings. This allows for a self-describing, localized information system with no dependency on a centralized database or wireless infrastructure for communications. The system could be integrated into building code requirements as part of ADA (Americans with Disabilities Act) at a cost of less than $1 per square foot. With an established RFID grid infrastructure blind children and adults will gain the independence and freedom to explore and participate in activities without external assistance. An established RFID grid infrastructure will also enable advances in robotics which will benefit from knowing precise location. In this paper, we present an RFID based information grid system with a reader integrated into the user’s shoe, which is connected to the user PDA or cell phone via a Bluetooth. An emphasis is placed on the architecture and design to allow for a truly integrated pervasive environment.
