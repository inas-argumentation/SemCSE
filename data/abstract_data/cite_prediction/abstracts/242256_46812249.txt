Smart bag tracking and alert system using RFID
The problem with deployed bag tracking system lies in the fact that the procedure is too much human dependent. This leads to a high error rates, thus resulting in misplaced bags and misrouted deliveries. A trivial solution to this would be automating the process that goes into transporting a bag from point A to point B cost-effectively and accurately while giving the users a real-time feedback and location update. Our solution exploits the Radio Frequency Identification (RFID) technology which uses electromagnetic fields to automatically identify and track tags attached to objects thus reducing human labour as well as error rates. RFID is a low power consuming technology. We have made use of reusable passive RFID tags for the postal service. Every postal node (post offices), is equipped with RFID reader which is coupled to a micro-controller which syncs its data to our backend system. The backend processes the data and displays the same to the respective persons as well as to the respective authority. The system also determines the most cost optimized path — calculated before the parcel is dispatched and updates itself according to the accident points. Our solution makes use of the RFID solution to track the booked parcel bags. As a baggage is sealed, it is allotted with a RFID tag and tracking ID generated using RFID tag, Date and time stamp. There is a feedback mechanism to check if the parcel has reached the desired destination. This technology tracks out the accident points and hence necessary actions can be taken at those points. This makes the whole system automated and reduces error to a great extent.
