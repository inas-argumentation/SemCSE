A NOVEL FUZZY ASSOCIATION RULE MINING METHOD USING UNSUPERVISED FUZZY CLUSTERING METHOD FOR PRE-PROCESSING
A new approach is presented for effectively mining fuzzy association rules (ARs). Association rule mining is an important research area in today’s scenario. It finds interesting associations among a large set of data items. Aproiri algorithm is commonly used algorithm to find association rules for single dimensional database but if the database is too large it generates a lot of candidate sets, it is not efficient for large databases. For finding the association rules for large multidimensional database or quantitative database some extension is required in existing Aproiri algorithm. Fuzzy clustering is an efficient modeling technique which can be used for segmenting quantitative values into fuzzy sets. But the conventional fuzzy clustering techniques like c-means need the user to specify the number of clusters and initial cluster centers. A novel approach to fuzzy based cluster estimation algorithm is used to segment quantitative values into fuzzy clusters. Instead of intervals, these segments can be later used with rule mining algorithms to form association rules. In each Cluster the authors have reduced set of data. After finding the clusters, apply the Apriori in each cluster for mining association rules Keywords— Association Rule Mining, Apriori, Clustering, Fuzzy C Means
