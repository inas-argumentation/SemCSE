A Hybrid Model of Wavelet and Neural Network for Short Term Load Forecasting
Electric load forecasting is a key to the efficient management of power supply system. Load forecasting, which involves estimation of future load according to the previous load data. This paper presents a pragmatic methodology for short term load forecasting (STLF) using proposed hybrid method of wavelet transform (WT) and artificial neural network (ANN). It is a two stage prediction system which involves wavelet decomposition of input data at the first stage and the decomposed data with other input is trained using separate neural network to forecast the load. The forecasted load is obtained by reconstruction of the decomposed data. The hybrid model has been trained and validated using load data from Australia electricity market.
