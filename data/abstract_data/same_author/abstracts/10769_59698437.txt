The CERN/SL XDataviewer: An Interactive Graphical Tool for Data Visualization and Editing
As a result of many years of successive refinements, the CERN/SL Xdataviewer tool has reached its final stage. This graphical tool was especially developed to plot monoor bi-dimensional arrays of data, and to interact with them, in many different ways. Many pages of graphical information can be handled by the program, in a loose hierarchy of Views, Graphs and Plots objects. Data can be displayed, and interacted with, both in graphical and in text format. Sophisticated built-in Zoom and Data Editing capability is implemented, as well as a flexible Data Output generation facility. A complete C Callable Interface is provided, including a mechanism for feeding back the Application Program with the selections made by the User in the Data Display part. The tool has been written in C language, making use of the standard X Window libraries (Xlib,Xt,Motif). It can be run as a stand alone process, communicating with the Application Program via a shared memory, or it can be embedded in the Application Program itself.
