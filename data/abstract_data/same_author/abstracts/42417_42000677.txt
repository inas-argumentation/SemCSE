Real-Time Database Benchmark Design for Avionics Systems
Traditionally, database systems have been developed for data processing applications. With the development of CAD/CAM applications, object-oriented databases have been shown to be more flexible and effective in providing the kind of performance more adequate for CAD users. Recently, as a result of the rapid growth in embedded and autonomous systems applications, many database applications are moving toward the real-time domain that is defined by high data access and/or transaction execution rates as well as stringent timing constraints. These real-time characteristics require databases to have special capabilities to handle time-critical transactions. Some examples are databases for safety-critical applications like air traffic control, avionics systems, process control, and medical service systems.
