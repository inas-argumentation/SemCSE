Resource Usage Policy Specification for Managing Application Resources
Specification and enforcement of resource usage policies of applications is an important problem in different areas of Computer Science such as in Grid Computing and execution of mobile code on language-based virtual machines such as JVM. In this paper we survey existing approaches to resource management; identify some of the key requirements of a language to specify resource usage policies and propose a new language to enforce resource usage policies. We give examples on how the language can be used to specify different types of resource usage policies.
