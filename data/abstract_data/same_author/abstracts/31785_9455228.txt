Software design for a database driven system for accelerator magnet measurements
Measurements of more than 1000 new magnets are needed for the main injector project at Fermilab. In order to achieve efficiency and accuracy in measurements, a database-driven design was chosen for control of the measurement system. A relational database will be used to describe the measurement subjects and equipment. A logbook system defined in the database will provide for prescription of measurements to be carried out, and a comment database for less-structured information. The operator interface will be built on X-windows.<<ETX>>
