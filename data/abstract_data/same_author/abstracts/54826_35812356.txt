A Study of How Domain Knowledge Improves Knowledge-Based Learning Systems
Abstract A knowledge-based learning system is developed to demonstrate that intelligently selecting a subset of examples based on domain knowledge for rule induction can be more productive than using all provided examples. Knowledge-based learning uses an incomplete domain theory and examples to induce knowledge missing in the theory. Knowledge-based learning systems determine where knowledge is missing in a domain theory, select a relevant subset of examples to use in induction, and induce new rules or modify existing rules.
