An object-oriented distributed system integrating multimedia resources
A distributed system is introduced which provides extensible as well as integrated environments for users and applications programs to access and combine distributed resources conveniently. The system is based on the concept of object-oriented service bases. Distributed resources are abstracted as objects containing the metainformation of the resources. A service base in each node is constructed to manage these objects. There are three layered views (external, conceptual, and internal) of objects. A service base can be seen as a software package built on an existing operating system to provide mapping from the external view of objects to the internal view to realize transparency and to absorb heterogeneity and different media types. The modeling and an implementation of this distributed system are presented.<<ETX>>
