Image Smoothing Using Parametric Relaxation
Abstract A new image-smoothing algorithm which smooths the image while preserving discontinuities is developed. The method poses the smoothing problem as an estimation problem of the maximum a posteriori probability of a pixel having a certain gray level. A prior probability density function is assigned to each pixel from the raw data, which is an estimate of the gray-level uncertainty. The algorithm is an application of the random measure field in image processing. Contextual information from neighbors is used in refining the probability distribution of each pixel, which is a continuous version of the relaxation algorithm. The way of parametrizing the probability functions enables the derivation of an efficient iterative formula for updating the gray-level values.
