Probing electroweak penguins through B^0(t) -> K_S K_S K_S
We examine the recently observed decay mode B^0 -> K_S K_S K_S, which like B^0 -> phi K_S, is a pure penguin decay in the Standard Model. A time dependent CP asymmetry in this mode can also reveal new physics contributions to b -> s penguins, if present. We show that this decay mode is even more special than previously realized, as within the Standard Model it can only be produced via the Delta I=1, b -> s bar{d} d electroweak penguins. Unlike B -> phi K_S, this mode cannot receive contributions from gluonic penguins, nor can it be produced via rescattering of final states obtained from tree diagrams. Experimental data (though not yet statistically convincing), seems to hint towards the presence of new physics contributions to b -> s electroweak penguins. The B^0 -> K_S K_S K_S mode, being theoretically extremely clean, will provide unambiguous signals of isospin violating ``electroweak penguin'' contributions from physics beyond the Standard Model.
