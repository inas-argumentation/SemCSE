A New Routing Algorithm for Cyclic Shifts on BRGC Hypercubes
The hypercube is one of the most efficient networks for parallel computation. It can efficiently simulate any other network of the same size. In particular, the N-node hypercube can simulate any O(N)-node array, binary tree, or mesh of trees with only a small constant factor slowdown [3]. Furthermore, it is completely symmetric and decomposable into sub-hypercubes. These properties, in addition to its simplicity, make it be an excellent and popular architecture for distributed memory parallel computers. Arrays are natural (data or process) structures for many applications. They can be embedded onto hypercube nodes either in natural order or in Binary-Reflected Gray Code (BRGC) order. It has been noted [2] that many algorithms use the cyclic shift (or rotation) in a natural way as a primitive step. Hence, efficient implementation of cyclic shifts on hypercube network is vita1 to the performance of hypercube computers. Cyclic shift algorithms for the natural order embedding have been studied in [51 and those for the BRGC embedding have been studied in [2,4]. The BRGC embedding has the property that any two adjacent numbers are mapped to neighboring nodes that can communicate directly through a link. Therefore, it uses only one link to route a message from any node to its sink node when the shift distance is one. In this case, it is superior to the natural order embedding. The existing cyclic shift algorithms for the BRGC embedding usually route a message by correcting successive bits that differ in source and sink nodes from the less significant end to the more significant end or in the other order with some exceptions. However, all the algorithms have their drawbacks. For example, the two algorithms presented by Johnsson [2] are neither link-disjoint. Thus, two routing paths will contend for the same link. This not only implies the need for local buffering to route the conflicting messages but also leads to the slowdown of the performance. The best disjoint link algorithm in the literature is the one proposed by Ouyang and Palem [4], which in the worst case uses $fi links to route a message from any node to its cyclic shifted sink node on an n-dimensional BRGC hypercube. There also have been many researches on the problem of general permutation routing [ll, but their algorithms are all asymptotically efficient and are not suitable for the cyclic shift problem. In this paper, we propose a new routing algorithm for cyclic shifts on BRGC hypercubes based on the divide-and-conquer approach instead of the usual one.
