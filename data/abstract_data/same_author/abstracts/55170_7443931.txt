Limitation of superscalar microprocessor performance
Today’s microprocessors are striving to get the highest possible performance. A new breed of microprocessors called superscalar which execute multiple instructions per clock cycle. The major problem of executing multiple instructions in a scalar program is the handling of data dependencies. If data dependencies are not effectively handled, it is difficult to achieve an execution rate of more than one instruction per clock cycle. In this study, we use a novel multi-bit control for handling of data dependencies for out-of-order execution and completion of instructions. This paper presents the maximum performance of the superscalar microprocessor using two simulation models and one calculation model. The first simulation model uses real benchmark programs, and the second model uses queuing networks. The calculation model derives the formula for deficiencies from the peak performance.
