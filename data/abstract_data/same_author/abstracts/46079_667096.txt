The string-matching problem is defined as follows [6]: Given a character string x, called the pattern, and a character string y, called the text, determine if x is a subword of y. It is well known that the string-matching problem is of great importance in practice, for example, the ``grep'' function in UNIX. Since the invention of the linear-time algorithms of [2, 3, 8], there have been constant efforts to find linear-time algorithms which use less space. See, e.g. [1]. The best theoretical result is in [6], where it was shown that string-matching can be performed by a six-head two-way deterministic finite automaton in linear time.
