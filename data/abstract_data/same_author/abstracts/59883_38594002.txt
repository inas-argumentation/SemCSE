Using String Languages to Describe Picture Languages
A picture is a set of unit lines from the Cartesian plane considered as a square grid. A word over the alphabet l, r, u, d is a picture description in the sense that it represents a traversal of a picture where the interpretation of the symbols l, r, u, d, is: l go one unit line to the left of the current point r go one unit line to the right of the current point u go one unit line up from the current point, and d go one unit line down from the current point. A set of picture descriptions forms a picture description language . This paper investigates the basic properties of pictures and picture description languages from the formal language theory point of view.
