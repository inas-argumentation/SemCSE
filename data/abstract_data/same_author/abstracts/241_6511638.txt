Research on visualization techniques for web usability analysis
A main method to analyze the usability of web site is observing and analyzing users' action, collecting the relevant data. Yet the huge amount data make it difficult to find problems. This paper introduces web usability firstly, and then discusses visualization techniques for web. According to the need of website usability analysis, we developed a assistant tool named SUAT to help the usability experts finding usability problems. Using this tool I carried out a research based on a lot of websites and selected many users randomly to confirm the effect. The result shows that using SUAT can help usability expert effectively find the usability problems that are prone to be overlooked otherwise, what's more it can improve the efficiency and make the judgment more accurate.
