Isospin decomposition of nuclear multipole matrix elements from. gamma. decay rates of mirror transitions: Test of values obtained with hadronic probes
The electromagnetic decay rates of mirror states are used to decompose the multipole electromagnetic matrix elements into isoscalar and isovector or equivalently proton and neutron matrix elements. This method is sensitive to the neutron matrix element because it is measured directly, and it is accurate since it depends only on electromagnetic interactions; it therefore can be used to test methods using inelastic hadron scattering. There is agreement with the results for (..cap alpha..,..cap alpha..') on /sup 26/Mg and /sup 42/Ca but disagreement with the recent /sup 18/O(..pi..,..pi..') experiments.
