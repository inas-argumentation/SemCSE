Computer Aided Operation on SPring-8 LINAC Control System
As for an accelerator in today, a highly e‐cient control system is demanded. The SPring-8 LINAC is also managed and operated with VME computers and an EWS. The operator of LINAC search the best parameter for getting optimum performance on the electron beam. Once, one of the best parameter has found, they can save all parameters. And using it next time, they can reproduce the beam performance quickly. However, they waste long time doing parameter searching. Because, the relationship of each parameter is very complex. If automatic parameter searching is able to do on the system, they can get a more comfortable operation and response. In this case, we designed the computer aided operations using our control system. Firstly, we try to produce the automatic RF conditioning on the system. In this paper, the status of the system and the concept of computer aided machine operation are described.
