Mesons and baryons from QCD
Abstract We study a gauge covariant method for quark bound states in 3 + 1 dimensions, based on a stationary phase approximation of the gluon path integral. Assuming thet lim | x |→∞ F μν a ( x ) F a μν ( x ) ≠ 0 we find meson (q q ) and baryon (qqq) states bound by a Coulomb + linear potential. The quark wave function is confined, as in the bag model. The high-spin states lie on asymptotically linear Regge trajectories of universal slope.
