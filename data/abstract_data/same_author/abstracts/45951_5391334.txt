Sequence homology detection through large scale pattern discovery
Extended Abstract We describe a new approach for idenhifling sequence similatity between a query sequence and a data base of proteins. The central idea is the use of a set ofpattems obtainedfiom the underlying data base through an one-time computation. These patterns are subsequently searchedfor on every query sequence presented to the system. A pattern matched by a region of the quev pinpoints to a potential local similarity between that reg+on and all the data base sequences also matching that pattern. By using a set of prudently chosen patterns, the tool presented in this work is able to discover weak but biologically important similarities.
