Metamodel Framework for Ontology Registration (MMF4Ontology Registration) for Semantic Interoperation
In semantic web service, ontology is widely used to describe the intension of the domain concepts. The relationship between ontologies is crucial for the mapping between them, and hence the semantic interoperation between ontology based information systems. Metamodel Framework for Ontology Registration (MMF4Ontology Registration) proposed in this paper provides an approach to register ontologies on different abstract layers. Additionally, it also provides a model to describe the evolution of ontologies. Such information will significantly improve the reliability of semantic web service. The content of this paper is based on ISO/IEC SC32 19763-3.The first Committee Draft has been approved by ISO/IEC SC32 in April, 2005.
