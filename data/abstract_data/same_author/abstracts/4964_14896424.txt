One-Photon Transitions between Heavy Baryons in a Relativistic Three-Quark Model
We study one-photon transitions between heavy baryon states in the framework of a relativistic three-quark model. We calculate the one-photon transition rates for ground-state to ground-state transitions and for some specific excited state to ground-state transitions. Our rate predictions for the most important transitions are: Γ ( Σ + c → Λ c + γ )=60.7±1.5 keV, Γ ( Ξ ′+ c → Ξ c + γ )=12.7±1.5 keV, Γ ( Λ c 1 (2593)→ Λ c + γ )=104.3±1.3 keV.
