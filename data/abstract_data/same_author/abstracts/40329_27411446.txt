A Purely Functional Language with Encapsulated Assignment
We introduce a new functional programming language with assignment. The language, which we call Λ, is a conservative extension of the λβ-calculus, and as such it it a higher order functional language in which we can manipulate functions as first class objects. Λ has a lazy evaluation semantics and Λ programs can be evaluated in parallel. Λ also supports imperative programming in terms of assignments. All the assingments in Λ are encapsulated within suitable scope of the let constructs. The language is therefore side-effect free and referentially transparent. We show by an example that we can smoothly reason about Λ programs.
