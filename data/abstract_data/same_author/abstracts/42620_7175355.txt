Asymmetric code design for remote multiterminal source coding
Asymmetric code design for remote multiterminal source coding in the quadratic Gaussian case is presented in this paper. For remote multiterminal source coding of X, to achieve the minimum sum rate of the two independent encoders subject to a fidelity criterion d, theoretical bounds were derived independently. The main idea is to quantize the first observation Y/sub 1/ and apply Wyner-Ziv coding on Y/sub 2/ by using the quantized version of Y/sub 1/ as side information in an efficient asymmetric coding scheme. The practical code design gives results that are very close to the sum-rate bound.
