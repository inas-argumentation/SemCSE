Network cache model for wireless proxy caching
We propose a wireless network cache model to facilitate the cooperative proxy caching in wireless base stations. A self-configured and adaptive virtual proxy graph (VPG) is used to achieve efficient data search, data cache and data replication. Based on demand, the aggregate effect of data caching, searching and replicating actions by individual proxies automatically distributes cached Web documents closer to the interested mobile clients. Our performance study demonstrates that the proposed individual-based wireless proxy caching scheme outperforms existing caching schemes in terms of different performance metrics.
