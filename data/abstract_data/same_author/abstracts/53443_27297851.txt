AXMEDIS Programme and Publication Tools Integration with Workflow-Enabled Communication and Process Control
This paper presents the AXMEDIS Programme and Publications (P&P) tools as supported by workflow (WF) integration enabling communication and control in a way that is designed to empower the user to locate digital contents of interest over the AXMEDIS P2P network and to manage and assign the distributions as required. These communications support a large set of interconnections between different sections of the AXMEDIS framework to enable automated processing and integration of digital contents. Following a brief introduction to the overall AXMEDIS framework, this paper presents the functionalities and features of the Programme and Publication (P&P) tools, discusses each individual component, including the P&P Editor and P&P Engine set in the context of the architecture for workflow integration and control for P&P tools within the AXMEDIS Framework
