TWO-LOOP OPERATOR MATRIX ELEMENTS CALCULATED UP TO FINITE TERMS
Abstract We present the two-loop corrected operator matrix elements calculated inN-dimensional regularization up to the ﬁnite terms which survive in the limite = N −4 → 0. The anomalous dimensions of the local operators have beenpreviously extracted from the pole terms and determine the scale evolution ofthe deep inelastic structure functions measured in unpolarized lepton hadronscattering. The ﬁnite e-independent terms in the two-loop expressions areneeded to renormalize the local operators up to third order in the strongcoupling constant α s . Further the unrenormalized expressions for the two-loop corrected operator matrix elements can be inserted into speciﬁc oneloop graphs to obtain a part of the third order contributions to these matrixelements. This work is a ﬁrst step in obtaining the anomalous dimensionsup to third order so that a complete next-to-next-to-leading order (NNLO)analysis can be carried out for deep inelastic electroproduction.PACS numbers : 11.15.Bt, 12.38.-t, 12.38.Bx
