Routing through a rectangle
In this paper an <italic>O</italic>(<italic>N</italic> log <italic>N</italic>) algorithm for routing through a rectangle is presented. Consider an <italic>n</italic>-by-<italic>m</italic> rectangular grid and a set of <italic>N</italic> two-terminal nets. A net is a pair of points on the boundary of the rectangle. A layout is a set of edge-disjoint paths, one for each net. Our algorithm constructs a layout, if there is one, in <italic>O</italic>(<italic>N</italic> log <italic>N</italic>) time; this contrasts favorably with the area of the layout that might be as large as <italic>N</italic><supscrpt>2</supscrpt>. The layout constructed can be wired using four layers of interconnect with only <italic>O</italic>(<italic>N</italic>) contact cuts. A partial extension to multiterminal nets is also discussed.
