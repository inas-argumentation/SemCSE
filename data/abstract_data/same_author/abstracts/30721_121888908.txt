The Altarelli-Parisi kernel as asymptotic limit of an extended Brodsky-Lepage kernel
An extended flavour non-singlet Brodsky-Lepage kernel is defined as the anomalous dimension of a light-ray operator. Introducing a new distribution function containing the Altarelli-Parisi quark distribution function as a special case we obtain a new set of evolution equations which induce a relation between the AP- and the extended BL-kernels. Thereby the consistency of the existing two-loop results is confirmed.
