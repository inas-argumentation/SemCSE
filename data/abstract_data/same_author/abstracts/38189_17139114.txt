A joint fit to the cosmological Model and the T-M and L_x-T relations using cluster data
In this work we show how well can the cosmological parameters be constrained using galaxy cluster data. We also show how in the process of fitting the model which attempts to describe the data it is possible to get some information about the cluster scaling relations T-M and L_x-T. Among other conclusions we found that only low density universes (Omega approx. 0.3 with or without cosmological constant) are compatible with recent data sets. These constraints will be improved with future SZ data.
