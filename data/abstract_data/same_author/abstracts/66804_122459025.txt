A Total-Lagrangian Fbem-Approach for Hyper-Elasticity and Plasticity at Finite Strains
Only a few papers can be found in literature (see e.g. references given in [1,2]) which are concerned with the application of FBEM to geometrical and material nonlinear problems. Most of these approaches are based on constitutive equations in rate-form. This recommends explicit integration schemes, which are quite sensitive with respect to the size of the increment. Hypoelastic laws, which are not compatible with reversible (hyperelastic) material behaviour in any configuration except the initial configuration, usually are taken as a basis for FBEM approaches in an Updated-Lagrangian framework. Therefore the validity of such formulations is restricted to small elastic strains. An Updated-Lagrange scheme is frequently applied with the main drawback that the system matrices have to be re-computed after each load increment if the configuration has changed significantly. Some of these drawbacks can be avoided in the proposed approach.
