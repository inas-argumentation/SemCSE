Negative-Weight Cycle Algorithms
The problem of finding a negative cycle in a weighted, directed graph is discussed here. First the algorithm for printing out a negative cycle reachable from the sources, with the running time no worse than the Bellman-Ford algorithm for the single-source shortest-path problem, is presented. Then an approach with the same time complexity, which could be used for outputting a negative cycle that may not be reachable froms, is reported.
