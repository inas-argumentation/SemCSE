Computing radical expressions for roots of unity
We present an improvement of an algorithm given by G<sc>AUSS</sc> to compute a radical expression for a <i>p</i>-th root of unity. The time complexity of the algorithm is <i>O</i> (<i>p</i><sup>3</sup><i>m</i><sup>6</sup> log <i>p</i>), where <i>m</i> is the largest prime factor of <i>p</i> - 1.On current workstations the given implementation of the algorithm can be used to obtain radical expressions for <i>p</i>-th roots of unity for <i>p</i> up to about 100 in the general case and <i>p</i> up to about 250 if <i>p</i> - 1 has only small prime factors.Moreover, the algorithm allows the use of coarse grained parallel computation in various ways that would allow one to compute bigger examples on a network of workstations.
