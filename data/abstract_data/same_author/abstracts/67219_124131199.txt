Linear Realization Theory, Integer Invariants and Feedback Control
The algebraic module theoretic stability framework for linear time-invariant systems is reviewed. The main theme is that Kalman’s algebraic realization theory has evolved much beyond its initial objective of providing an abstract framework for the derivation of mathematical models of systems. It has become a powerful tool for the extraction of structural invariants, permitting the exact characterization of all options for dynamics assignment through internally stable linear dynamic compensation. This characterization is provided by a set of integers—the stability indices of the system.
