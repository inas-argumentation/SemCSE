A 2D kinetic triangulation with near-quadratic topological changes
A triangulation of a set <i>S</i> of points in the plane is a subdivision of the convex hull of <i>S</i> into triangles whose vertices are points of <i>S</i>. Given a set <i>S</i> of <i>n</i> points in ℝ<sup>3</sup>, each moving independently, we wish to maintain a triangulation of S. The triangulation needs to be updated periodically as the points in <i>S</i> move, so the goal is to maintain a triangulation with small number of topological events, each being the insertion or deletion of an edge. We propose a kinetic data structure (KDS) that processes n<sup>2</sup> 2<sup>O(√log n•log log n )</sup> topological events, with high probability, if the trajectories of input points are algebraic curves of fixed degree. Each topological event can be processed in <i>O</i>(log <i>n</i>) time. This is the first known KDS for maintaining a triangulation that processes near-quadratic number of topological events, and almost matches the Ω(<i>n</i><sup>2</sup>) lower bound, [1]. The number of topological events can be reduced to nk • 2<sup>O(√log k•log log n )</sup> if only <i>K</i> of the points are moving.
