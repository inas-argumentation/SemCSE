Constructing minimum energy mobile wireless networks
Given a set of wireless network nodes <i>N</i>, the directed weighted transmission graph <i>G<sub>t</sub></i> has an edge <i>uv</i> if and only if node <i>v</i> is in the transmission range of node <i>u</i> and the weight of <i>uv</i> is typically defined as |<i>uv</i>| <sup>α</sup> + <i>c</i> for a real constant 2 ≤ &gr;≤4 and c & 0. The minimum power topology <i>G<sub>m</sub></i> is the smallest subgraph of <i>G<sub>t</sub></i> that contains the shortest paths between all pairs of nodes. We described a distributed position-based networking protocol to construct the enclosure graph <i>G<sub>e</sub></i>, which is an approximation of <i>G<sub>m</sub></i>. The total communication complexity is <i>O</i>(<i>n</i>). Let <i>d<sub>G</sub></i>(<i>u</i>) be the degree of node <i>u</i> in a graph <i>G</i>. The time complexity of each node <i>u</i> is <i>O</i> (<i>d<sub>Gt</sub></i>)). The space required at each node is <i>O</i>(<i>d<sub>Gt</sub></i> (<i>u</i>. This improves the previous result that approximates <i>G<sub>m</sub></i><i>O</i>(<i>d</i><sub><i>G</i><sub><i>t</i></sub></sub>(<i>u</i>)<sup>3</sup>) time using <i>O</i>(<i>d<sub>G<sub>t</sub></sub></i>(<i>u</i><sup>2</sup>) spaces. We also show that the average degree <i>d<sub>G<sub>e</sub></sub></i> (<i>u</i>) is usually a constant, which is at most 6. Our result is first developed for stationary network and then extended to mobile network.
