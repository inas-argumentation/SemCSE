MU-MAQAS: A P2P based Model Updatable Mobile Automatic Q/A System
Along with the development of wireless technology and especially 3Gpsilas throw into commercial, the mobile value-added services gradually popular used, such as mobile automatic question and answer (Q/A) system. But the current mobile Q/A system mainly based on FAQ database, the question and answer can not be validated and updated by itself. So this paper attempts to implement a p2p based model updatable automatic Q/A system named MU-MAQAS for mobile phones using SMS interface. MU-MAQAS mainly includes: question & answer information collecting module and model manage & use module. It can automatically collect Q/A information from internet and update the Q/A model in time. A simulated Q/A system is also coded to validate the design. Results of simulation proved that under ideal conditions the systempsilas average responding time is less than 64 ms and precision is above 60% when there are no more than 3000 simultaneous asking queries, and so the completeness and feasibility of the systempsilas design is proved.
