Algebraic construction of static axially symmetric self-dual gauge fields for an arbitrary group
Abstract A linear scattering problem associated with the static axially symmetric self-duality equation is introduced in a natural way using a symmetry argument. In conjunction with previously found symmetry (Backlund) transformations it provides an algebraic construction method of the self-dual solutions. This algebraic procedure which can be used to construct multi-monopoles is presented in some detail.
