Efficient piecewise-linear function approximation using the uniform metric: (preliminary version)
We give an <italic>O</italic>(<italic>n</italic>log<italic>n</italic>)-time method for finding a best <italic>k</italic>-link piecewise-linear function approximating an <italic>n</italic>-point planar data set using the well-known uniform metric to measure the error, ε≥0, of the approximation. Our method is based upon new characterizations of such functions, which we exploit to design an efficient algorithm using a plane sweep in “ε space” followed by several applications of the parametric searching technique. The previous best running time for this problem was <italic>O</italic>(<italic>n</italic><supscrpt>2</supscrpt>).
