Research on Distributed Data Mining Tool Used in Control System
In this paper, A distributed data mining tool that suitable for distributed and isomeric database environment of intelligent control system by borrowing ideas from architecture of grid is introduced. It can also perform incremental data mining based on history mining result. This tool makes full use of Metadata of each kind of resources. The resources associated in the data mining are all packed into form of web service, which is give a description by respective attribute document of the XML format. SOAP takes charge of the communication between the separated parts of the whole data mining process.
