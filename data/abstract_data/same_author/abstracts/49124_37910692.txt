Replicated shared object model for parallel edge detection algorithm based on spiral architecture
Edge detection in computer vision and image processing is a process which detects one kind of significant feature in an image that appears as discontinuities in intensities. A parallel edge detection algorithm based on spiral architecture is designed in this paper using a replicated shared object model (RSOM). We use this approach to meet the requirements of replicated object management, update propagation, underlying communication and consistency maintenance among replicated objects. Multi-scale image theory plays an important role in this research.
