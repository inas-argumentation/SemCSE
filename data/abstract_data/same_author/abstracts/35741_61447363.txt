Software for a database-controlled measurement system at the Fermilab Magnet Test Facility
A software system has been developed for use in measuring the magnetic properties of accelerator magnets at the Fermilab Magnet Test Facility. Key features of the system include: storage of measurement data in a relational database; use of database tables to define the individual steps that occur during a measurement; use of an "electronic logbook" to store an historical record of important measurement details within the database; a graphical user interface for measurement technicians and data analysts to use in acquiring and analyzing data. We describe the final software system design, with particular emphasis on the data acquisition subsystem. Currently, the system supports 3 test stations and has been used to measure approximately 85 magnets. It is used for both production measurements and R&D studies of prototype magnets.
