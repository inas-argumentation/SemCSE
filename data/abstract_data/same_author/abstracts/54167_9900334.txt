IntClust: A Software Package for Clustering Replicated Microarray Data
IntClust is a software package for clustering gene-expression data with repeated measurements based on interval data analysis. By utilizing interval data for representing replicated microarray data, IntClust is able to take into account the scopes where replicate microarray data are distributed instead of simple data points. The soft ware package offers several transformation models for interval data representations, supports different extended distance similarity/distance measures for interval data analysis, provides some variations of modified K-means clustering, and presents three popular clustering quality evaluation measures. Our experiments show that IntClust improves the clustering performance of gene-expression microarray data over traditional approaches. The software package is available at http://cadse24.cs.fiu.edu/IntClust
