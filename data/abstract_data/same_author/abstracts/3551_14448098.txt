Research on Dynamic Task Assignment in Grid Workflow System
Task assignment in grid workflow system should be designed to adapt well with the grid which allow people from different organizations to work together in the same workflow process. To ensure grid workflow systems could assign the task to the most suitable person, a novel solution is proposed firstly. Then two description languages GHRSL and HRRL are defined. GHRSL (grid human resource specification language) describes people as grid resources. HRRL (human resources requirement language) describes human resources requirement of workflow tasks. Finally, the evaluation method and the algorithm of dynamic task assignment are also proposed. Based on these, the grid workflow system could assign tasks dynamically to the correct person(s)
