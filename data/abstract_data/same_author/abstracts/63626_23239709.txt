A Low Complexity Scheme for Adaptive MIMO-OFDM System
In this paper, we propose a low complexity scheme for adaptive MIMO-OFDM system. A new method for calculating the process gain is developed to reduce the complexity and avoid pseudo inverse operations in the transmitter. The computation method is derived for the adaptive V-BLAST architecture which is based on the ZF-SIC detection algorithm and adaptive modulation and bit loading algorithm. The proposed process gain algorithm is proved equal to the ZF-SIC based process gain computation algorithm. So the proposed algorithm can achieve the same result as the ZF-SIC algorithm, which is proved through simulation methods in the paper. Also the complexity analysis is presented.
