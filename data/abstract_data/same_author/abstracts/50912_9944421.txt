A parallel algorithm for mapping a special class of task graphs onto linear array multiprocessors
In parallel and distributed computing, mapping a task graph to a specific multiprocessor topology is an important problem. In this paper we investigate a special case of this problem for linear task graph and linear array multiprocessors. A polynomial time sequential algorilhm and a parallel algorithm are developed'and analyzed. It has been shown that the sequentialalgorithm developed has a time complexity at least as .qood as the existing n log n algorithm while the parallel algorithm presents the very first attempt at parallelizing the sequential solution.
