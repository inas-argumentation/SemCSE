The Human Face Recognition Based on the Improved Multi-scale LBP
This paper put forward an operator for face recognition based on LBP algorithm and multi-scale fusion method. It uses an e-LBP operator to extract texture features of face images, then divides the LBP feature of images into non-overlapping feature areas, and computes the histogram statistics on them respectively. Finally the multi-scale LBP features are derived by connecting the LBP histogram of sequences in all areas, and the nearest neighbor classifier is used for face image classification and recognition. The experimental results shows that this algorithm is able to face a good image classification and recognition and can extract much richer global information. Introduction Face recognition is a representative and important research topic in the pattern recognition, image analysis and understanding. Face recognition is not only has important theoretical value, it also has important use value in practice. but, due to the change of image acquisition condition, coupled with the human face has the changes by itself so it makes the same person’s different photos has a very big difference and the result is likely to be mistaken for different pictures of people, this brought difficult problems to face recognition. Therefore, how to improve the accuracy of the face recognition is become an important topic for researchers. Initially to incoming the LBP operator into the face recognition [1], because compared LBP [2] with PCA and LDA, LBP is not sensitive to light, and it is good at extracting local texture feature extraction. Based on the traditional LBP propose the ε-LBP, by adjusting the parameter e, to seek more suitable for target classification feature subspace, and at the same time using multi-scale image feature description and the face recognition method. Using Difference of Gaussian filter to do the image multi-scale analysis, extracting the face images in the scale space of the e-LBP features images, then blocking and extracting the ε-LBP feature image histogram, make all of the ε-LBP histogram to connecting and form a multi-scale e-LBP histogram. Finally, matching the multi-scale characteristics of ε-LBP histogram and realize face recognition. This method is not sensitive to the effects of image noise, and it has a better ability and judgment of face images.
