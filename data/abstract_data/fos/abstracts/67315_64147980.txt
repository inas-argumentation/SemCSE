Design of Logistics Orders Management System Based on B/S and AJAX Technology
For the treatment of logistics company,they need a cargo information management system,with convenient.Gives a order design scheme and key technology of the logistics order management system based on ASP.NET and AJAX technologies.System is mainly based on AJAX,ASP.NET and SQL Server 2005 technology.The database is SQL Server 2005.Combines AJAX and ASP.NET to make the Web browser application processing to play the best side,and without the need to talk to the server-side interactivity to update the page refresh-free technology.
