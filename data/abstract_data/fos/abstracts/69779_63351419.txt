Research and Implementation of Nutch Chinese Word Segmentation in Hadoop Cloud Platform
Nutch is an open source search engine. Hadoop which Apache develops is an open source cloud platform similar to GFS and MapReduce of Google. An efficient,reliable and scalable Chinese search engine can be designed using Nutch and Hadoop. How ever,the w ord segmentation module of Nutch segments Chinese into some single characters and doesn't conform to Chinese language habit of segmenting Chinese into some w ords. To solve this problem,this paper proposes to use IK Analyzer Chinese w ord segmentation toolkit based on dictionary to transform Nutch. First,the paper describes the method that how to implement IK Analyzer Chinese w ord segmentation module on Nutch,then tests the w ord segmentation module in the hadoop cloud platform. Experiments show that the w ord segmentation result of IK Analyzer module more conforms to Chinese language habit and has large significances on the theory and application of Nutch.
