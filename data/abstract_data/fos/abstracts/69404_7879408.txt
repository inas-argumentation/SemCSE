A benchmark for performance evaluation of a distributed file system
This paper presents a performance study of a distributed file system. The distributed system allows for remote file access and remote process execution. A set of benchmarks for performance evaluation is presented. The benchmarks consist of CPU-intensive and I/O-intensive processes executed locally and/or remotely. The processes can read and write files placed on the local and remote machines. File replication, file migration, and process migration are implemented. A number of experiments executed in a distributed system are discussed to show the applications of the benchmarks. These experiments show the changes of system performance due to file and process placement, file replication, and file and process migration.
