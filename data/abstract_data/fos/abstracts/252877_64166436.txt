Research and Design of Network Performance Measurement System Architecture
With the growing size of the Internet, the growing number of Internet users, the design and application of the network posed a severe challenge, which requires real-time detection of the network and processing based on the results. The research and implementation of network performance measurement platform is necessary. Introduces the basic concepts of network measurements, the main network measurement techniques, on this basis, focuses on analysis of network measurement system architecture design and implementation, and thus on the measurement results for data analysis, finds that network anomalies, and proposes possible solutions.
