Approach to Estimate a Basic Block's Execution Time on the Reconfigurable Device at Compile Time
In order to quickly and accurately estimate a code fragment's execution time on reconfigurable devices and provide more instructive information to hardware-software code partition at compile time, an IP-core based code transformation and a description method for general reconfigurable devices are proposed in this paper, which can be used to estimate a basic block's execution time on a reconfigurable hardware at compile time. Experiment results show that although some approximations and assumptions are made to reduce the hardware synthesis, place and route tasks needed at compile time, the difference between the proposed method and Time Analyzer provided in Xilinx ISE is 2.9% on the average, and 8.2% in the worst case.
