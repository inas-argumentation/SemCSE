Discussion on Semantic Web and Semantic Grid and Data Resources Integration
At present,many e-govenment systems are up against a common problem,namely information island.The key for solving the problem is to integrate the data sources in existence.The semantic grid theory which combines semantic Web and the grid brings us a new method to do the job.Based on the theory,puts forward a prototype of semantic grid called Taxi Grid(Tx-Grid) according to the application requirement of informationzation of Taxi management,and discusses a mechanism that integrates heterogeneous distributed database resources by using ontology to solve the problem efficiency.
