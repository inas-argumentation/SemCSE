Network Constructing Algorithm Based on Link Significance Evaluation: NABLE
A new network design algorithm called NABLE (Network constructing Algorithm Based on Link significance Evaluation) is proposed for constructing future telecommunications networks. This algorithm first synthetically creates a backbone network by utilizing a newly proposed concept named “link significance evaluation”, then adds other links to the backbone network. After explaining the concept of “link significance evaluation”, the flow-chart of NABLE based on this concept is given. Design examples on a large-scale network show that NABLE is a powerful heuristic method for total network optimization. NABLE can practically be used for the long-range planning of various types of networks.
