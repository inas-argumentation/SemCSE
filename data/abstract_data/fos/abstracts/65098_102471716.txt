Structure evolution in the LaMn1 − xFexO3 + δ system by Rietveld analysis
The synthesis of LaMn 1 −  x Fe x O 3 + δ (0 ≤  x  ≤ 1) solid solutions perovskite powder was carried out using high-energy milling from the constituent oxides, and further crystallization by high temperature treatment. The compositions of the crystalline phases as a function of x were determined by X-ray powder diffraction using a Rietveld refinement. The relationship between composition and structure was covered. This showed that LaMn 1 −  x Fe x O 3 + δ exists with the rhombohedral structure (R-3c, 167) only below x  = 0.3 and with the orthorhombic structure (Pnma, 62) over x  = 0.7.
