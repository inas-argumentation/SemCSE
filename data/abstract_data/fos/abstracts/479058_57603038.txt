Study and Implementation on ETL Strategies of Excel Documents in Data Warehouse System
The data in data warehouse are obtained from organization's internal OLTP system and other format's internal or external data,in which many of them are organized in Microsoft Excel format.It must be solved urgently at present that how to transform the Excel format's data to the useful information of data warehouse.After analyzing the Excel document structure and Java Excel API application method,the operation approach of reading Excel document by Java program is discussed,and the process and strategies implementing and storing the Excel data to data warehouse are illustrated combined with an instance.
