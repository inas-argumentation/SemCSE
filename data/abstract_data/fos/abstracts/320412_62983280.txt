Extended Dewey Encoding Algorithm of Twig Pattern Query Without Merging
Finding all the occurrences of a twig pattern in an XML document is important to the operation of XML query.Many algorithms such as TwigStack and TJFast were proposed in the past.However,they are all based on merging,without avoiding a large number of unnecessary path merging.TwigWM(Twig Without Merging) algorithm with extended Dewey code is proposed in this paper,which uses part of the stack and list structure to realize the non-merged query.Experimental results have showed that TwigWM is better than TJFast,Twig2Stack etc.
