An On-board Group De-multiplexing Algorithm of Flexible Frequency-band Wideband Satellite Communication
This paper studies an algorithm based on FFT to flexible frequency-band group de-multiplexing of wideband satellite communication.This algorithm first has a FFT analysis of the input signal,and then de-multiplexes the input signal due to the distribution of the frequency,at last gets the different access signal using split-radix algorithm.The computer analysis proves that this algorithm have a low computational complexity,more dynamic frequency-band processing ability compared to the formers,and easy to realized on board when dealing with flexible frequency-band group de-multiplexing.
