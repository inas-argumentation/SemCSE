Dynamic programming model of a cotton ginning system.
ABSTRACT A dynamic programming model of a cotton ginning system was developed in response to the need for op-timizing energy usage in cotton gins and for maximizing returns to the farmers. Performance tables indicating the influence of each stage of the ginning process on mois-ture content, composite grade, and lint turnout were developed for a small-scale ginning system and used as transfer functions in the model. When the model is used in a specific ginning system, the performance tables in the model can be used, or the existing tables can be ad-justed to more correctly reflect the performance char-acteristics in the specific ginning system. Input to the model consists of the initial grade associated with the minimum ginning sequence, initial moisture content, maximum turnout, maximum grade, and staple length. Output of the program consists of the decision codes for each stage of the ginning process, composite grade, final moisture content, turnout, and monetary returns to producers
