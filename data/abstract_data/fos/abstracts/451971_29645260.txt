Performance Results for the CSMA/CD Protocol Using GreatSPN
This article presents the performance modelling results for a LAN in which a single bus is accessed by a finite number of stations randomly located along the bus using the 1-persistent CSMA/CD protocol. The results are obtained using the following steps: a GSPN model for the CSMA/CD protocol is developed and entered into the GreatSPN software system; the correctness of the model is validated by GreatSPN; three important performance measures — throughput, delay, and collision probability — are defined; GreatSPN then computes the results for these measures, the graphs of which are plotted against the parameters: number of stations, retransmission rate, and arrival rate. Finally, the strengths and weaknesses of the GreatSPN software are evaluated. A distinct benefit of using GreatSPN to obtain these performance results is that we can predict how a LAN system using the CSMA/CD protocol reacts to various changes, policies, and loading factors and then is able to select parameter values to maximize system performance.
