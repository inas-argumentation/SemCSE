Solution of two point boundary value problems using orthogonal collocation on finite elements
A convenient computational algorithm to solve boundary value problems (BVP) using orthogonal collocation on finite elements (OCFE) is presented. The algorithm is the conjunction of finite element method (FEM) and orthogonal collocation method (OCM). OCM discretize BVP's conveniently where as FEM provides accuracy to the solution. The method is applied to the boundary value problems having mixed Robbin's and Dirichlet's boundary conditions. The numerical results are compared with the analytic solution.
