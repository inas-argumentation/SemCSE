Network Security under Wireless Network Environments
Along with the wireless network's widespread use and development,the wireless network's security problem starts to highlight and receive the widespread attention,what especially is the open threat,the junction point threatens denial of service,and so on.Through using WAP,according to MAC address filtering,set a unique SSID,intrusion detection systems and virtual private network technologies,as well as the wireless network's physical control and the security control mechanism's consummation,may guard against the security risk effectively and to develop the promotion wireless network healthy.
