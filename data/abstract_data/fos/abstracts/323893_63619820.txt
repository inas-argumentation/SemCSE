Research on Universal Interoperability-oriented Sensor Data Model
Sensor network,has been developed rapidly with higher requirements for openness and interoperability,and unified sensor dada model is the foundation of interfaces definition and standardization.The paper applied ontology theory to sensor node description for knowledge acquisition.Based on that,UML diagram and XML Schema of sensor data "SDDP"(sensor data description protocol)were given.Finally,the application of SDDP to press sensor node showed that SDDP had powerful function,such as reusability,etc.SDDP,a kind of sensor data model,can reduce the cost of sensor network development and give a good foundation for development of sensor network with universal interoperability.
