Research and Design of Higher Education Information System Integration Based on SOA
Analyzes the major problems of the current campus information system,introduces the basic principle,the hierarchical model and implementation technology based on SOA,proposes an higher education information system integration model based on SOA in the previous infor-mation system.It focuses on the system architecture,implementations based on service-oriented architecture.At last,gives an example of integration for existing higher education information system application and performance,the practice showed that the architecture can be used to achieve college application integration information system with good performance.
