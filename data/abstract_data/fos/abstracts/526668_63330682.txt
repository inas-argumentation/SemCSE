SnSim:Study and Implementation of a Wireless Sensor Network Simulator
With the sensor network technology research gradually deepening,the sensor network simulation platform has been the demand for more and more attention.In order to facilitate more effective sensor network algorithm study,we designed and implemented a sensor network simulation platform SnSim(Sensor Network Simulator).View of the current developments in the sensor network,sensor networks combine the characteristics of the current popular Eclipse RCP object-oriented framework for the design of the sensor network simulation platform mathematical model,architecture,function modules,the platform language,the ultimate realization of the sensor network simulation platform,and its performance and effectiveness of the scientific assessment.
