Strategy of Light-load Antiworm Propagating on a Hierachical Overlay Network
In order to reduce the influence on network and improve the speed during the antiworm propagating,a hierarchy overlay propagation model(HOPM) and a propagating algorithm which is based on periodical feedback self-adapting technology algorithm(FBSP) are proposed.The hierarchy propagation model has the following characteristics:manageable,approaching the physical network which is based on,and adapting frequent changes of the physical network.The FBSP algorithm traces the reciprocity processing of worms and antiworms,adjusts the antiworm propagating ranges and policies in real time to control the consumption of network bandwidth.The simulated result shows,while the network is large enough,the communication load of the antiworm propagating in HOPM model is only about 30%-50% of the one in a Landmark model.
