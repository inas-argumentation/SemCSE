Research on Java Teaching Model Based on Task-Driven
In current Java teaching process,exists many problems,such as the short of class hour,heavy task,the lack of practice sessions,the separate of theory and practice and baldness of teaching content.Aiming at the problem of students' weak learning initiative and hands-on ability,proposes Java teaching model based on Task-driven,which can be separated in four parts including creating situation,setting tasks,collaborative learning and evaluation.The marked characteristics of this model is to set up a task principal line,and the independent learning and collaborative learning are given priority while instructor-led is supplemented.This model has obvious difference from the cramming method of teaching.The application of this teaching method to Java teaching can simulate students' interest in study,and improve their comprehensive ability.
