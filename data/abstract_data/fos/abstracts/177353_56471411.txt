Based on Ajax and jQuery Technology Web Application Development
With the coming of the information age, a lot of information management system on reading speed data and interaction with customers has many places need to be improved. On the basis of Web application development, we research a number of technology, such as jQuery library, the chart plugin, the linkage menu and the calendar widget. This paper mainly describes the practical application of these plug-ins in Web application development. We can visualize the corresponding data, using the form of charts and calendar to display, and users can be very intuitive to see some information. The following is mainly about the research of these technologies and its implementation methods.
