Dynamic Feedback Scheduling Algorithm of the Video Server Cluster System
Nowadays,Server Cluster is an effective method of setting up massive video server. An implementation method of video server cluster system is presented in this paper by analyzing the Linux virtual server.By studying the scheduler of load balancing in the cluster-based system, this paper presents a dynamic-feedback algorithm for load balancing in order to smooth extremely high variable traffic. Combining the weighted connection scheduling algorithms, it can adapt the weights according to dynamic-feedback load information, therefore it can effectively solve the load imbalance problem among the servers and increase the throughput of the whole system,which make the rate of the whole cluster increase smoothly with the scale enlarging.
