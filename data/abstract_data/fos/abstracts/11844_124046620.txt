Application of Multiple Equlibrium Points Search in Gradient Systems to Mixed-Integer Programming
This paper proposes a solution to mixed-integer programming by using a gradient system and searching for multiple equilibrium points (EPs) in the system. The proposing method is available when the objective function of a problem is continuous and differentiable. In order to find feasible solutions of a mixed-integer problem by gradient systems, we treat discrete decision variables as continuous ones. A gradient system in which EPs are embedded at feasible solutions of a mixed-integer problem is built by a systematic procedure and is solved by the multiple EPs search method which we have already proposed. To improve efficiency and certainty for mixed-integer programming, we also proposed adjustments of the search method in this paper.
