Realization of IP Network Running Quality Evaluation Method Using Policy
A set of IP network running quality metrics and the network running quality model using policy were presented for solving the flexible and extensible problems in evaluation and satisfying evaluation demands.The network running quality evaluation process was described and the evaluation information model was established.The evaluation prototype system using B/S framework was developed,the fuzzy evaluation method was applied for the running quality evaluation and its pseudocode was described.The running results show that this system can realize the efficient,automatic,quantitive and extensible network running quality evaluation.
