Research on the Techniques of Continuous Data Capturing Based on File System Filtering Driver and its Application on Disaster Tolerance
According to the developing trend of disaster tolerant technology and combing the detailed purpose of continuous data protecting,a file filtering driver based continuous data capturing technology is proposed first.Then the detailed working process is described,and related critical technology including IRP intercepting,captured data transferring in kernel model and continuous data caching technology is proposed.Finally,a continuous data protecting system is constructed based on this technology,and related system testing metrics are presented.Compared with continuous snapshot and na?ve API robbing,the technology based on file filtering driver can work with high efficiency,no data lose and low cost,and will make little influence on the performance of upper application.
