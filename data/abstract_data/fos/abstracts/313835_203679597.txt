Fuzzy-grey Comprehensive Evaluation of Software Cost Estimation Methods
It is very important to evaluate software cost estimation method reasonably and subsequently select the most suitable one from current lots of software cost estimation methods.On the basis of the evaluation framework of software cost estimation methods,Fuzzy-Grey comprehensive evaluation method which combines fuzzy evaluation and grey theory is used in the evaluation of software cost estimation methods.Eventually,through an example the evaluation method is proved to be useful and feasible for evaluating estimation methods and have practice reference for software development.
