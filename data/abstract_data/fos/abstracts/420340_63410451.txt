Method of Heterogeneous Databases Access and Integration in Mineral Resources Grid Environment
In Xinjiang mineral resources data grid environment, applications are developed with dis-tributed geologic data. To facilitate application, a uniform data integration framework should be provided. For geologic applications characteristics, the data integration systems should focus on maintaining dynamic data resource information, searching among heterogeneous da-ta and coordinating constrain relations in the distributed environment. For the needs, pro-poses a Web service resource framework based mechanism for data resource integration. In the mechanism, implements a dynamical layered data information structure that consists by virtualized local data resource information and global data view for searching. Uncertainty of dynamic data resource is hidden by the structure through which application accessed data uniformly. Realizes coordination among heterogeneous database management system (DBMs). Based on the mechanism, consturcts a service system named MRG-DAIS has been con-structed and serves for MRG.
