Chaotic Image Scrambling Algorithm Based on Location and Gray Transformation
Based on the analysis of the defect of the traditional image scrambling,a new image scrambling algorithm is proposed based on location and pixel gray transformation.The algorithm scrambles by taking the matrix element as the unit,which produces the image total scrambling matrix by randomly changing the location and gray of every matrix element in different chaotic sequence.The form of the transformation matrix is unfixed and the number of the unmoving point is zero with no standard iterated formula,which achieves a better scrambling performance.Meanwhile,the algorithm has lower time complexity and high-level security.At last,some simulations and experiments verified the algorithm effectiveness.
