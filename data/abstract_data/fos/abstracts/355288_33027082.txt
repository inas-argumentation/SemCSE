Small program for fast DAQ in windows environment
A new data acquisition program for personal computers with the Windows operating system has been built at Charles University van de Graaff laboratory. It allows fast data acquisition from VME, CAMAC, and other PC interface cards using an interrupt or polling mode via several types of crate controllers. The program also facilitates basic on-line analysis and visualization of acquired data in graphs and histograms. The program is written as a combination of MSVC6.0++ and ROOT macros and offers easy customization to individual user requirements via external configuration files, without need of recompilation. A driver interface supports PCI bus devices (W-IE-NE-R PCI-CC32) or older ISA bus devices with internal drivers. In this paper, a description of the program concepts and features is given. The program was extensively tested with several combinations of hardware and software, and results of the tests are shown.
