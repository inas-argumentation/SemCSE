Development of Urban Distribution Network Planning Software Package Based on GIS
The features of GIS,Geographical Information System, applied in urban distribution network planning are analyzed in this paper.An o ptimization software package which based on GIS is designed.And it is exemplifi ed to illustrate the application of GIS in urban distribution network planning. The structure,basic algorithms and main functions of this software package are described.This software package is developed with Delphi language,and it has a friendly interface,provide a specialist consulting mode.It has been proved b y some practical examples that this package can work steadily and rapidly.And t his package takes advantage of GIS,so that the results are more accurate,intui tional and practical.
