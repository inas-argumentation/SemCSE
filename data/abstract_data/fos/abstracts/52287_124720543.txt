Rough Set Model Based on Limited Non-symmetric Similarity Relation
The rough set theory, based on the original definition of the indiscernibility relation, is not useful for analyzing incomplete information systems where some values of attributes are unknown. In order to process incomplete information systems, the classical rough set theory needs to be extended to some unequal relation. Several extension models had been researched such as tolerance relation, non-symmetric similarity relation, valued tolerance relation and limited tolerance relation. However, these extensions have their own limitation. In this paper, a new extension of rough set which is based on a limited non-symmetric similarity relation was developed. A theory analysis and the computational experiments show that for the limited non-symmetric similarity relation approach it is possible to obtain more information approximations compared with the other models.
