Research on Die-casting Machine's Monitoring System Based on MCGS
In this thesis,daily control routine such as current working station's data gathering,process,real-time and historical data processing,safe mechanism,procedure control,ejection curve,report output and so on,are finished by MCGS configuration software in common use.In this system,through in the HMI establishing the graphics object and adjusting picture layout,the configuration which collocates different parameters completes the different function.All controlling information and the data message are managed and assigned in on its server,s HMI.Therefore,the system maintenances simpler,effectiver.The way of offering information is more consistently,so conveniently obtain the comprehensively,the prompt field information.The actual movement indicated that,the method is more simple to be realized,takes the resources few,and the system is stable and reliable.So it has very good application value.
