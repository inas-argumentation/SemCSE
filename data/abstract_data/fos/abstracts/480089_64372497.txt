Application Research of Metadata on Generating Component-Based Software Test Case
In this paper, the basic process of component-based software has been firstly analyzed, and the differences between the process and traditional software testing process have been further given. Based on summarizing the notions and meanings of metadata, present use case meta model and test case meta model based on metadata. And the transition method of use case to test case is described. Then constitute the elements of metadata and the test model embedded in the metadata. Lastly, present an example implemented by above methods.
