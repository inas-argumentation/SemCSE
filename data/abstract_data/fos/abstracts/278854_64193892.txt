An Approach to Generating Tests for Web Applications Based on Relation Graph
The swift development of Web applications and their own complex characteristics have brought certain difficulty for their test.Thus,the demand cannot be satisfied by the traditional test methods and some bran-new Web test approaches are urgently required.This work defines Web application schema and constructs Web application relation graph in order to model Web applications.An approach to generating test paths is presented by establishing path-generating graph which is derived from the relation graph and used to produce path expressions.The test paths can be easily employed to construct test cases if user input values are provided.As a case study,a simple Web login system is exemplified.Moreover,a path generation strategy is suggested in accordance with the "divide and conquer" principle when the Web application under test is complicated.The strategy makes the Web application less complex and more controllable.This also restricts the state space explosion in a sense.Finally,it illuminates in theory the generality and correctness of the approach and rules proposed.
