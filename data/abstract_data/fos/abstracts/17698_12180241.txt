Tspec enforcement for MPEG video transmission over the next generation Internet: an analytical framework
Abstract The evolution of the Internet from a simple data network into a true multiservice network today constitutes a challenging task. To this end, the Internet engineering task force (IETF) has set up the integrated services (intserv) working group, with the goal of defining a next generation Internet, in which traditional best-effort datagram delivery and additional enhanced quality of service delivery classes coexist. In this framework it is necessary to provide a traffic source with the capability of matching the traffic characteristics, Tspec, declared to the network. Current MPEG encoders implement feedback laws which usually take into account the state of the encoder output buffer to provide a constant output bit rate. In this paper we propose to use this encoder facility to shape the output traffic according to the declared Tspec while maintaining an acceptable perceived image quality, and we introduce an analytical tool to evaluate feedback laws which provide this target efficiently. To this end an SBBP/D/N/K queueing system is used where the SBBP arrival process is varied according to the quantizer scale parameter chosen by the addressed feedback law at the frame level. The analytical framework allows us to evaluate system performance in terms of both marking probability, defined as the probability that the output traffic is not compliant with the specifications, and quantization distortion.
