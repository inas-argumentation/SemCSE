An Efficient Method of Publication Time Extraction for Web News
Time information of Web page plays important roles in Web search,because the majority of users' search is time-related.Focusing on Web new s publication time,an efficient method of publication time extraction for Web new s is proposed,w hich considers the feature of containing time information in Web new s URL,and the distance constraint betw een publication time and new s title.The experiment uses 30 keyw ords for 7 main Chinese search engines,and analyzes the accuracy and time consuming of publication time extraction for 3827 pieces of Web new s.The experimental result show s that the accuracy is 95.5% and time consuming is 88 seconds.
