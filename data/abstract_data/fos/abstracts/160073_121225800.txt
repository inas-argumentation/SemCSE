The Path of the Minimum l p -Norm Estimator for p Between 1 and Infinity
The minimum lp-norm estimator is the point that minimizes the sum of the distance from each data point in the lp-norm. The path of this location estimate for an lp-norm is found as p goes from 1 to infinity. This path indicates how critical the selection of an exponent is. An alternative proof of Descartes's rule of signs, applied to exponential sums, limits the number of repeated exponents for the same minimum point with usual data sets. Several bounds on this path include that it stays among the averages of pairs of data points.
