Mobile Peer-to-Peer Searching Using Ant Algorithm and Routing Detection
A mobile Peer-to-Peer search algorithm combining bandwidth-efficiency routing detection technology with the Ant algorithms is presented.It computes the semantic similarity between the query and peer to update the pheromone of routing table,and transmits the queries according to the pheromone of routing table.By caching queries of the passed nodes and detecting responses to the passed through nodes,the algorithm replies the cached queries according to the responses.The experiment results show that,compared with the other existing algorithms,the presented algorithm obtains high hit rates with low consumed bandwidth and improves the search efficiency.
