Study and Application of Production Data Retrieval System in Yongping Copper Mine
Production data retrieval system based on Internet/Intranet technique is developed centering on enterprise production information resource, taking study and development of production data retrieval system in Yongping Copper Mine for example. The system provides unified simple mode of communication with no difference to user platform for information department and grassroots unit to achieve information communication taking task as central organization through building Web network database server and taking Web network technique as kernel.
