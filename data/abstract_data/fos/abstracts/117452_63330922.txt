Discussion on the Teaching Skills of Data Structure Course Based on C++ Language
Data Structure is one of core courses of computer specialty,it is important to learn it well for the learning of successive courses.Compared with Data Structure course based on C language,because of more flexible grammar and more powerful function,it has more difficult in C++ learning than other computer language.While Data Structure is a comprehensive course,it's difficult for students too.So it's difficult for students to learn Data Structure based on C++ language and some of them lost the interest in it.Aiming at these problems,proposes some teaching skills to solve them.It can be proved that using these skills can achieve a better teaching effect.
