Multicore Frame of Sending Real-time Streaming Data for Video-on-demand System
This paper presents a hybrid frame combining of serial structure and parallel structure using for multi-core network processor platform,the frame consists of serial and parallel multi-core structure.For streaming data in video-on-demand system,this hybrid structure can effectively improve the stationarity and the accuracy of sending data on multi-core network platform.And with compared to the common parallel structure to point out that the pipeline structure can reduce the volatility of real-time streaming data,as well as scalability,etc.
