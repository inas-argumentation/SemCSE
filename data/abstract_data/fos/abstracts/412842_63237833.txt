Researching on Stable Analysis Pattern of Model-based Software Reuse
In software engineering,it is very valuable to build efficient reusable software artifacts. Software analysis patterns are reusable models,However,there are some deficiencies with the present analysis patterns,which make it difficult to use analysis patterns as efficient reusable artifacts.Eight important properties to evaluate the reusability of patterns are proposed in this paper. In addition ,the concept of stable analysis pattern is introduced.In the end,this paper contrasts the stable analysis pattern with the other patterns.
