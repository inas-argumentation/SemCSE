Framework and Modeling Method for Heterogeneous Systems Information Integration Base on Semantic Gateway
To realize the integration of heterogeneous systems with greater flexibility and more convenience, a framework for heterogeneous systems information integration based on semantic gateway is constructed firstly, and then the integration process and several relevant technologies are discussed. On the basis of above researches, a modeling method for heterogeneous systems information integration is put forward. According to the integration requirements and traditional information models, the method is able to rapidly generate the information integration models, which provide supports to the implementation and operation of semantic gateway. Finally the research results have been verified in a manufacturing enterprise
