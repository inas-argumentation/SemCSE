Application of UML State Diagram and Petri Nets in Class Test Cases Generation
A method of combinating the advantages of three types test case generation is proposed through researching and analyzing the characteristics of UML state diagram,EFSM and Petri nets in test case generation.The state explosion,the state diagram of conflict and the state map coverage can be resolved,analyzed and understand through analyzing characteristics of state diagram by Petri nets.Through examples and analysis of the study,test cases generation base on the combination of the full path to conversion guidelines to be effective.
