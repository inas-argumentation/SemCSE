2-Connectivity Backbone Network Constructing Algorithm for Ad Hoc Networks
Topology connectivity is an essential pre-condition to date communication,and bi-connectivity is the basic requirement to maintain topology connectivity in the case of unexpected node or link failure.In order to construct a tolerate backbone network of Ad hoc network,a 2-connectivity backbone network constructing algorithm is proposed to overcome the node or link failure.The algorithm is based on the correlation theories in graph-theory,and uses the triangulation structure in computational geometry.The simulation results show that,in different network,when using the algorithm proposed in this paper,the topology will be bi-connected at least,which is consistent with theoretical analysis.
