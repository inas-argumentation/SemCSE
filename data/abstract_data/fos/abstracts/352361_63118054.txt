Improvement on Routing Protocol QoS AODV for Mobile Ad Hoc Network
Research on routing protocol QoS AODV for mobile ad hoc network is hot. Since it only allows destination node to return routing reply packet RREP, the routing overload is quite high. AQ-AODV(Advanced QoS AODV) is proposed to allow intermediate node to return RREP by constructing routing table with different QoS levels and renewing the propagating mechanism of QOS-LOST packet. Simulation experiment shows that AQ-AODV has quite lower overload than AODV and QoS AODV, also, both the packet delivery ratio and average packet propagating delay are better.
