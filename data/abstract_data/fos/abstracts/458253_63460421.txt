Data Collection Method in Wireless Sensor Networks Based on Mobile Base Station and Collecting-tree
In order to save and balance the energy consumption of wireless sensor networks and adapt to the needs of large-scale applications,a data collection method in w ireless sensor netw orks based on mobile base station and collecting-tree is proposed in this paper. This method allocates nodes into virtual square grid area and elects a cluster head for each grid according to the energy and location information of nodes using delay mechanism. Nodes that are not cluster heads should join the nearest cluster and cluster heads make up a data aggregation tree w ith the base station as the root. Data w ill then be passed by cluster heads to base station via the aggregation tree. In order to balance the energy consumption of each node,the base station is moved to next position at the edge of the area after each round of data collection w hen all nodes are sleeping,and another similar round of data collection w ill begin. Simulation results show that this method can effectively extend the lifetime of the netw ork.
