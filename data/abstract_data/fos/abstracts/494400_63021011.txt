Application of Canny Edge Detection Algorithm in Robot Version
OpenCV is a lightweight and efficient library of programming functions,mainly aim at real time computer vision,which realizes a series of general algorithm in the field of image processing and computer vision,it consists of C function mainly and provides multi-language interfaces. Uses Canny algorithm to detect the fuzzy edge,as well referring to the instance of L2BOT vision robot,researches on image recognition of barcodes and obstacles based on OpenCV in the mode of the pure background,and puts forward a reference model in order to select an optimal movement path of L2BOT.
