Research of Volatile Code Rate Inter-satellite Communication System for Micro-satellite Formation-flying Constellation
This paper bases on three micro-satellites which formation fly on a same orbit and perform three dimension solid mapping for terra.The calculating formula of LEO formation-flying satellite inter-satellite links is guided according to the special require of formation-flying micro-satellite inter-satellite links.A new communication project which changes code rate according to the inter-satellite communication distance is brought forward to suit this situation.And the simulation of volatile code rate inter-satellite communication system for micro-satellite formation-flying constellation is performed.
