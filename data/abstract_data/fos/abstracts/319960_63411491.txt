Discussion on Elementary Teaching Method of Visual C++ Programming
Proposes a teaching method of fastly improving the learning efficiency for Visual C++ pro-gramming elementary. By employing interests actuating in the first beginning of the courses,the what-you-see-is-what-you-get (WYSIWYG) sample programs are used to actuate stu-dents' learning interests. Also,by the means of improved experimental teaching,the Windows operation system related running mechanisms and the application program framework can be validated and understood much easier. Practice shows that the presented method does good to students to improve the learning efficiency of Visual C++ programming elementary.
