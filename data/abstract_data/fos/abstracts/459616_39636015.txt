Distributed evaluation of commutative and associative functions
A symmetric distributed algorithm for evaluation of associative and commutative functions is presented. This class of functions underlies many decentralized consensus protocols, such as decentralized extrema finding and distributed transaction commit. Let N be the number of participating processes and c > 0 be a design parameter. The algorithm uses a total of 2cN(N 1 c − 1) messages and executes in time M + c ( M + C + 2 D ), where M and C are time intervals needed for certain internal computations within a process and D denotes the transmission delay of the communication network. The algorithm permits a trade-off between execution time and communication, and allows designers to choose an optimal value for the design parameter c .
