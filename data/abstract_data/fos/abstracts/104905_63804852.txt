Non-linear Dynamic Self-adaptive Agent Coalition Algorithm
Agent coalition is an important way to manage WSN(Wireless Sensor Network).In the paper,we introduce PSO(Particle Swarm Optimization) and improve the algorithm through making its parameters non-linear self-adaptive.Solve Agent coalition formation using improved PSO and design a utility function for the characteristics of WSN.Algorithm based on non-linear dynamic self-adaptive PSO has larger scope in the early of the search and has a good performance in local mining in the late of the search.It is proved by simulation that algorithm based on PSO is superior to other algorithm in stability.Improved PSO widens the search scope and can convergence to the optimal solution faster.Furthermore,Agent coalition formation algorithm based on non-linear dynamic self-adaptive PSO supports solving Agent coalition formation in parallel multi-tasks environment.
