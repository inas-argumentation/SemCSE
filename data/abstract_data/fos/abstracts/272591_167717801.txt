Discussion on Using Earned Value Method in Software Project Management
Earned value method is the use of integrated project management theory and statistics principle, introduces the "earned value" concept to help project managers clearly distinguish the reason of progress and cost management in project cost diversity, in order to have specific measures to carry out the project schedule management and cost control. In the practice of project management abroad, earned value method has been the primary means of project control, widely used by project managers. Introduces earned value method to software project management, in order to reduce software project's management costs and enhance project management level.
