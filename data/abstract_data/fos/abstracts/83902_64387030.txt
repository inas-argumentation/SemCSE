Research and Implementation of the Cache Algorithm for Multimedia Network File System
After analyzing the storage and access characteristics of Multimedia file,a kind of high-performance MNFS(Multimedia Network File System) which is based on TCP/IP protocol and local file system is designed for Multimedia.The MNFS uses two-level Cache structure(directory and data),which is convenient for the maintenance and fast search.In order to improve the disk access performance of MNFS,an optimized Cache algorithm has been designed.The replacement algorithm of whole Cache is LRU(Least Recently Used),while the directory Cache and file data Cache are organized to different LRU chain.The performance of MNFS is tested in the environment of 100M Ethernet,and the test result shows that the performance of random reading of MNFS is close to Server Message Block Protocol(SMB),but the performance of sequentially reading is probable 10-20% higher than SMB.
