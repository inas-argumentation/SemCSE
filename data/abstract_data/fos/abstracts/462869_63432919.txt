To Improve the System Structure of Data Warehouse & Data Mart
This paper raises a new method to build the data mart and data warehouse system. It uses the same loading program to load data to all data marts and data warehouse. It loads the detailed data and light summing-up data to the data mart, the historic data and shared data to the data warehouse, and the high summing-up data to central data warehouse through second integration. This system not only has advantages of bottom-up method and top-down method, such as easy developing and the same data structure, but also has more advantages than joint method, such as more reasonable data structure and accord with policymakers' demands.
