Study and Implementation of Grid Service Server Performance Optimization System
To improve the performance of grid service servers, this paper studied and designsed a dispatcher-based dynamic load balancing grid service server system. A prototype, Cluster-based Grid Service Server (CGSS), is designed and implemented. Through dispatchers, CGSS can integrate a cluster of grid service servers to provide a single image of grid service servers. And CGSS also can carry out the load balance among the cluster of servers. This paper measures and analyzes the performance of CGSS. The results showed that dispatch-based load balancing approach can improve the performance of grid service server remarkably.
