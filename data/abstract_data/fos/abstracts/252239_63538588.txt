Integrated Control Model for Different Systems of Networked Manufacturing Enterprise
To improve the intelligent restructuring capability of manufacturing system,deeply develop and produce new products,an integrated control model for different systems of networked manufacturing enterprise is proposed,which is integrated controlled within enterprise based on Common Object Request Broker Architecture and Multi-Agent System,communication mechanism within the enterprise are established;and integrated control outside enterprise is realized by using Web services,which through the remote service Agent based on Simple Object Access Protocol to support allies to implement remote cooperative production control;feasibility and practicability of the proposed integrated control model are proven through networked manufacturing experiment.
