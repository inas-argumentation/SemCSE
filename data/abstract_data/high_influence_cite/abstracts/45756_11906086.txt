Spacetime supersymmetry in AdS3 backgrounds
Abstract We construct string target spacetimes with AdS 3 × X geometry, which have an N =2 spacetime superconformal algebra. X is found to be a U (1) fibration over a manifold which is a target for an N =2 worldsheet conformal field theory. We emphasize theories with free field realizations where in principle it is possible to compute the full one-particle string spectrum.
