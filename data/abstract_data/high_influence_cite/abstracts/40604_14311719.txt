An Efficient Optimal Algorithm for the Successive Minima Problem
In many applications, including integer-forcing linear multiple-input and multiple-output (MIMO) receiver design, one needs to solve a successive minima problem (SMP) on an <inline-formula> <tex-math notation="LaTeX">$n$ </tex-math></inline-formula>-dimensional lattice to get an optimal integer coefficient matrix <inline-formula> <tex-math notation="LaTeX">$\boldsymbol {A}^\star \in {Z}^{n\times n}$ </tex-math></inline-formula>. In this paper, we first propose an efficient optimal SMP algorithm with an <inline-formula> <tex-math notation="LaTeX">${\mathcal {O}}(n^{2})$ </tex-math></inline-formula> memory complexity. The main idea behind the new algorithm is it first initializes with a suitable suboptimal solution, which is then updated via a novel algorithm with only <inline-formula> <tex-math notation="LaTeX">${\mathcal {O}}(n^{2})$ </tex-math></inline-formula> flops in each updating, until <inline-formula> <tex-math notation="LaTeX">$\boldsymbol {A}^{\star }$ </tex-math></inline-formula> is obtained. Different from existing algorithms which find <inline-formula> <tex-math notation="LaTeX">$\boldsymbol {A}^\star $ </tex-math></inline-formula> column by column through using a sphere decoding search strategy <inline-formula> <tex-math notation="LaTeX">$n$ </tex-math></inline-formula> times, the new algorithm uses a search strategy once only. We then rigorously prove the optimality of the proposed algorithm. Furthermore, we theoretically analyze its complexity. In particular, we not only show that the new algorithm is <inline-formula> <tex-math notation="LaTeX">$\Omega (n)$ </tex-math></inline-formula> times faster than the most efficient existing algorithm with polynomial memory complexity, but also assert that it is even more efficient than the most efficient existing algorithm with exponential memory complexity. Finally, numerical simulations are presented to illustrate the optimality and efficiency of our novel SMP algorithm.
