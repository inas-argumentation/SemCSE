A semi analytical procedure for estimating relative permeability from displacement experiments: account for pre breakthrough data
The parameter estimation technique for determining relative permeability functions from unsteady state experiments is considered. An expression for differential pressure across the core sample which is applicable before the injected fluid reaches the outlet face, is derived. The method proposed extends the Johnson Bossler Nauman Efros procedure which is currently an industrial standard for estimating relative permeability and which can be used to interpret flow data only after breakthrough. A relative permeability simulator based on this semi analytical procedure is described. In the history matching algorithm, the determination of the global minimum of the objective function is ensured by using the simulated annealing method of minimization.
