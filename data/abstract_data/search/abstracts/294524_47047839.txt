QRD RLS adaptive filtering approach for acoustic echo cancellation and its comparison with LMS and FLMS algorithms
Adaptive filtering has numerous applications in the field of research. Acoustic echo cancellation (AEC) is one of the most interesting and challenging applications in the era of rapidly emerging telecommunication industry. Number of adaptive filtering algorithms has been presented to achieve echo cancellation like (Least Mean Square) LMS, (Fractional Least Mean Square) FLMS etc. Efficiency of these algorithms is evaluated by using different performance indices. Although, some of these algorithms found to be very attractive choices for echo cancellation, but still there is a need to improve the performance of these algorithms for obtaining better results. Here, in this paper, we have proposed a new adaptive filtering approach for echo cancellation named as QRD RLS. The proposed algorithm proved to be better in terms of performance indices like Echo Return Loss Enhancement (ERLE) Mean Square Error (MSE) convergence rate etc.
