Using Prewitt Operator as Gradient Based Method for Fingerprint Singular Points Detection
Singular Point (SP) is an essential feature in fingerprint images. It is considered as a fingerprint landmark. It is used for both fingerprint classification and alignment in automatic fingerprint recognition systems. In this paper the Prewitt operator is used as method for detecting of singular points in fingerprint image. The Prewitt operator is used as a gradient based method of fingerprint image edge detection. Singular Points detection technique searches on the core point and the delta point in fingerprint classes. The experimental work has been evaluated using the four groups of the set (B) of the FVC2004 database that include DB1, DB2, DB3 and DB4. The experimental evaluation of the Prewitt operator showed good results, especially in good quality fingerprint images. The maximum accuracy achieved was in DB4 is up to 95% for core point detection and 53.75% for delta point detection
