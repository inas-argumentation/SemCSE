Double Let Water Tank Control Experiment System Based on LabVIEW
The experiment system controlling a double let water tank is designed,the mathematical model and simulation model of the double let water tank PID control system are established by the Simulink tool which is a component of MATLAB,and the simulation model of the control system without PID control algorithm is built too,the simulated results of two models are obtained.The software of double let water tank experiment control system is complied by programming language LabVIEW,and the foreground interface and background program are given.The experimental teaching demand of control system can be satisfied by this system.
