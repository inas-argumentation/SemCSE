Utilizing Extended Visual Cryptography for Ensuring Safety and Accuracy of PDF File in Cloud Storage
Nowadays cloud computing (CC) is in endless prosperity position and visual cryptography (VC) is very important part of cloud computing. Many institution and people at every turn use cloud storage but they do not know about its security policies, which is risky for their business. It is a very challenging part for the user and cloud service provider (CSP) to protect data in cloud storage. If secret data is stored in cloud in unencrypted form then the unauthorized people and the CSP can easily access the data. But the algorithm which is standard need computational primitives, storage space and cost. So it is very staple significance to protect cloud data with minimum computation and storage space. Utilizing extended visual cryptography for ensuring safety and accuracy of PDF file in cloud storage (UEVCESAPDFCS) process offer useful storage to maintain data confidentiality and integrity verification. In the previous work the authors used (VC) in the proposed method we also use (VC) But the different between this two works is, in the previous work there is a chance to rearrange the data value, but in our algorithm the condition is like when the uploaded and downloaded data will be same then the algorithm will be finished, so there is no chance to change the data value. In this research our main target was to defense the unauthorized people from recognize the clouds data value
