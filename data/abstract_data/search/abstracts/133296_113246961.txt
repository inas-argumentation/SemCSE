Research on Chinese chess playing robot system based on Mega128
Chess robot is a kind of entertainment robot, which is a very promising new force in robotic field. A kind of Chinese chess playing robot system is introduced in this paper, which makes use of the serial communication technology, the VB program and AVR MCU servo controltechnology synthetically. With Mega128 chip as the core and PWM technology controlling the manipulator movement, the system realizes the control of the chess pieces. By using the computer as the upper machine, the actions of the system are coordinated with each other. Hardware part consists of three parts :a board device, control system and manipulator. Control system includes a motor driver module, data sending module and data receiving module etc. Software part is based on VB platform, including the Chinese chess algorithm module and serial interface communication module which can achieve the logic control of the pieces and send commands to the control system of the manipulator via a serial port
