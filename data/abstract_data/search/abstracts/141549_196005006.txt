Face Detection for Mouse Movement using web cam
we present a simple prototype system for real time tracking of a human face and eyes. The system uses a simple yet a effective Face Tracking algorithm. The general requirements of a real time tracking algorithm .it should be computationally inexpensive, should posses the ability to perform in different environment and should be able to start and initialize itself with minimum knowledge about the environment, well addressed by the elliptical head tracking algorithm. The objective of this project is to create an alternative user interface uniquely using real time video of the users face captured using an off the shelf web camera. The position of the head is tracked and converted into the two dimensional coordinates on a computer screen, additionally ,it is intended to enable the recognition of a deliberate blink in order that this could be considered as a command from a user
