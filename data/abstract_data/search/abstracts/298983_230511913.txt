Different Types of Phishing Attacks and Detection Techniques: A Review
In this paper a review has been taken on different types of phishing attacks and detection techniques. Most of the cyber attacks are spreading through users weaknesses, which makes user weakest elements in security chain. Mostly this phishing targets the vulnerability which is already in the system due to human factor. Phishing is the huge problem and there is no single solution for mitigating the vulnerability completely so one has to use number of techniques to mitigate the attack. Here we presented various categories of mitigation technique for the phishing website like detection, correction, prevention and offensive defense.
