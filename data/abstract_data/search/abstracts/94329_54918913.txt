Failure Diagnosis of Spur Gear in Two Stage Planetary Gear Box of Bagasse Carrier Machine used in Sugar Industry by Using FEA
In this paper we have selected agearbox of bagasse carrier machine which is used in sugar industry. In sugar industry, For feeding bagasse to boiler as well as to carry crushed bagasse coming from sugar mill, bagasse carrier and bagasse elevators are commonly used. This bagasse carrier machine is driven by planetary gearbox. It is seen that the spur gear in second stage of that planetary gears fails under working conditions. So to diagnose the failure we have made the design calculations by using standard design procedure. later on, the analysis is made to find out the various stresses on the spur gears failure As existing gears fails, the modified design parameters are calculated according to standard design procedure. According to new values, modelling of gears on CREO2.0modelling software is done. Later on static structural analysis is done by using ANSYS software with finite element approach.
