Development and Implementation of Mobile Platform Oriented Interactive English Grammar Learning System
Based on the characteristics of mobile learning, an English grammar mobile learning system on Android platform is designed. Firstly, the background and advantages of mobile terminal and Android system are analyzed. Then, the development mode, database creation and communication mode are discussed. In the system implementation process, we design and implement data transmission based on Tomcat Web server and HTTP protocol, and text information exchange and voice chat based on Openfire instant messaging server and XMPP protocol. At the same time, using online learning algorithm combined with interactive system, as well as C SVC and v svc data analysis, the modular design and overall test of the system are realized. The results show that the system is accurate in search, comprehensive in content, conducive to English grammar learning, and it has strong practicability.
