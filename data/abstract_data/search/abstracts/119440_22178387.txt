Wireless Neighborhood Area Network Path Loss Characterization at 5.7 GHz
We describe a channel sounding system designed for small outdoor cell ~400 meter radius) wireless channel characterization. We report on a program of path loss measurements using a 2x2 MIMO configuration and data reduction in the frequency range of 5.7 5.75 GHz. The results are based on over 10,000 independent complex frequency responses collected in residential neighborhoods in northern New Jersey. We characterize and report on key path loss parameters such as path loss exponent and shadowing for low base station antenna heights. Based on our data analysis, we propose a statistical model for path loss in neighborhood area networks in suburban environments.
