Hadoop Based Cloud Data Security on Cloud Using Encryption Algorithm
Cloud computing is the typical creative pattern of computing technique for people to apply the Information Technology its related works along with the cheaper capabilities of computing. The services offered on the web are extending from applying the cloud provider's hardware and software to controlling the security and other issues. Securing the data from the malignant customers, a process of client authentication have becomes a significant task. Several securities and the privacy problems related to the cloud computing although these types of problems can be categorized into two wide categories such as Privacy issues and Security issues which are now suffered by the cloud providers and also by their users. This paper is basically suggested the basic idea of the secured cloud computing. In this paper, the elements are explained which may influence the cloud's security and few solutions for the issues of cloud security. This paper may provide the brief overview of the several techniques for the security of cloud data also with its limitations. Moreover, this provided support to detect solution for demerits faced within the given approached and provided the latest solution or techniques to protect the cloud.
