Data gathering algorithm for children's observation system: For realizing real time performance in information terminal bus stop
In this paper, we propose a data gathering algorithm for children's observation system which enhances anonymity of data and enhances security and has advanced security function to prevent third parties from exploiting data. Data gathering algorithm is studied widely[1, 2] However, these methods are suitable for handling relatively small data such as temperature, and it is not suitable for transmitting data more than 30 times as large as the temperature information, such as children's feature information. In the children's observation system, real time performance is important. We describe the proposed data gathering algorithm is superior the conventional algorithm in the point of data gathering time. The proposed children's observation system using information terminal bus stop is expected great contribution for city safety and security.
