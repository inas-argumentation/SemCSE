R&D and Implementation of an Embedded Remote Monitoring Terminal Based on LWIP Protocol
Respective to the demand on terminal miniaturization and modularization in the remote monitoring system,we design a remote monitoring terminal,using ARM7 ENC28J60 as the core. We further analyze network communication service as well as the real time issue of data acquisition and logical control. The system is divided into two parts: Ethernet to CAN communication module and data acquisition and control module. Inter module communication and extension is realized through CAN bus. The communication module uses real time operating system mCOS II,and transplants LWIP light duty TCP IP protocol stack. Experiments show that the system has solved the contradiction between Ethernet communication and the real time monitoring on site,conforms to the concept of modular design of the embedded system,and can be easily extended or modified.
