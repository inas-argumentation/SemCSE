Bootstrap confidence levels for phylogenetic trees
Evolutionary trees are often estimated from DNA or RNA sequence data. How much confidence should we haveintheestimatedtrees?In1985,Felsenstein(Felsenstein, J. (1985) Evolution 39, 783 791) suggested the use of the bootstrap to answer this question. Felsenstein's method, which in concept is a straightforward application of the bootstrap, is widely used, but has been criticized as biased in the genetics literature. This paper concerns the use of the bootstrap in the tree problem. We show that Felsenstein's method is not biased, but that it can be corrected to better agree with standard ideas of confidence levels and hypothesis testing. These corrections can be made by using the more elaborate bootstrap method presented here, at the expense of considerably more computation.
