Foreign Language Classroom Code Switching: An Overview (Issues, Theories, and Frameworks)
In basic terms, code switching is related to bilingualism in that one needs to be bilingual (i.e. have the use of two languages) in order to code switch between two languages. Martin Jones (1995) suggests that research into code switching ranges from educational research into classroom interaction to CA and the ethnography of interaction. Owing to its cross disciplinary nature, many other terms are used to refer to code switching. In this chapter, I define each one and highlight the differences between them.
