Load Flow Analysis of Radial Distribution System with DG and Composite Load Model
The paper presents the load flow analysis of a radial distribution system penetrated by distributed generator which can inject real power into the system. The load flow is formulated using DLF matrix. The load is modeled as composite load model which includes all four practical load models. Simulation is carried out for 12 bus and IEEE 69 bus system to demonstrate the effectiveness of the projected method at different system loading conditions for constant power and composite load model. The noteworthy reduction in system power losses, cost of annual energy loss with enhanced voltage profile is observed with DG with composite load model compared to constant power model.
