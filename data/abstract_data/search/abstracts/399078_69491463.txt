Data Security Using Homomorphic Encryption for Cloud Based Medical Record Management System
Homomorphic encryption technique is latest development in the field of data encryption. The replacement algorithm is taking part in this technique. In this paper, this technique is used for security of patient's medical record on cloud. Proposed technique besides data security, stores and retrieves cloud data is very fast. Paper proposes a model and encryption techniques with analysis before conclusion. (c)2018 Muthanna University.
