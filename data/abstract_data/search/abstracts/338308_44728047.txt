Speed control of IPMSM motor drives using Model Reference Adaptive technique
This paper presents a new robust speed control approach for Interior Permanent Magnet Synchronous Motor (IPMSM) drives with incorporated Maximum Torque per Ampere (MTPA) regulation. Compared to the conventional closed loop structure, where the reference torque for the MTPA regulator is equal to the output signal of the PI speed controller, the proposed system updates this reference via implementation of the torque loop with the Model Reference Adaptive Control (MRAC) The proposed control method overcomes the problems of the conventional control caused by the system parameters uncertainties and nonlinear structure of the MTPA algorithm. The paper highlights mathematical justification of the control realization including torque estimation and experimental validation of the corresponding speed vector control system based on the OPAL RT platform. During parameter variations, the test results show distinctly better transient behavior of the proposed system compared to the conventional control scheme.
