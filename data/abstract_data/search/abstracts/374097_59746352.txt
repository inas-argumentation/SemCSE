Effective Web Design: Master All the Essentials
From the Publisher: Here is the essential skills based guide to Web design. It's written for the millions of new and experienced Web designers who need to learn the key techniques and tricks to building exciting, yet effective, Web sites. Written by well known and well connected Web designers, this hands on guide teaches the correct usage of HTML 4 tags, "browser safe" graphics techniques, effective use of dynamic media (animation, video, sound, plug ins) site navigation principles, marketing and much more. The Appendix on browser behavior for popular platforms is a "must have" reference for all Web designers. The companion CD is loaded with the most valuable Web design tools, including HTML editors, cool multimedia plug ins, and The HTML Reference Library.
