Rdf vocabulary description language 1.0 Rdf schema
The Resource Description Framework (RDF) is a general purpose language for representing information in the Web. This specification describes how to use RDF to describe RDF vocabularies. This specification defines a vocabulary for this purpose and defines other built in RDF vocabulary initially specified in the RDF Model and Syntax Specification. Status of this Document This document has been reviewed by W3C Members and other interested parties, and it has been endorsed by the Director as a W3C Recommendation. W3C's role in making the Recommendation is to draw attention to the specification and to promote its widespread deployment. This enhances the functionality and interoperability of the Web.
