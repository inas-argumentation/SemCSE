A NOVEL HYBRID APPROACH TO ESTIMATING MISSING VALUES IN DATABASES USING K NEAREST NEIGHBORS AND NEURAL NETWORKS
Abstract. Missing values in datasets and databases can be estimated via statistics, ma chine learning and arti cial intelligence methods. This paper uses a novel hybrid neuralnetwork and weighted nearest neighbors to estimate missing values and provides goodresults with high performance. In this work, four ffent characteristic datasets wereused and missing values were estimated. Error ratio, correlation coffi predictionaccuracy were calculated between actual and estimated values and the results were com pared with basic neural network genetic algorithm estimation method.
