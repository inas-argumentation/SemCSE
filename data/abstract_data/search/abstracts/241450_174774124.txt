DESIGN AND IMPLEMENTATION OF AN EXAMPLE SEMANTIC WEB BASED SYSTEM ANLAMSAL WEB
OZET The Semantic Web is envisioned as the future of the current Web. The Semantic Web proposes the mark up of Web content so that machines can automatically process, interpret and integrate information available on the Web. This study explains the vision, architecture, theory, and fundamental components of the Semantic Web and presents design and implementation of an example prototype Semantic Web based system for an academic department of a university. Anlamsal Web mevcut Web'in gelecegi olarak betimlenmektedir. Anlamsal Web, Web iceriginin isaretlenmesini ve boylece makinalarin Web uzerindeki bilgiyi otomatik isleyebilmesini, yorumlayabilmesini ve birlestirilebilmesini onermektedir. Bu calisma, Anlamsal Web'in vizyonunu, mimarisini, teorisini, temel bilesenlerini aciklar ve bir universitenin akademik bir bolumu icin Anlamsal Web tabanli ornek bir prototip sistem tasarimini ve gerceklestirimini sunar.
