Dynamic optimization using control vector parameterization with state transition algorithm
In real world applications, a majority of optimization problems belong to dynamic optimization, which involves optimization over time and whose underlying space is infinite dimensional. In this paper, a novel dynamic optimization technique based on state transition algorithm (STA) is investigated to solve dynamic optimization problems (DOPs) Firstly, an infinite dynamic optimization problem is converted into a finite nonlinear programming problem (NLP) based on the control vector parameterizations (CVP) in which, instead of discretizing both state and control variables, only the control profiles are approximated by piecewise constant functions. Then, a stochastic global method is proposed to solve the resulting nonlinear programming problem based on state transition algorithm. By applying it in two well known dynamic optimization instances, simulation results show that the proposed approach is able to obtain similar or even better performance indicators compared with other methods in terms of computational cost, solution accuracy and stability.
