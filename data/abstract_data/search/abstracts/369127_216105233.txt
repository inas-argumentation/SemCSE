Gesture Recognition of Basketball Referee Violation Signal by Applying Dynamic Time Warping Algorithm Using a Wearable Device
This research develops a sensor based wearable device for gesture recognition in basketball violation. It gears to improve and enhance the ways of identifying signals performed by the referee. Moreover, it aims to lessen the workload of the sports officials or committees. The research presents a system wherein it is capable of recognizing basketball referee violation signals using an algorithm called dynamic time warping. The proponents used LabVIEW software for extracting data from the device that is considered as the input data. These data were transferred through Wi Fi module and were processed in the system where dynamic time warping algorithm is applied. The system was able to recognize or identify which basketball violation is performed through the provided data set of the user. The proponents concluded that the accelerometer sensor was able to recognize the basketball referee violation signals by using dynamic time warping algorithm.
