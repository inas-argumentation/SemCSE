Grouped B spline windows for the design of modulated filter banks
A fast technique for designing prototype filters for modulated filter banks is proposed. This technique is based on using the grouped B spline windows for designing the prototype filter and also spline functions in the transition band to approximate ideal filters. The main advantage of the proposed design scheme is that it lowers the computational complexity when compared with other existing techniques. Some examples are included illustrating the resulting filter banks closely satisfy the perfect reconstruction property.
