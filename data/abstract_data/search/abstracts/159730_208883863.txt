Research on Intelligent Modulation Method of Tunable Diode Pulse Width Based on Single Chip Microcomputer
In that intelligent detection process of the pulse width of the tunable diode, a tunable diode pulse width intelligent modulation system based on the 80C51 single chip microcomputer is designed, the amplitude compensation of the tunable diode pulse width spectrum is analyze, the pulse width of the tunable diode is calculated, And the positioning and identifying capability of the adjustable diode pulse width is improved. The intelligent modulation design of the tunable diode pulse width is carried out by an improved FIR filter algorithm, and the modulation and demodulation processing is carried out according to the input data of the current broadband tuning circuit to realize the intelligent modulation of the tunable diode pulse width based on the 80C51 single chip microcomputer. The experimental results show that the self adaptive performance of the tunable diode pulse width modulation is good, the broadband back wave detection capability is strong, the signal filtering performance is good, the pulse width identification capability of the tunable diode is improved, the detection accuracy is improved by 14.5% The intelligent modulation and processing performance of the better tunable diode pulse width is shown.
