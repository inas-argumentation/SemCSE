Design and implementation of web page classification tool based on word vector
With the continuous development of the Internet, the number of web pages is growing rapidly. How to find the webpage information people need in a total number of web pages has become a difficult challenge. In many web pages, manual classification is obviously unrealistic. In view of the difficulty in obtaining tools or software that can be used for automatic classification of web pages [1,11,12,13] on the Internet, this topic designs and implements a web page classification tool based on word vector. With this tool, we can classify a large number of uncategorized pages based on some of the pages that have been classified. This article will discuss the overall architecture, design and implementation process of the web page classification tool and the classification process of the tool. At the same time, the article tests the usability and practicability of the tool, and the test results have positive significance for the use and evaluation of the tool.
