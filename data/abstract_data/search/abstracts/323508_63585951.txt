Real time Sitting Posture Monitoring System using Pressure Sensor
The present invention provides a real time sitting position monitoring system by using pressure sensors. The system includes: a measuring unit which includes a first pressure sensor which senses pressure the left thigh puts on a chair, a second pressure sensor which senses the pressure the right thigh puts on the chair, a third pressure sensor which senses the pressure the left hip puts on the chair, a fourth pressure sensor which senses the pressure the right hip puts on the chair, a fifth pressure sensor which senses the pressure the left back puts on the chair and a sixth pressure sensor which senses the pressure the right back puts on the chair; a control unit which converts a pressure value sensed by each of the first pressure sensor, the second pressure sensor, the third pressure sensor, the fourth pressure sensor, the fifth pressure sensor and the sixth pressure sensor into digital data and transmits the digital data; and a monitoring unit which stores the pressure digital data transmitted by the control unit by measuring date and time and displays the pressure digital data.
