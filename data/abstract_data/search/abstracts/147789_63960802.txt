Graph Representation of Concurrent Programs in C
Graph representation of software is a fundamental concept in the the areas of software testing and analysis. Although there is a plethora of software graphs in the literature, each one offering a different perspective of the underlying program, little effort has been devoted for the formulation of a graph which would offer a comprehensive view of the system by combining sub graphs of different granularity. Furthermore, capturing concurrency is an area which has received limited attention by the scientific community especially when it comes to modern programming languages like C+ and Java. In this project, we have developed a compiler based tool for the C++11 programming language which operates on the abstract syntax tree of arbitrary C++11 programs and produces a concurrent program graph of the input system which captures its object oriented design as well as the control and concurrency dependencies that exist in (and between) the system's defined methods and functions.
