Domain Adaptation for Sentiment Analysis A Survey
Domain adaptation is a useful technique to combat the problem of data scarcity. It has been used for multiple NLP tasks like part of speech tagging, dependency parsing, named entity recognition etc. Crossdomain sentiment analysis (CDSA) is one such application of domain adaptation where classifier is trained on one domain (referred as 'source domain' and tested on another domain (referred as 'target domain' In this paper, we investigate various challenges and techniques for CDSA. We also address the problem of selecting suitable source domain for a particular target domain in CDSA.
