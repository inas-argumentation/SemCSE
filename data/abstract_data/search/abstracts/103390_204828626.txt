Modified PCA based image fusion using feature matching
Image fusion is the process that involves combination of two or more images are into a single image retaining the certain characteristic features from each of the initially used images. In this paper, a method to optimize image fusion using Modified Principle Component Analysis (MPCA) is proposed. In conventional PCA, principal components based on eigen values of the source images are estimated. Though conventional PCA fuses the images, the probability for principal components to lie in the same region is high. Whereas in case of Modified PCA, the principal components are determined for each block which will eliminate the problem of having principal components over the same region. Performance of the proposed method is experimented on Panchromatic image (PAN) and Multispectral image (MS) of Worldview 2 sensor. The fused image is better in both spatial and spectral information content.
