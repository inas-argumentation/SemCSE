A Survey on Software Fault Localization Techniques
In recent years, there has been significant interest in fault localization techniques that are based on statistical analysis of program constructs executed by passing and failing executions. This paper shows how an existing techniques such as Tarantula, Jaccard ,Ochiai have an efficient technique for localizing fault based on suspiciousness score and rank compared to set union, setintersection. A survey of all an existing techniques should be analysed and a faulty statement in each should be calculated. Each and every technique same test case is generated and an executed statement should be denoted for finding faulty statement. Keywords Tarantula, Jaccard, Set union, SetIntersection, Nearest Neighbor, Fault Localization
