Continuous Time Sigma Delta Modulator with VCO based integrators and optimized NTF zeros
This work presents the architectural concept and circuit simulation of a third order VCO based Continuous Time Sigma Delta Modulator. The loop filter has a mixed mode resonator built with an RC OTA PI element and a VCO based integrator coupled through a resistor, which helps to optimize SNDR. The quantizer is built with a noise shaping digitally controlled oscillator. A linear model of the system is developed and used to optimize the architecture. The performance of this concept is limited by the linearity of the DCO based quantizer, which can be mitigated by using a set of parallel single bit switched ring oscillators. As an example, a 60 MHz bandwdith ADC is designed and simulated, showing more than 70dB of SNDR with 2 GHz sampling clock.
