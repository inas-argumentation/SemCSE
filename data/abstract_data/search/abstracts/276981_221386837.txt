Development of Intelligent Door Locking System Based on Face Recognition Technology
This paper presents a low cost smart door locking system capable of making decisions based on facial recognition technology. The system operates through a combination of Arduino UNO and Android based smartphone. It is capable of performing all the facial recognition stages on its own such as face detection, features extraction, face recognition applying OpenCV libraries. The identification is fast and non contact, providing an increase in comfort for system users. Moreover, the system has a secondary protection level, such as the conventional pin code based and RFID based security levels that extend the functionality. The main advantage of the system is its autonomous function; once the system is installed, there is no need to supervise it. The system is easy to tune, and the Android OS allows to update the database for face recognition easily.
