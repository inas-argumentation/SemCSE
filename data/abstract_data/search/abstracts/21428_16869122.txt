An Adaptive Information Research Personal Assistant
Available tools to retrieve information from the Web implement a generalist approach that does not account for the characteristics of the user. This limits the quality of the results that they provide. The agent presented here uses document references gathered by a user to build a hierarchical model (user profile) of this user's interests. The agent then uses the model to interpret the queries and to filter the results returned by the search engines of the Web. It also uses information gathered while observing the ongoing activities of the user to select the most relevant parts of this profile.
