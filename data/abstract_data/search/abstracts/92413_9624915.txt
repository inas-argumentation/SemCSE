A Design Approach for Traffic Volume Monitoring and Intelligent Signal Control System
A development of an integrated intelligent traffic light (IITL) system necessary because today's traffic light controllers are basically microcontroller and microprocessor based. These systems use the predefined program that does not have the flexibility of modification on real time application. Hence these systems have many disadvantages. The present traffic system have fixed time interval for green, orange and red signal which does not provide the flexibility to the system. The IITL system consist of high performance ,low power AVR_32 microcontroller with 32kbytes of in system programmable flash memory and in built 8 channel ADC which required to process the IR input from sensor network. The IITL system will able to deal two basic problem of traditional traffic light system: i) Detection of traffic volume by using genetic algorithm. ii) Emergence vehicle detection such as ambulance, police etc by using wireless sensor network (IR) embedded at the signal intersection. KeywordsTraffic Volume Estimation, Genetic Algorithm, wireless sensor network, Vehicle detection, Intelligent Traffic Light Controller, embedded systems.
