ANALISIS PERMINTAAN JASA ANGKUTAN KERETA API NONEKONOMI DI DAOP VIII SURABAYA (STUDI KASUS KERETA API EKSEKUTIF TURANGGA JURUSAN SURABAYA BANDUNG)
Penelitian ini melihat adanya hubungan antara variabel usia dan pendapatan dengan permintaan kereta api eksekutif Turangga yang digambarkan dengan frekuensi penumpang menggunakan kereta tersebut pada bulan Februari, Maret, dan April tahun 2014 jurusan Surabaya Bandung (One Way) Metode yang digunakan adalah regresi linear berganda (ordinary least square) Hasilnya variabel usia tidak signifikan atau tidak memiliki hubungan dengan frekuensi penumpang untuk menggunakan kereta api eksekutif Turangga. Namun, apabila dilihat dari distribusi respondennya maka terdapat hubungan negatif antara usia dengan frekuensi penumpang menggunakan kereta tersebut. Sementara itu, variabel pendapatan memiliki hubungan positif dengan frekuensi penumpang menggunakan kereta tersebut pada bulan Februari, Maret, dan April tahun 2014 jurusan Surabaya Bandung (One Way) Selain itu, penelitian ini juga mengamati faktor pendorong utama dari empat faktor yaitu keamanan, kenyamanan, kecepatan dan tarif yang paling mempengaruhi penumpang untuk menggunakan kereta api eksekutif Turangga dengan melakukan survey. Survey dilakukan dengan metode random sampling menggunakan skala Likert kepada 100 penumpang kereta api eksekutif Turangga jurusan Surabaya Bandung. Hasilnya faktor keamanan merupakan faktor utama yang mendorong penumpang untuk menggunakan kereta api eksekutif Turangga
