Fast global registration for image mosaicing
A number of papers have been dedicated to the estimation of the projective transform between a pair of frames. Some of them have focused on the error accumulation problem caused by the concatenation of these transforms. In this paper, a new method that uses sequential graph system is proposed to minimize the error accumulation. And, we propose a robust matching method using sequential shortest path search algorithm and uncertainty measure. Our method is fast and robust. Also, because our system is sequential and uses limited system memory, our method is useful for real time applications.
