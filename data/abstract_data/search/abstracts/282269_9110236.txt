An algorithm for triangulation applied to 3D GIS
In 3D GIS, in order to quickly and accurately build 3D models, polygons which are formed by 2D vector data should be triangulated. At present, in GIS, ear clipping triangulation algorithm is widely used in triangulating simple polygons. Because ear clipping triangulation algorithm is low efficiency, more easily to generate long, narrow triangles, a continuous cutting algorithm for triangulating a simple polygon is proposed based on ear clipping algorithm. The algorithm is mainly to continuously cut out the triangles with same vertex in polygon. This algorithm has features such as strong practicability, high efficiency and not easy to generate long, narrow triangles, etc.
