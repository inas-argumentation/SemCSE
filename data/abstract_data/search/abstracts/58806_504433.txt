Receiver Design For OSDM Communication System
A new information transmission method using the Kronecker product between the rows of DFT matrix and the data sequences called OSDM (orthogonal signal division multiplexing) OFDM method is one special case of OSDM method, and MMSE receiver for OSDM method achieve more than 2 times faster transmission speed compare with OFDM under same bandwidth, same transmitter power, same multipath environment,and same bit error probability. In this paper we use reduced size MLD (maximum likelihood detector) receiver to detect OSDM signal. Simulation results is shown that reduced size MLD receiver for OSDM system have good performance compare with MMSE receiver for OSDM system.
