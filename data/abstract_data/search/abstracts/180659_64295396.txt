The Research of NAS Based Mirror File System and it's Implementation under Linux
The rapid increase of Global data brings the extensive applications of NAS,but the data may lose when the devices occur failure in the traditional structure of NAS,from this point,traditional structure of NAS can not match the demands of a modern storage system in availability and reliability. This paper puts forward a NAS frame structure ,which is applied in files mirror,and based on VFS mechanism,designs and implements a file system under Linux platform,named Mirror File System (NASMFS),which is applied in this NAS frame structure. This file system screens the differences of each NAS device's file system in the low level of a system ,and it provides a secure and reliable uniform storage directory space to clients ,accomplishes the mirror function transparently as well,so it can restore the data from the mirror files when the devices occur failure. Concerning the availability and reliability of the traditional structure of NAS,this paper offsets these limitations,and meets the demands of applications.
