Smart Automated Teller Machine Applications Using Artificial Intelligence
This paper provides various methods for increasing the features and possible applications of an automated teller machine (ATM) using AI and machine learning to keep up with the latest technologies and trends. The methods include targeted advertisement, biometric security, cryptocurrency conversion, remote medical kiosks and much more. The strategic placement of these kiosks allows for a wide range of unique applications, which might not be otherwise possible, and that too with only minor hardware additions to the current machines. In future, these centers will turn into hotspots for services like banking, transportation, documentation, healthcare, survey implementation.
