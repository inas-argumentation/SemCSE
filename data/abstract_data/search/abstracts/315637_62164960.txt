Internet Explorer 5 for Windows For Dummies
From the Publisher: Internet Explorer 5.5 For Windows ME For Dummies is sure to please the legions of new Internet users turning to IE as their main Internet tool. This book helps readers figure out the essential first steps of using the Internet like going online and making all their software work. It then moves into offering fun and easy guidance on the things that make using the Internet great Web browsing, using E mail, and instant communication. Author Doug Lowe also introduces readers to the latest advances in browser technology included with IE 5.5. Internet Explorer 5.5 For Windows ME For Dummies is ideal for new IE users making their first Internet journeys or Web vets who want to know more about the updated PC tool. Covers the essentials of going online and getting around, including connecting to the Internet with IE 5.5, Web browsing, customizing the browser, and sending and receiving E mail with Outlook Express. Features real, hands on instruction on making IE 5.5 as secure as possible for private Internet usage. Authored by Doug Lowe, a prolific For Dummies author who has also written MSN.com For Dummies and Creating Web Pages For Dummies Quick Reference. About the Authors Doug Lowe (Fresno, CA) is a prolific writer in the For Dummies series with several editions of several titles to his credit. Along with previous editions of Internet Explorer For Dummies, he also wrote Networking For Dummies, PowerPoint For Dummies, Client/Server Computing For Dummies, and Microsoft Office For Windows For Dummies Quick Reference. He recently finished MSN.com For Dummies.
