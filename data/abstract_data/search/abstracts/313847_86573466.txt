Active Protection System
The invention relates to an active protection system including a first lens, a second lens, a communication unit, a processing unit and an alarm unit. The first lens receives first radial and generates a first image. The second lens receives second radial and generates a second image. The processing unit obtains characteristic quantity of an object according to the second image, judges whether the characteristic quantity meets a preset value or not. If the characteristic quantity reaches the preset value, whether the object is modified or not in a predetermined time or not is judged according to the first image. If a condition that the object is not modified in the predetermined time is judged, the processing unit controls the alarm unit to send alarms.
