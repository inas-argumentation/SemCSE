Unified Structured ID and Orthogonal Information Retrieval technique on Chat Room Style Realtime Messaging Platform for Industrial Internet of Things
The "Industrial Internet of things" (IIoT) has rapidly become a popular concept. However, the IIoT concept has caused problems in managing consistent identifiers. To solve these problems in control system management, we propose Structured ID, which can define the complicated structure of control systems using IDs on a tree structure, and relational links, which can describe meaning for subsets of structured IDs. Furthermore, in use cases that utilize consistently managed information, a method of distributing appropriate information to each stakeholder is required. To address this requirement, we propose an orthogonal information retrieval technique for Structured ID. Finally, we evaluate that the proposed techniques can be implemented using web technology and confirmed that those can solve problems in the Industrial Internet of things use case.
