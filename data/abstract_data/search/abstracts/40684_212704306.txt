An Enhanced Model for Skin Disease Detection using Dragonfly Optimization based Deep Neural Network
In this paper, we have proposed an efficient skin disease identification approach using enhanced deep neural network model. The database images are segmented using enhanced level set approach based segmentation. Feature extraction is carried out for all the images to retrieve the feature vector using GLCM. Finally, dragonfly optimization based deep neural network is utilized for the classification of skin diseases. The system is implemented in the working platform of MATLAB, and the proposed dragonfly based DNN is evaluated using existing methods such as SVM, ANN for different evaluation metrics such as accuracy, sensitivity, and specificity to show the system efficiency
