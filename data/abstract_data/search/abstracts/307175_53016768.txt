Distribution System State Estimator Based on a Linearized Three Phase Power Flow
This paper presents a distribution system state estimator using Load Allocation based on the Three Phase Linear Power Flow. The formulation adjusts the loads according to the difference between system measurements and load flow results. Bus voltages as state variables were estimated and results were compared with traditional load flow results produced using OpenDSS. This formulation was further implemented using parallel computing paradigm using Nvidia's CUDA API and graphics cards achieving to enhance the performance. For the IEEE 13 and IEEE 37 bus test systems, state estimator achieved a maximum average error of 4% for bus voltage magnitude a speed up of about nine times, compared to non parallel computing.
