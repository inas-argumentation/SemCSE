Shopping Mall Promotion Tracker Subsystem For Pin It Social Network
Shopping Mall Promotion Tracker Subsystem (SMPTS) is an easy to use, web based application that allows user to get the latest information about the promotions that are being held in the shopping mall around Malaysia. Generally, this system is developed to help people especially those who are busy working to be more aware on the latest promotions held by shopping malls besides enabling the stakeholders of shopping mall to promote products using eco friendly way. Evolutionary methodology has been selected as the software development reference to this project. This methodology has five phases, which are planning, analysis, design, implementation and maintenance. This methodology also act as a maintenance oriented process as it is based on a tree of engineering decisions made at various times. In analysis phase, the functional requirements for SMPTS are determined which consist of login, registration, manage user account, manage promotion, view statistic of promotion and comment on promotion that has been posted. Next, system architecture, user interface design and database design are defined in design phase to eliminate all the redundant and unnecessary data during implementation phase. Three phases which are Software Development Environment (SDE) Software Configuration Management (SCM) and Security Characteristics (SC) are executed in order to deploy SMPTS in the implementation phase. Lastly, Unit Testing, Integration Testing and Acceptance Testing are being carried out to determine whether the system produced fulfils the user requirement where the validation and verification is done onto the system. It is believed that SMPTS can help people to be more aware on the promotions held by shopping malls.
