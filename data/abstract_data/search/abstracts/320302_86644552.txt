A Proposed OpenFlow based Load Balancing Technique for http Adaptive Streaming
HTTP Adaptive streaming (HAS) is considered the dominant technology for video transmission over the internet for the past few years. Software Defined Networking (SDN) is used over (HAS) to provide the control of the network traffic. In this paper, we propose a load balancing framework for HAS based on SDN to improve the network streaming performance. Our proposed framework consists of four phases. In the first phase network topology is constructed. In the second phase, the load balancing is applied. The typical Equal cost multipath (ECMP) protocol is proposed to do both routing and load balancing. ECMP selects the best path to send for all packets in the same flow. By the end of the third phase, the streaming servers are ranked and scheduled according their weights. Weighted Round Robin (WRR) algorithm is proposed as servers' scheduler to reduce the request time between the clients and the servers. In the final phase, the performance of the streaming network is evaluated with different values of network parameters. The proposed technique is compared with ECMP and non blocking algorithms. The simulation results shows that the proposed technique (ECMP as a load balancer and WRR algorithm as a server scheduler) achieve a higher performance rather than the two other algorithms.
