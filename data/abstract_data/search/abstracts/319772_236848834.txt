Malware Detection Using Mixture of Experts Neural Network in the IOT Platform
With the introduction of the Internet of Things, cybersecurity has expanded beyond the human realm possibilities. This has led to new research methods to detect IOT malwares. IOT malwares pose a real threat to the internet domain. That is why we need a strong framework algorithm to eradicate this possible threat. There has been many techniques adopted to detect and classify malware and benignware till now. Machine learning techniques and convolutional neural networks are most popular. The best technique available is using the mixture of experts neural network. There are three tasks in this neural network. Task 1 converts the gate input layer code to a binary matrix containing hexadecimal operational codes, task 2 detects malware and task 3 detects benignware. Here tasks 1, 2 and 3 are interconnected with each other since they are the hidden layers in the neural network. With a targeted accuracy of 96.32 this is one of the best available methods till date.
