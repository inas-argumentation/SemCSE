Encryption and Decryption of Vital Signs Information through a Symmetric based Cryptography Algorithm
The key factor of safe data transfer is through thorough data security. One way of securing data is through encryption. Data encryption is necessary for sensitive data like medical information. This study focuses on symmetric key algorithm which is one of the many data encryption algorithms. This algorithm shares a single symmetric key that is used for encryption and decryption of data. Compared to asymmetric key encryption, symmetric key encryption is less complex, therefore would perform faster and may lessen the delays of processing data. The objective of this study was to encrypt and decrypt vital signs information using symmetric key algorithm. The study also created an algorithm that generates a symmetric key for both encryption and encryption. After implementation, the performance of this algorithm was measured in seconds and compared to the performance of asymmetric key algorithm. After data analysis and statistical treatment using t test, the results showed that the application of symmetric key algorithm is faster than asymmetric key algorithm which implied that symmetric key algorithm can indeed lessen the delays in processing data.
