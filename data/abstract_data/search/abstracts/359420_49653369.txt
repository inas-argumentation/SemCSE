Mobile sink path planning research for underwater heterogeneous sensor network
This paper provided a mobile sink path planning method for underwater heterogeneous sensor networks (UHSN) First, a cluster topology network in which sensor nodes collect small scale data, forward to cluster head for storage by multi hop acoustic communication in cluster; Cluster heads collect large scale data, upload to mobile sink by optical communication, which can save network energy consumption and expand network coverage; Particle swarm intelligent algorithm is used to optimize the position selection of the cluster head, and shorten the moving path of the mobile sink. Lastly, the monitor center can send remote path plan control command to the mobile sink with inter cluster network route and change its moving path to maintain network, in order to realize remote control of the mobile sink by monitor center. The article achieved efficient and stable transmission of monitoring data by dual modal communication of UHSN and path plan of mobile sink, and solved the bottleneck problem of the underwater communication speed and distance conflict.
