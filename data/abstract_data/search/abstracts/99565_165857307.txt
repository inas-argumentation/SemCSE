Soluciones para el diseno y construccion de cimentaciones de torres de transmision electrica de Alta Tension
El presente trabajo contiene el desarrollo de las soluciones para el diseno de cimentaciones y construccion de estas, para torres de transmision electrica de alta tension, este trabajo de graduacion es una guia para iniciar, este tipo de disenos partiendo de conocer los aspectos mecanicos de una linea de transmision, y como parte final se describe los procesos constructivos de las soluciones dadas en este trabajo
