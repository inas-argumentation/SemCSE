Creating A Personal Cloud Storage Using NAS (Network Attached Storage)
On the contrary to economical perspective of cloud storage many cloud providers concern only about the mass usage of organisation leaving behind the individual users who rely on third party providers such as Google, Amazon, Dropbox. This increases the high risk of data integrity and reliability. Data security becomes a major question here. Hence this paper breaks the economical perspective and makes sure that each individual able to have their own cloud device which provides full access towards their data in terms of security and integrity. This is accomplished using NAS (Network Added Storage) this can be used as solution for having our own personal cloud storage this reduces the cost when compared to that of paying monthly subscriptions to third party cloud providers.
