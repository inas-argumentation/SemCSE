Analisis Pengaruh Self Control, Peer Influence, Parent Socialization dan Financial Literacy terhadap Saving Behavior pada Mahasiswa Universitas Internasional Batam
Penelitian ini dilaksanakan dengan tujuan untuk mengetahui faktor apa saja yang mempengaruhi self control, peer influence, parent socialization dan financial literacy terhadap saving behavior pada mahasiswa Universitas Internasional Batam. Penelitian ini juga bertujuan untuk membantu para pihak untuk mencari tau apa saja yang perlu ditingkatkan untuk menggapai tingkat saving behavior yang memadai. Data yang terisi secara lengkap dan menghasilkan hasil yang valid berjumlah 388 dan hasil tersebut kemudian akan diikutsertakan. Metode regresi linear berganda yang digunakan adalah aplikasi SPSS 21. Setelah dilakukannya penelitian, hasilnya menunjukkan bahwa 4 variabel yaitu: self control, peer influence, parent socialization dan financial literacy berpengaruh signifikan positif terhadap variabel dependen yaitu: saving behavior. This report was implemented to figure out what is the effect of self control, peer influence, parent socialization and financial literacy on saving behavior toward Batam International University students. This research was done using data that amounted to 388 respondents which were valid for inclusion in the test. This research is using multiple linear regression method by using the SPSS 21 software application. Helping almost all parties to know what things that needed to be improved or avoided to achieve an adequate level of saving behavior is the aim of this research. Because, saving behavior is an important behavior that needs to be applied by every individual in this millennial era. The results showed that self control, peer influence, parent socialization and financial literacy had a significant positive effect through this analysis on saving behavior.
