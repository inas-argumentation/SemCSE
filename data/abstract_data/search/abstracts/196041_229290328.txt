Perancangan dan Implementasi Aplikasi Sales Force Automation (SFA) Dengan Java Spring Boot Menggunakan Vaadin
Teknologi Java Spring memainkan peranan penting dalam perkembangan teknologi masa kini, Java ada di semua lini dunia bisnis dan kehidupan masa kini, hadir dalam bentuk aplikasi yang dapat digunakan dengan mudah.Spring sebagai salah satu framework pengembangan yang seringkali digunakan mendominasi mayoritas pengembangan aplikasi berteknologi java. Spring boot yang merupakan teknologi terbaru berbasis java dalam pengembangan memudahkan pengembang menciptakan aplikasi komplek dengan security yang lebih baik dan aman. Khususnya aplikasi otomasi penjualan yang dikenal dengan sebutan Sales Force Automation(SFA) Sementara Framework front end yang didukung juga berbasis java yang digunakan adalah framework vaadin pada aplikasi SFA, Framework vaadin berbasis java fundamental memberikan tampilan yang responsive dan menarik serta mudah digunakan.
