Indicated Torque On Line Estimation Based on Cerebellar Model Network for Marine Diesel Engine
A new method for torque estimation based on engine instantaneous speed was presented,transforming the torque estimation question into engine speed tracking one.The system model of marine diesel engine was established.Its inverse dynamic model was approached by cerebellar model network based on reliability allocation,using gradient descent algorithm to correct weigh of the network.The system stability was ensured with error feedback.The engine instantaneous speed data collected,as the parameter of the power plant were used to calculate the instantaneous torque.Results show that simulated instantaneous speed approaches actual engine speed with 1% tracking error in 60 oCA.On the premise that the system model is accurate,the proposed method is of high accuracy,simple calculation and good real time performance.
