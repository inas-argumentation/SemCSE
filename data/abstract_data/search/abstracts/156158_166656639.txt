Sub system Evaluation Report, Computer Security Corporation Sentinel. Version 3.13
The Computer Security Corporation's, Sentinel Security System product was evaluated against the identification and authentication, discretionary access control and audit requirements detailed in the Department of Defense Trusted Computer System Evaluation Criteria, dated December 1985. Sentinel is a hardware/software product which, when properly installed, provides trust through the implementation of the security features listed above. This report documents the evaluation of this product.
