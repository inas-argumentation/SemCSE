Anti theft smart electric meter box
The utility model discloses an anti theft smart electric meter box and belongs to the electric meter box technical field. The anti theft smart electric meter box comprises a shell and a smart anti theft system which is arranged in the electric meter box and is powered by an external power source; a storage battery is arranged in the shell; the storage battery can supply power for the smart anti theft system when external power supply is interrupted; the storage battery is charged by the external power source; the smart anti theft system comprises an identity authentication module, a main controller, an electronic lock, an image pick up device, an audible alarm module and a wireless communication module; and the smart anti theft system further comprises a power outage monitoring module used for judging whether the external power source is cut off or not, and feeding back information to the main controller. According to the anti theft smart electric meter box of the utility model, the storage battery and the smart anti theft system are adopted, the electric meter box can be prevented from being opened, so that electricity larceny behaviors can be avoided, and electricity larceny and electric meter box larceny can be prevented when the external power source is cut off.
