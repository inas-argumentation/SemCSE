Sonar image registration for swarm AUVs navigation: Results from SWARMs project
This work is a part of the European SWARMs project (Smart and Networking UnderWAter Robots in Cooperation Meshes) in which AUVs and ROVs should work in a cooperative mesh. This research is a preliminary study of a multisensor image registration problem to help AUV localization. It is split in two principal tasks: landmark detection and landmark matching. Currently, algorithms use only sidescan sonar images but they should be as versatile as possible to allow the use of more than one sensor in the future. Several real cases are presented and results accuracy is discussed.
