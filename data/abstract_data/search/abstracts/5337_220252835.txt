Enhancing information transfer rate of multi class BCI system by improving classification accuracies using machine learning methods
This paper presents a novel method of enhancing the information transfer rate of a multi class brain computer interface (BCI) system by improving classification accuracies using machine learning methods. Brain signals are converted into digital commands by decoding their activity patterns. Functional near infrared spectroscopy (fNIRS) is a non invasive optical imaging procedure that records the neural activities by measuring concentration changes of oxygenated hemoglobin (HbO) and deoxygenated hemoglobin (HbR) The most important performance parameters of fNIRS based BCI are accuracy and information transfer rate (ITR) Till now, mostly the ITR analysis of only two class fNIRS based BCI have been shown. Here, we propose to improve the information transfer rate for a three class problem by improving the classification accuracy. After data acquisition, filtration was performed to remove noises, and then the k nearest neighbor (KNN) classifier was well known to achieve high accuracies using a 10 fold cross fold validation in this kind of problem. The classification accuracy for the three class problem was 95.6% Furthermore, the average ITR for the fNIRS based BCI system was calculated to be 8.23 bits/min. These results demonstrate that these ternary mental tasks have the potential to improve user's performance for fNIRS based BCI systems.
